# SUBIT-∞

## Формальна специфікація ієрархії SUBIT-64 ⊂ SUBIT⁺ ⊂ SUBIT-TOPOS ⊂ SUBIT_∞

**Версія 5.1**

---

## Анотація

SUBIT-∞ — формальна нотаційна система для опису самореферентних динамічних систем: систем, у яких правило еволюції є частиною самого стану, а не зовнішнім параметром. Специфікація побудована як строга кумулятивна ієрархія з чотирьох рівнів, кожен з яких є самодостатньою, завершеною системою і додає до попереднього рівно один новий шар структури:

```
SUBIT-64  ⊂  SUBIT⁺  ⊂  SUBIT-TOPOS  ⊂  SUBIT_∞
```

**SUBIT-64** фіксує статичний алфавіт із 64 архетипних станів. **SUBIT⁺** додає внутрішнє правило еволюції та оператор, що змінює і стан, і правило. **SUBIT-TOPOS** підносить це до категорії з класифікатором стабільності, типовою системою та модальною логікою. **SUBIT_∞** знімає обмеження скінченності, розширюючи простір станів до рекурсивної коіндуктивної структури дерев із мітками, у якій категорія "хаотичної" динаміки вперше стає математично змістовною.

Специфікація завершується нормативним розділом про епістемологічний статус системи: SUBIT-∞ є інструментом формулювання й структурування гіпотез, а не емпіричною теорією.

# ЧАСТИНА I. SUBIT-64 — алфавіт станів

## 1. Алфавіт примітивів

В основі системи лежить скінченна множина примітивних маркерів потужності 4. Специфікація параметризована вибором конкретної реалізації цієї множини; визначено дві стандартні, взаємно ізоморфні реалізації.

**Семантична реалізація** — для прикладного моделювання конкретних емпіричних систем:

```
A_WHO   = { ME, WE, YOU, THEY }
A_WHERE = { EAST, SOUTH, WEST, NORTH }
A_WHEN  = { SPRING, SUMMER, AUTUMN, WINTER }
```

**Логічна реалізація** — білаттис Белнапа, для формально-логічного трактування:

```
𝔸 = { T, F, B, N }
```

де T = True (Yang), F = False (Yin), B = Both (діалетеїчне значення), N = Neither (паракомплетне значення). Множина 𝔸 несе структуру білаттиса з двома незалежними частковими порядками:

```
порядок істинності:  F <ₜ N <ₜ T,   F <ₜ B <ₜ T
порядок інформації:   N <ᵢ F <ᵢ B,   N <ᵢ T <ᵢ B
```

Кожне значення обох реалізацій кодується двома бітами (bigram = b₁b₂):

| Bigram | Семантична реалізація | Логічна реалізація |
|---|---|---|
| 10 | ME / EAST / SPRING | T |
| 11 | WE / SOUTH / SUMMER | B |
| 01 | YOU / WEST / AUTUMN | F |
| 00 | THEY / NORTH / WINTER | N |

Відповідність між реалізаціями є ізоморфізмом множин потужності 4: він дозволяє переносити алгебраїчні результати між реалізаціями, не встановлюючи жодного змістовного ототожнення на кшталт "ME означає True" — це технічна, а не інтерпретаційна еквівалентність.

## 2. Простір станів S₀

**Означення 2.1.** Простір станів SUBIT-64 визначається як

```
S₀ = A_WHO × A_WHERE × A_WHEN  (або 𝔸³ у логічній реалізації)
|S₀| = 4³ = 64
```

Кожен стан — трійка s = (α, β, γ), де α ∈ A_WHO, β ∈ A_WHERE, γ ∈ A_WHEN. Стан кодується 6-бітним словом b₁b₂b₃b₄b₅b₆, де b₁b₂ кодує WHO, b₃b₄ — WHERE, b₅b₆ — WHEN.

**Гексаграмна нотація.** Розбивши код на дві тригами — Lower Trigram (b₁b₂b₃) і Upper Trigram (b₄b₅b₆) — кожному стану можна зіставити унікальну гексаграму І-Цзін (повна таблиця відповідності — Додаток A). Ця нотація використовується виключно як компактний, однозначний комбінаторний запис 6-бітного слова; жодне додаткове тлумачення традиційної символіки триграм не є частиною формальної специфікації.

**Властивості рівня.** S₀ є статичним простором: відсутній оператор переходу, відсутня внутрішня динаміка, класифікатор істини тривіальний. SUBIT-64 — необхідний алфавіт архетипів, але сам по собі не описує зміну, причинність чи перехід між станами.

# ЧАСТИНА II. SUBIT⁺ — скінченна самореферентна динаміка

## 3. Простір правил і розширений стан

**Означення 3.1.** Простір правил еволюції на цьому рівні — скінченна множина

```
ℛ = { ρ₁, ρ₂, …, ρₙ },   ρᵢ : S₀ → S₀
```

**Означення 3.2.** Розширеним станом називається пара

```
ŝ = (s, ρ) ∈ S₀ × ℛ
```

де ρ — активне правило еволюції, що належить самому стану. Це — принципова відмінність SUBIT⁺ від класичного скінченного автомата: у автоматі функція переходу δ зовнішня щодо стану q і фіксується раз і назавжди; у SUBIT⁺ правило ρ є компонентою стану ŝ і само підлягає зміні.

## 4. Оператор еволюції та ієрархія рівнів самореференції

**Означення 4.1.** Оператор еволюції

```
F : S₀ × ℛ → S₀ × ℛ
F(s, ρ) = ( f_ρ(s), g(ρ, s) )
```

де f_ρ : S₀ → S₀ — застосування поточного правила до стану; g : ℛ × S₀ → ℛ — функція метаеволюції, що визначає, як саме правило змінюється залежно від поточного правила й стану.

**Аксіома 4.1 (детермінованість).** F — тотальна функція, визначена для всіх пар (s, ρ) ∈ S₀ × ℛ.

Ця конструкція виявляє чотири рівні самореференції, недоступні класичному автомату:

```
Рівень 0:   s = (α, β, γ)      базовий стан (без правила)
Рівень 1:   ŝ = (s, ρ)         стан із внутрішнім правилом
Рівень 2:   F(ŝ) = (s′, ρ′)    еволюція стану і правила за один крок
Рівень 3:   g(ρ, s) → ρ′       метаеволюція: зміна способу зміни
```

Класичний автомат має лише Рівень 0 і фіксований (незмінний) Рівень 2; SUBIT⁺ додає Рівні 1 і 3, стираючи межу між даними, програмою й метапрограмою.

## 5. Траєкторії у скінченному просторі

**Означення 5.1.** Траєкторією розширеного стану ŝ₀ називається послідовність

```
τ(ŝ₀) = (ŝ₀, ŝ₁, ŝ₂, …),   ŝₙ₊₁ = F(ŝₙ)
```

**Твердження 5.1 (скінченна періодичність).** Оскільки S₀ × ℛ — скінченна множина, а F — детермінована функція цієї множини в саму себе, для будь-якого ŝ₀ існують m ≥ 0 і k ≥ 1 такі, що ŝ_{m+k} = ŝ_m. Іншими словами, кожна траєкторія в SUBIT⁺ рано чи пізно входить у цикл, можливо, після скінченного передперіодичного "хвоста" (принцип Діріхле, застосований до відображення скінченної множини в себе).

Це дає повний перелік типів одноточкових траєкторій, реалізованих на цьому рівні:

| Тип | Умова |
|---|---|
| Атрактор (нерухома точка) | F(ŝ) = ŝ ⟺ f_ρ(s) = s і g(ρ, s) = ρ |
| Орбіта (цикл довжини k > 1) | Fᵏ(ŝ) = ŝ і ∀i < k: Fⁱ(ŝ) ≠ ŝ |
| Передперіодична траєкторія | ∃m > 0, k ≥ 1: ŝ_{m+k} = ŝ_m, а ŝ₀, …, ŝ_{m−1} — без повторів |

Жодна одноточкова траєкторія на цьому рівні не може бути неперіодичною в строгому сенсі — генуїнно неперіодична динаміка вимагає нескінченного простору станів чи правил (Частина IV).

**Алгоритм 5.1 (класифікація за скінченним наближенням).**

```
Вхід: ŝ₀ = (s₀, ρ₀), горизонт пошуку N_max
visited ← ∅
для n = 0, 1, …, N_max:
    якщо ŝₙ ∈ visited:
        L ← n − позначку входження ŝₙ до visited
        якщо L = 1: повернути "атрактор"
        інакше:      повернути "цикл довжини L"
    додати ŝₙ до visited
    ŝₙ₊₁ ← F(ŝₙ)
якщо N_max вичерпано без повтору:
    повернути "цикл довший за N_max" (горизонт пошуку недостатній)
```

# ЧАСТИНА III. SUBIT-TOPOS — категорія, класифікатор, типи

## 6. Класифікатор стабільності Ω

Означення й результати цієї Частини формулюються для довільної множини P ⊆ S₀ × ℛ (а не лише для одноточкової траєкторії, як у Частині II), і залишаються дослівно чинними при заміні S₀ на S_∞ у Частині IV.

**Означення 6.1.** Клас стабільності множини P визначається такими умовами:

```
STABLE       ⟺  F(P) = P
METASTABLE   ⟺  F(P) ⊊ P                         (строга власна підмножина)
CYCLIC       ⟺  існує мінімальне k > 1: Fᵏ(P) = P,  і F(P) ≠ P
CHAOTIC      ⟺  F(P) ⊄ P   і   ∀k > 1: Fᵏ(P) ≠ P
```

Ці чотири умови взаємовиключні й вичерпні за побудовою. Дійсно: якщо F(P) ⊆ P і F(P) ≠ P (тобто P метастабільна), то за індукцією Fᵏ(P) ⊆ F(P) ⊊ P для всіх k ≥ 1, тож Fᵏ(P) ≠ P за жодного k — METASTABLE і CYCLIC автоматично несумісні. Якщо ж P задовольняє умову CYCLIC (∃k>1: Fᵏ(P)=P, F(P)≠P), то з щойно наведеного випливає, що F(P) не може бути власною підмножиною P, тобто F(P) ⊄ P — отже, коли F(P) ≠ P, рівно одна з трьох можливостей (METASTABLE, CYCLIC чи CHAOTIC) реалізується, залежно від того, чи F(P) ⊊ P, чи існує k>1 з Fᵏ(P)=P, чи жодне з двох. CHAOTIC, таким чином, є точним доповненням об'єднання трьох інших класів, а не окремою умовою, яку потрібно перевіряти "до нескінченності" алгоритмічно — вона є коректно визначеною математичною альтернативою вже на етапі формулювання.

**Означення 6.2 (семантична істина).** Множина станів P вважається істинною тоді й лише тоді, коли вона стабільна: P істинне ⟺ F(P) = P. Це — внутрішній критерій: він не апелює до жодного зовнішнього спостерігача, а випливає безпосередньо з динаміки F. Істина трактується як динамічний інваріант, а не як статична відповідність.

**Зауваження (математична межа скінченного рівня).** Оскільки на рівні SUBIT-64/SUBIT⁺ простір S₀ × ℛ скінченний, а кожна одноточкова траєкторія обов'язково зрештою періодична (Твердження 5.1), клас CHAOTIC для одноточкових траєкторій на цьому рівні не реалізується: будь-яка одноточкова траєкторія в скінченному просторі, розглянута як множина своїх наступних станів, зрештою стає STABLE або CYCLIC. Категорія CHAOTIC стає математично змістовною лише для множин P у нескінченному просторі S_∞ (Частина IV) — це структурна причина, чому ієрархія потребує виходу за межі скінченного рівня.

## 7. Алгебра Ω

На множині Ω = {STABLE, METASTABLE, CYCLIC, CHAOTIC} визначено лінійний порядок:

```
CHAOTIC < CYCLIC < METASTABLE < STABLE
```

Для будь-якого лінійно впорядкованого скінченного ланцюга операції ∧ = min і ∨ = max автоматично утворюють дистрибутивну ґратку. Разом із релятивним псевдодоповненням, визначеним стандартною формулою для ланцюгів (a → b := найбільший елемент ⊤, якщо a ≤ b; інакше b), ця структура утворює **алгебру Гейтінга** (алгебру Ґеделя — лінійну модель інтуїціоністської логіки).

**Кон'юнкція (∧ = min):**

| ∧ | STABLE | METASTABLE | CYCLIC | CHAOTIC |
|---|---|---|---|---|
| **STABLE** | STABLE | METASTABLE | CYCLIC | CHAOTIC |
| **METASTABLE** | METASTABLE | METASTABLE | CYCLIC | CHAOTIC |
| **CYCLIC** | CYCLIC | CYCLIC | CYCLIC | CHAOTIC |
| **CHAOTIC** | CHAOTIC | CHAOTIC | CHAOTIC | CHAOTIC |

**Диз'юнкція (∨ = max):**

| ∨ | STABLE | METASTABLE | CYCLIC | CHAOTIC |
|---|---|---|---|---|
| **STABLE** | STABLE | STABLE | STABLE | STABLE |
| **METASTABLE** | STABLE | METASTABLE | METASTABLE | METASTABLE |
| **CYCLIC** | STABLE | METASTABLE | CYCLIC | CYCLIC |
| **CHAOTIC** | STABLE | METASTABLE | CYCLIC | CHAOTIC |

**Заперечення.** Визначаючи ¬a := a → CHAOTIC і застосовуючи формулу релятивного псевдодоповнення: якщо a = CHAOTIC, то a ≤ ⊥, звідки ¬CHAOTIC = ⊤ = STABLE. Для будь-якого іншого a маємо a > ⊥, тож ¬a = ⊥ = CHAOTIC:

| a | ¬a |
|---|---|
| STABLE | CHAOTIC |
| METASTABLE | CHAOTIC |
| CYCLIC | CHAOTIC |
| CHAOTIC | STABLE |

**Твердження 7.1 (недосяжність класичного виключеного третього).**

```
METASTABLE ∨ ¬METASTABLE = METASTABLE ∨ CHAOTIC = METASTABLE ≠ STABLE
```

Закон виключеного третього не виконується — Ω_SUBIT є моделлю інтуїціоністської, а не класичної (булевої) логіки.

## 8. Категорія SUBIT

**Означення 8.1 (об'єкти).** Об'єктом категорії SUBIT є система X = (S_X, ℛ_X, F_X, g_X), де S_X ⊆ S₀ (у цій Частині; S_X ⊆ S_∞ у Частині IV), ℛ_X ⊆ ℛ, з аксіомою замкненості F_X(S_X × ℛ_X) ⊆ S_X × ℛ_X.

**Означення 8.2 (морфізми).** Морфізм φ: X → Y — пара відображень φ = (φ_S, φ_ℛ), що задовольняє умову динамічної сумісності:

```
φ_S( π_S( F_X(ŝ) ) ) = π_S( F_Y( φ_S(π_S(ŝ)), φ_ℛ(π_ℛ(ŝ)) ) )
```

тобто застосування еволюції з наступним відображенням дає той самий результат, що й відображення з наступною еволюцією. Композиція та тотожні морфізми визначаються покомпонентно; асоціативність і нейтральність тотожного морфізма спадкуються безпосередньо від властивостей композиції функцій. SUBIT — категорія.

**Спеціальні об'єкти й конструкції:**

- *Термінальний об'єкт* **1**: S₁ = {∗}, ℛ₁ = {id}. Для будь-якого X існує рівно один морфізм X → 1.
- *Добуток* X × Y: S_{X×Y} = S_X × S_Y, ℛ_{X×Y} = ℛ_X × ℛ_Y, F_{X×Y}((s₁,s₂),(ρ₁,ρ₂)) = (F_X(s₁,ρ₁), F_Y(s₂,ρ₂)).
- *Експоненціал* Yˣ: S_{Yˣ} — множина динамічно сумісних відображень S_X → S_Y, з оператором евалюації F_{Yˣ}(φ)(s) = F_Y(φ(F_X⁻¹(s))).

**Зауваження про застосовність експоненціала.** Наведена конструкція спирається на існування оберненого відображення F_X⁻¹, тобто застосовна лише до об'єктів X із оборотною динамікою. Для об'єктів із необоротною динамікою (типовий випадок дисипативних систем) ця конструкція не визначена, і статус декартової замкненості категорії SUBIT у повному обсязі є відкритим питанням (розділ 17); вона встановлена лише для повної підкатегорії об'єктів з оборотним F.

## 9. SUBIT як proto-topos

Категорія є топосом, якщо вона має (T1) скінченні ліміти, (T2) експоненціали й (T3) субоб'єктний класифікатор. SUBIT задовольняє (T1) безумовно й (T2) на підкатегорії оборотних об'єктів (розділ 8). Умова (T3) виконується в динамічній, а не класичній формі: замість двозначного Ω = {⊤, ⊥} — Ω_SUBIT = {STABLE, METASTABLE, CYCLIC, CHAOTIC}, що за розділом 7 утворює алгебру Гейтінга, а не булеву алгебру. SUBIT є **proto-topos**: категорія, що прагне задовольнити умови топосу з двома застереженнями — умовним T2 і нестандартним, некласичним Ω замість строгого T3. Чи є SUBIT топосом у повністю формальному категоріальному сенсі, залишається відкритим питанням (розділ 17).

## 10. Динамічна теорія типів

**Судження.** Γ ⊢ t : A @ τ означає: у контексті Γ стан t має тип A на фазі еволюції τ. Тип A трактується не як статична класифікація, а як клас траєкторій зі спільним режимом стабільності: A = {ŝ | stability_class(ŝ) = mode_A}.

**Правила виведення:**

```
Рефлексивність:    ───────────────────
                   Γ, x:A@τ ⊢ x : A@τ

Еволюція типу:     Γ ⊢ t:A@τ     F(A) ⊆ B
                   ──────────────────────────
                   Γ ⊢ F(t) : B @ (τ+1)

Стабільний тип:    Γ ⊢ t:A@τ     F(A) = A
                   ──────────────────────────
                   Γ ⊢ t : □A @ τ

Потенційний тип:   Γ ⊢ t:A@τ     ∃k: Fᵏ(A) ⊆ B
                   ─────────────────────────────
                   Γ ⊢ t : ◇B @ τ

Циклічний тип:     Γ ⊢ t:A@τ     ∃k>1: Fᵏ(A) = A
                   ──────────────────────────────
                   Γ ⊢ t : ◯A @ τ
```

Умова циклічного типу обмежена k>1, узгоджено з означенням модальності ◯ у розділі 11 і з означенням CYCLIC у розділі 6.1: це відокремлює "справжню" періодичність від тривіального випадку нерухомої точки, який уже покривається стабільним типом.

**Атракторна рівність.** Замість класичної ідентичності вводиться відношення s ~_F t ⟺ ∃k: Fᵏ(s) = Fᵏ(t): два стани еквівалентні, якщо їхні траєкторії зрештою збігаються.

## 11. Модальна логіка

| Модальність | Визначення | Змістовний сенс |
|---|---|---|
| □A | F(A) = A | стабільна (необхідна) істина: A — точний F-інваріант |
| ◇A | ∃k ≥ 0: Fᵏ(s) ∈ A | потенційна стабілізація: існує момент входження в A |
| ◯A | ∃k > 1: Fᵏ(s) ∈ A і Fᵏ(A) = A | справжнє циклічне повернення (з періодом, більшим за тривіальний) |

Модальність ◯ визначена з умовою k>1: це — свідомий вибір, що відокремлює її від □ (яка відповідає випадку k=1) і робить наступну аксіому змістовною, а не тавтологічною.

**Аксіоми:**

```
(M1)  □A → A
(M2)  □A → □□A
(M3)  □(A → B) → (□A → □B)
(M4)  ◇A ↔ ¬□¬A
(M5)  ◯A → ◇A
(M6)  □A → ◯A
(M7)  ◯◯A ↔ ◯A
(M8)  □A ∧ □B → □(A ∧ B)
```

*Обґрунтування M6.* Якщо F(A)=A (тобто □A), то застосувавши F ще раз, F²(A)=F(A)=A — отже, ∃k=2>1 такий, що Fᵏ(A)=A, тобто ◯A виконується. Це — змістовний, хоч і короткий, висновок: він використовує k=2, відмінний від k=1, що визначає □A, тому M6 не зводиться до простого переозначення.

Не виконуються ◇A ∨ ◇¬A і □A ∨ □¬A. Відповідність класифікатору Ω: stable ↔ □A; metastable ↔ A ∧ ¬□A; cyclic ↔ ◯A ∧ ¬□A; chaotic ↔ ¬◇A.

## 12. Внутрішня мова, універсальний об'єкт, принцип симуляції

**Внутрішня мова.** Примітивні терми: s, t, u — терми типу State; ρ, σ — терми типу Rule; p, q — терми типу Prop. Конструктори: who(s), where(s), when(s) — проекції на координати стану; rule(ŝ) — витягування правила зі стану; evolve(ŝ) = F(ŝ). Пропозиційні конструктори: stable(p), reaches(s, A), cycle(A), morphism(φ, X, Y), iso(φ).

**Універсальний об'єкт.** U = (S₀ × ℛ*, F*, g*), де ℛ* — коди всіх допустимих локальних правил, F* — інтерпретатор, що приймає код (s, ρ) системи X і обчислює f_ρ(s), g* — оператор переписування правил. Для будь-якого X ∈ SUBIT постулюється існування морфізму φ_X: U → X, що робить U внутрішнім універсальним інтерпретатором категорії — структурний аналог λ-числення та універсальної машини Тюрінга. Конструкція кодування encode_X, encode_R подається на рівні принципу; повне доведення динамічної сумісності кодування для довільного X виходить за межі цієї специфікації.

**Принцип симуляції.** Будь-який скінченний автомат (Q, δ) вкладається в SUBIT⁺: обираємо ін'єкцію ι: Q → S₀; для кожного символу a ∈ Σ будуємо правило ρ_a ∈ ℛ таке, що f_{ρ_a}(ι(q)) = ι(δ(q, a)); визначаємо метаеволюцію g: ρ_a ↦ ρ_{наступний символ}. Це вкладення зберігає стани, переходи й прийняття. Наслідок: SUBIT⁺ є умовно універсальною симуляційною системою, де універсальність досягається через внутрішню самореференцію, а не через нескінченність множини станів.

# ЧАСТИНА IV. SUBIT_∞ — рекурсивний нескінченний простір

## 13. Простір станів S_∞ як дерева з мітками

**Означення 13.1.** Рекурсивний простір станів визначається як найбільша коалгебраїчна нерухома точка (кінцева коалгебра) функтора `Φ(X) = A ⊔ X³` на категорії множин:

```
S_∞ = νX. (A ⊔ X × X × X)
```

з відповідним відображенням-структурою (out-map)

```
out : S_∞ → A ⊔ S_∞³
```

Цей функтор має два конструктори: **лист**, помічений елементом алфавіту A, і **внутрішній вузол** — трійка піддерев. Явно: S_∞ — множина всіх дерев (скінченних і нескінченних, глибини не більше ω), у яких кожен вузол або є листом із міткою з A, або є внутрішнім вузлом із рівно трьома піддеревами; ототожнення за бісимуляцією (у сенсі антифундаційної аксіоми, Aczel, 1988) допускає нескінченні й циклічні, самореферентні структури серед внутрішніх вузлів. Елемент s ∈ S_∞ — це або s = a для деякого a ∈ A (лист), або s = (w, x, y) для w, x, y ∈ S_∞ (вузол).

**Чому потрібен доданок A.** Функтор без базового (листкового) конструктора, Φ'(X) = X³, має кінцеву коалгебру, ізоморфну одноелементній множині (доведення — Додаток B): без жодної мітки немає жодної ознаки, за якою можна відрізнити одне нескінченне саморозгортання дерева від іншого, і всі вони ототожнюються бісимуляцією в єдину точку. Додавання підсумовуваного компонента A вносить генуїнну розрізняльність на кожному рівні розгортання: тепер два дерева бісимулярні лише тоді, коли вони структурно й помітково тотожні на кожній глибині, і з чотирма різними мітками існує (зокрема) 4³ = 64 попарно нерізних дерев глибини рівно 1.

**Вкладення S₀ ⊂ S_∞.** Означимо

```
S₀ := { (a, b, c) ∈ S_∞ | a, b, c ∈ A ⊂ S_∞ }
```

де кожен a ∈ A вкладається як лист (одновузлове дерево з міткою a) через канонічне вкладення A ↪ S_∞. Тоді S₀ — це підмножина S_∞, що складається з дерев глибини рівно 1 (внутрішній вузол, три листкові нащадки), і |S₀| = |A|³ = 64, точно узгоджено з Частиною I. **SUBIT-64 є скінченною апроксимацією глибини 1 об'єкта S_∞.** Дерева глибини більшої за 1 відповідають випадку, коли одна з координат — наприклад, WHO ("спільнота") — сама вимагає внутрішнього опису через власні WHO/WHERE/WHEN (підструктуру з чотирма атомарними чи, знову ж, розгорнутими значеннями), що й було вихідним мотивом уведення рекурсії.

**Простір правил.** У загальному випадку

```
ℛ = { f : S_∞ → S_∞ | f обчислювана в розширеному сенсі (задана скінченним описом) }
```

На відміну від Частини II, ℛ тут може бути нескінченною множиною. Крім того, сам S_∞ (на відміну від S₀) є нескінченною множиною вже за побудовою (для |A| ≥ 1 існують дерева необмеженої глибини). Разом це знімає обмеження Твердження 5.1: принцип Діріхле більше не гарантує зрештової періодичності жодної траєкторії, і генуїнно неперіодична (chaotic у строгому сенсі) динаміка стає математично можливою.

## 14. Динаміка й категорія на рівні S_∞

Оператор еволюції

```
F : S_∞ × ℛ → S_∞ × ℛ
F(s, ρ) = ( f_ρ(s), g(ρ, s) )
```

формально ідентичний до Частини II, але тепер визначений на нескінченному S_∞. Усі означення розділів 6–11 (класифікатор Ω, алгебра, типи, модальна логіка) переносяться дослівно із заміною S₀ на S_∞: жодне з них по суті не спиралося на скінченність носія.

**Множина атракторів.** Fix(F) = {ŝ ∈ S_∞ × ℛ | F(ŝ) = ŝ} є найменшою STABLE-множиною відносно F.

**Категорія.** Означення 8.1–8.2 переносяться дослівно із заміною S_X ⊆ S₀ на S_X ⊆ S_∞. Застереження щодо оборотності F_X в конструкції експоненціала (розділ 8) не є артефактом скінченності й лишається чинним і на цьому рівні.

**Універсальний об'єкт (повна версія).** U = (S_∞ × ℛ*, F*, g*); для будь-якого X ∈ SUBIT постулюється морфізм φ_X: U → X через кодування encode_X: S_X → S_∞, encode_R: ℛ_X → ℛ*, за тим самим застереженням щодо повноти доведення, що й у розділі 12.

## 15. Семантична ультраметрика d_Ω

**Означення 15.1 (перша розбіжність).** Для двох розширених станів ŝ, t̂ ∈ S_∞ × ℛ визначимо

```
n₀(ŝ, t̂) := min{ n ≥ 0 : Ω(Fⁿŝ) ≠ Ω(Fⁿt̂) },   якщо таке n існує
```

і покладемо

```
d_Ω(ŝ, t̂) := 2^(−n₀(ŝ,t̂)),  якщо n₀ визначено;   d_Ω(ŝ, t̂) := 0,  якщо Ω(Fⁿŝ) = Ω(Fⁿt̂) для всіх n ≥ 0
```

Тобто d_Ω вимірює горизонт узгодженості — перший крок еволюції, на якому дві траєкторії починають класифікуватися по-різному за Ω.

**Теорема 15.1 (властивості ультраметрики).** Функція d_Ω задовольняє:

1. d_Ω(ŝ, t̂) = 0 тоді й лише тоді, коли Ω(Fⁿŝ) = Ω(Fⁿt̂) для всіх n ≥ 0;
2. d_Ω(ŝ, t̂) = d_Ω(t̂, ŝ);
3. сильна нерівність трикутника d_Ω(ŝ, û) ≤ max(d_Ω(ŝ, t̂), d_Ω(t̂, û)).

*Доведення (3).* Нехай n₁ = n₀(ŝ, t̂), n₂ = n₀(t̂, û). Для всіх n < min(n₁, n₂) маємо Ω(Fⁿŝ) = Ω(Fⁿt̂) і Ω(Fⁿt̂) = Ω(Fⁿû), звідки за транзитивністю рівності Ω(Fⁿŝ) = Ω(Fⁿû). Отже, n₀(ŝ, û) ≥ min(n₁, n₂), звідки d_Ω(ŝ, û) ≤ max(d_Ω(ŝ, t̂), d_Ω(t̂, û)). ∎

**Зауваження (псевдометричність).** Властивість (1) показує, що d_Ω(ŝ, t̂) = 0 не тягне за собою ŝ = t̂: два різні розширені стани можуть мати тотожну, назавжди узгоджену Ω-траєкторію. d_Ω, строго кажучи, є псевдоультраметрикою на S_∞ × ℛ; вона стає справжньою ультраметрикою на факторпросторі (S_∞ × ℛ)/~_Ω, де ~_Ω ототожнює точки з однаковою нескінченною Ω-послідовністю.

**Теорема 15.2 (нульвимірність).** Простір ((S_∞ × ℛ)/~_Ω, d_Ω) є тотально незв'язним: кожна відкрита куля одночасно є замкненою множиною, топологія — нульвимірна.

**Інтерпретаційне зауваження.** d_Ω дає кількісну міру того, наскільки швидко дві конкуруючі гіпотези розходяться в передбаченнях: n₀ — перший крок еволюції, на якому вони починають давати різні Ω-передбачення.

## 16. Метатеоретичні властивості

**Несуперечність.** У скінченній апроксимації (Частини I–III) усі аксіоми виконуються в скінченній моделі. Для повного S_∞ несуперечність спадкує від коректності побудови кінцевої коалгебри функтора A ⊔ X³ (Додаток B), за умови, що ℛ складається зі справді коректно визначених обчислюваних функцій.

**Аналогія з неповнотою.** Якщо ℛ достатньо багатий, щоб містити правила самоопису системи, правдоподібно очікувати — за аналогією з теоремами Гьоделя — існування тверджень внутрішньої мови, істинних (F(P) = P), але не виведених синтаксично засобами самої системи. Це евристична аналогія, а не доведена теорема: строге кодування арифметики всередині SUBIT-∞ виходить за межі цієї специфікації.

**Ієрархія виразності:**

| Рівень | Додає | Головне обмеження |
|---|---|---|
| SUBIT-64 | статичний алфавіт 64 станів | відсутня динаміка |

## 17. Відкриті питання

- Чи існує конструкція експоненціала, застосовна до об'єктів із необоротною динамікою F_X, що робить категорію SUBIT-∞ декартово замкненою в повному обсязі?
- Чи є Ω_SUBIT дійсно внутрішнім субоб'єктним класифікатором у строгому категоріальному сенсі?
- Чи можна строго закодувати арифметику всередині SUBIT_∞ так, щоб аналогія з неповнотою (розділ 16) стала доведеною теоремою?
- **Гіпотеза фрактальної межі.** Чи утворює множина правил ρ, для яких траєкторія фіксованого s₀ є CHAOTIC, множину дробової Хаусдорфової розмірності відносно природної топології на ℛ?
- **Гіпотеза нерухомої точки інтерпретації.** Чи існує розширений стан ŝ* такий, що F(ŝ*) = ŝ* для довільної достатньо багатої ℛ?

# ЧАСТИНА V. Застосування

## 18. Епістемологічний статус і протокол застосування

### 18.1 Природа формальних результатів цієї специфікації

Усі теореми й твердження Частин I–IV є твердженнями про саму нотацію — про те, як певні символи й функції співвідносяться одне з одним за визначенням. Жодне з них не встановлює й не може встановити, що будь-яка конкретна емпірична система, до якої застосовують апарат SUBIT-∞, дійсно еволюціонує за правилом ρ, яке дослідник обирає для її опису, або що присвоєння конкретній емпіричній множині станів певного Ω-класу є істинним у сенсі відповідності реальності, а не інтерпретаційним судженням, підігнаним під уже наявні дані.

### 18.2 Функція апарату в дослідницькій роботі

SUBIT-∞ функціонує як інструмент структурування гіпотез, а не як їх джерело чи підтвердження. Його користь — не в тому, щоб "довести" щось про світ через властивості формалізму, а в тому, щоб:

- змусити явно сформулювати конкретний причинний механізм (ρ) там, де наративний виклад залишає його імпліцитним;
- дати компактну мову для розрізнення типів переходу, яка спрямовує пошук конкретної емпіричної ознаки;
- дати кількісну (через d_Ω) або якісну (через Ω) мову для порівняння того, наскільки й де саме розходяться передбачення конкуруючих гіпотез.

### 18.3 Протокол застосування

1. Визначити емпіричну систему та дослідницьке питання.
2. Сформулювати конкуруючі гіпотези як явні, відмінні одне від одного правила ρ₁, ρ₂, …
3. Для кожного ρᵢ вивести емпіричне передбачення, відмінне від передбачень інших гіпотез.
4. Зібрати або розглянути наявні першоджерельні дані, що підтверджують чи спростовують кожне передбачення.
5. Лише після кроку 4 — за потреби — присвоїти Ω-клас переходу як компактний підсумковий ярлик уже здобутого емпіричного висновку. Ω-клас ніколи не замінює крок 4.
6. У викладі результатів явно розрізняти: (а) формально доведене в самій нотації; (б) підтверджене конкретним емпіричним джерелом; (в) інтерпретаційна пропозиція дослідника.

## Додаток B. Коректність конструкції S_∞

**Лема B.1.** Кінцева коалгебра функтора Φ'(X) = X × X × X на категорії множин ізоморфна одноелементній множині: νX. X³ ≅ 1.

*Доведення.* Кінцеву коалгебру довільного функтора, що зберігає границі (зокрема, функтора-добутку Φ'(X)=X³, побудованого зі скінченних добутків), можна обчислити як границю термінальної послідовності 1 ← Φ'(1) ← Φ'²(1) ← …, де 1 — термінальний об'єкт категорії множин (одноелементна множина). Оскільки 1 — термінальний об'єкт, 1×1×1 ≅ 1 канонічно. Тому послідовність стабілізується на першому ж кроці: Φ'(1) = 1³ ≅ 1, Φ'²(1) ≅ 1, і так далі для всіх скінченних степенів. Границя стабільної послідовності дорівнює самій цій точці, тож νX.X³ ≅ 1. ∎

**Наслідок B.2.** Будь-яка спроба вкласти алфавіт A потужності більшої за 1 у νX.X³ як множину "листків" (наприклад, ототожнюючи a ∈ A з розв'язком рівняння s=(s,s,s)) зазнає невдачі: усі такі розв'язки бісимулярні між собою (кожен із них розгортається в єдине, структурно ідентичне нескінченне дерево без жодної розрізняльної мітки), а отже, після факторизації за бісимуляцією ототожнюються в одну й ту саму точку кінцевої коалгебри. Це — не недолік конкретного способу вкладення, а точна відповідність Лемі B.1: коли *весь* простір станів є кінцевою коалгеброю функтора X³, у ньому просто немає місця для чотирьох різних "констант".

**Лема B.3.** Кінцева коалгебра функтора Φ(X) = A ⊔ X³ (Означення 13.1) не вироджується в одноелементну множину, якщо |A| > 1.

*Доведення (ескіз).* Термінальна послідовність для Φ: X₀ = 1, X₁ = A ⊔ 1³ = A ⊔ 1, X₂ = A ⊔ (A⊔1)³, … Оскільки на кожному кроці зберігається копія A як окрема, нескорочувана компонента коопродукту (додавання не "поглинається" термінальним об'єктом так, як це відбувається з добутком у Лемі B.1: X ⊔ 1 ≇ 1 для |X|>0), послідовність не стабілізується на одноелементній множині; її границя містить принаймні |A| попарно різних елементів уже на першому нетривіальному рівні (самі елементи A, вкладені як листки). Отже, S_∞ = νX.(A⊔X³) містить принаймні |A|=4 різних точки (а насправді — незліченно багато дерев довільної глибини та структури), і зокрема містить S₀ = A³ як підмножину дерев глибини 1, |S₀|=64, точно узгоджено з Частиною I. ∎

Це — формальне обґрунтування того, чому Означення 13.1 використовує саме Φ(X)=A⊔X³, а не Φ'(X)=X³: перший функтор має "базовий випадок" (лист), який зупиняє вироджене колапсування в точку, властиве другому.

## Підсумкова формула

```
SUBIT-∞ = ( S_∞, ℛ, F, g, Ω, d_Ω, U, ℒ ),   S_∞ = νX.(A ⊔ X × X × X)
```

де S_∞ — рекурсивний простір дерев із мітками з A, що містить S₀ = A³ (|S₀| = 64) як вкладену скінченну апроксимацію глибини 1; ℛ — простір внутрішніх правил еволюції; F — оператор динаміки; g — оператор метадинаміки; Ω — динамічний класифікатор стабільності, що утворює алгебру Гейтінга на чотирьох значеннях; d_Ω — семантична ультраметрика за принципом першої розбіжності; U — універсальний об'єкт-інтерпретатор; ℒ — внутрішня мова динамічної теорії типів і модальної логіки.

**Центральна теза.** Правило належить стану. Істина визначається стабільністю: F(P) = P. Відстань між траєкторіями вимірюється горизонтом їхньої першої розбіжності. Категорія прагне до декартової замкненості на підкатегорії оборотних об'єктів. Простір станів — дерево з мітками, а не немарковане дерево, і саме мітки роблять цей простір нетривіальним.

**Центральне методологічне положення.** Формальна коректність цієї нотації не переносить сама по собі жодного емпіричного змісту на будь-яку конкретну систему, описану її мовою: висновок про те, що щось у світі є "stable" чи "chaotic", завжди залишається інтерпретаційним кроком дослідника, який потребує незалежного емпіричного обґрунтування.

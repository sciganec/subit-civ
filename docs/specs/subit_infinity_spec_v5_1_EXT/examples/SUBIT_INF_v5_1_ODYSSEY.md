# SUBIT-ODYSSEY

## Формальна специфікація динамічної системи фільму «Одіссея» (2026)

Версія 1.0

---

## Анотація

SUBIT-ODYSSEY — формальна модель сюжетно-символічної динаміки фільму «Одіссея» Крістофера Нолана, побудована на основі специфікації SUBIT-∞. Система описує фільм як самореферентну динамічну систему, у якій:

- простір станів S₀ кодує архетипні ситуації (WHO × WHERE × WHEN);
- простір правил ℛ кодує типи сюжетної логіки (війна, подорож, випробування, забуття, повернення, справедливість);
- оператор еволюції F описує перехід між сценами/епізодами;
- класифікатор стабільності Ω описує стабільність/циклічність/хаотичність сюжетних підсистем;
- нелінійна оповідь (бард, фрагментарність, флешбеки) трактується як метаеволюція правила g(ρ, s).

Специфікація має чотири рівні:

SUBIT-64ᴼᴰ ⊂ SUBIT⁺ᴼᴰ ⊂ SUBIT-TOPOSᴼᴰ ⊂ SUBIT-∞ᴼᴰ

де кожен рівень додає новий шар структури до попереднього.

# ЧАСТИНА I. SUBIT-64ᴼᴰ — алфавіт станів «Одіссеї»

## 1. Алфавіт примітивів

В основі системи лежить скінченна множина примітивних маркерів потужності 4 для кожної з трьох осей.

### 1.1. Вісь WHO (хто в фокусі)

A_WHO = { ME, WE, YOU, THEY }

Інтерпретація для «Одіссеї»:

- ME = Одіссей (суб’єкт-герой, центр оповіді).
- WE = команда Одіссея / греки / супутники.
- YOU = Пенелопа, Телемах, Ітака (той, до кого повертаються).
- THEY = боги, женихи, чудовиська, зовнішні сили.

### 1.2. Вісь WHERE (просторова орієнтація)

A_WHERE = { EAST, SOUTH, WEST, NORTH }

Інтерпретація:

- EAST = Троїда, схід, війна.
- SOUTH = Середземномор’я, острови пригод (Еея, Огігія, Тринакія, земля циклопів).
- WEST = Ітака, дім, захід, «останній берег».
- NORTH = підземний світ (Некуія), незвідане, метафізичний простір.

### 1.3. Вісь WHEN (часовий модус)

A_WHEN = { SPRING, SUMMER, AUTUMN, WINTER }

Інтерпретація:

- SPRING = початок, вирушення, надія.
- SUMMER = війна, розквіт сили, дія.
- AUTUMN = повернення, втрата, підсумок.
- WINTER = забуття, стагнація (Каліпсо), смерть/суд.

### 1.4. Бітна реалізація

Кожне значення кодується двома бітами (bigram = b₁b₂):

- WHO:
  - 10 → ME
  - 11 → WE
  - 01 → YOU
  - 00 → THEY
- WHERE:
  - 10 → EAST
  - 11 → SOUTH
  - 01 → WEST
  - 00 → NORTH
- WHEN:
  - 10 → SPRING
  - 11 → SUMMER
  - 01 → AUTUMN
  - 00 → WINTER

---

## 2. Простір станів S₀

Означення 2.1. Простір станів SUBIT-64ᴼᴰ визначається як:

S₀ = A_WHO × A_WHERE × A_WHEN  
|S₀| = 4³ = 64

Кожен стан — трійка:

s = (α, β, γ), де α ∈ A_WHO, β ∈ A_WHERE, γ ∈ A_WHEN.

Стан кодується 6-бітним словом:

b₁b₂b₃b₄b₅b₆, де:

- b₁b₂ — WHO,
- b₃b₄ — WHERE,
- b₅b₆ — WHEN.

### 2.1. Гексаграмна нотація

Розбивши 6-бітний код на дві тригами:

- Lower Trigram = b₁b₂b₃ (WHO + частково WHERE),
- Upper Trigram = b₄b₅b₆ (WHERE + WHEN),

кожному стану можна зіставити унікальну гексаграму І-Цзін. У SUBIT-ODYSSEY ця нотація використовується:

- як компактний індекс стану;
- як основа для нумерації епізодів (наприклад, «епізод Hᵢ» = гексаграма i).

# ЧАСТИНА II. SUBIT⁺ᴼᴰ — скінченна самореферентна динаміка сюжету

## 4. Простір правил ℛ

Означення 4.1. Простір правил еволюції на цьому рівні — скінченна множина:

ℛ = { ρ₁, ρ₂, …, ρₙ }, ρᵢ : S₀ → S₀

Для SUBIT-ODYSSEY визначаємо такі базові правила:

- ρ_war = правило війни (Троянська війна, бійка з женихами).
- ρ_voyage = правило подорожі (море, переміщення між островами).
- ρ_trial = правило випробування (циклоп, сирени, Скілла/Харибда, бик Геліоса).
- ρ_forget = правило забуття / стагнації (Каліпсо, лотос).
- ρ_return = правило повернення (рух до Ітаки, розпізнавання).
- ρ_justice = правило відновлення порядку / покари (вбивство женихів, суд).
- ρ_prophecy = правило пророцтва / підземного світу (Тіресій, Агамемнон).
- ρ_narration = правило оповіді (бард, нелінійна структура, флешбеки).

Кожне ρᵢ — це функція S₀ → S₀, що описує, як змінюється стан під дією даного типу сюжетної логіки.

---

## 5. Розширений стан ŝ = (s, ρ)

Означення 5.1. Розширеним станом називається пара:

ŝ = (s, ρ) ∈ S₀ × ℛ

де ρ — активне правило еволюції, що належить самому стану.

### 5.1. Приклади розширених станів

- Троянська війна: ŝ_war = ((WE, EAST, SUMMER), ρ_war).
- Подорож морем: ŝ_voyage = ((WE, SOUTH, AUTUMN), ρ_voyage).
- Випробування з циклопом: ŝ_cyclops = ((WE, SOUTH, AUTUMN), ρ_trial).
- Каліпсо: ŝ_calypso = ((ME, SOUTH, WINTER), ρ_forget).
- Повернення на Ітаку: ŝ_return = ((ME, WEST, AUTUMN), ρ_return).
- Фінальний суд: ŝ_justice = ((ME, WEST, AUTUMN), ρ_justice).

---

## 6. Оператор еволюції F

Означення 6.1. Оператор еволюції визначається як:

F : S₀ × ℛ → S₀ × ℛ  
F(s, ρ) = ( f_ρ(s), g(ρ, s) )

де:

- f_ρ : S₀ → S₀ — застосування поточного правила до стану;
- g : ℛ × S₀ → ℛ — функція метаеволюції, що визначає, як правило змінюється.

### 6.1. Приклади переходів

1. Війна → Подорож:

F((WE, EAST, SUMMER), ρ_war) = ((WE, EAST, AUTUMN), ρ_voyage).

2. Подорож → Випробування:

F((WE, SOUTH, AUTUMN), ρ_voyage) = ((WE, SOUTH, AUTUMN), ρ_trial).

3. Випробування → Забуття:

F((ME, SOUTH, WINTER), ρ_trial) = ((ME, SOUTH, WINTER), ρ_forget).

4. Забуття → Повернення:

F((ME, SOUTH, WINTER), ρ_forget) = ((ME, SOUTH, AUTUMN), ρ_return).

5. Повернення → Справедливість:

F((ME, WEST, AUTUMN), ρ_return) = ((ME, WEST, AUTUMN), ρ_justice).

---

## 7. Траєкторія фільму

Означення 7.1. Траєкторією розширеного стану ŝ₀ називається послідовність:

τ(ŝ₀) = (ŝ₀, ŝ₁, ŝ₂, …), де ŝₙ₊₁ = F(ŝₙ).

Для «Одіссеї» можна виділити головну траєкторію Одіссея:

τ_Odysseus ≈  
(WE, EAST, SUMMER, ρ_war) →  
(WE, EAST, AUTUMN, ρ_voyage) →  
(WE, SOUTH, AUTUMN, ρ_trial) →  
(ME, NORTH, WINTER, ρ_prophecy) →  
(ME, SOUTH, WINTER, ρ_forget) →  
(ME, SOUTH, AUTUMN, ρ_return) →  
(ME, WEST, AUTUMN, ρ_justice).

Та паралельну траєкторію Ітаки:

τ_Ithaca ≈  
(YOU, WEST, SPRING, ρ_peace) →  
(YOU, WEST, AUTUMN, ρ_waiting) →  
(THEY, WEST, AUTUMN, ρ_suitors) →  
(ME, WEST, AUTUMN, ρ_justice).

### 7.1. Типи траєкторій

У скінченному просторі можливі:

- Атрактор (нерухома точка): F(ŝ) = ŝ.
- Орбіта (цикл довжини k > 1): Fᵏ(ŝ) = ŝ, і для всіх i < k: Fⁱ(ŝ) ≠ ŝ.
- Передперіодична траєкторія: існують m > 0, k ≥ 1 такі, що ŝ_{m+k} = ŝ_m, а ŝ₀,…,ŝ_{m−1} — без повторів.

У «Одіссеї»:

- Цикл випробувань (ρ_trial) — квазі-циклічна орбіта.
- Каліпсо — близька до атрактора / циклу великої довжини.
- Фінал Ітаки (ρ_justice) — атрактор (лад відновлено).

# ЧАСТИНА III. SUBIT-TOPOSᴼᴰ — категорія, класифікатор, типи

## 8. Класифікатор стабільності Ω

Означення 8.1. Клас стабільності множини P ⊆ S₀ × ℛ визначається так:

- STABLE якщо F(P) = P.
- METASTABLE якщо F(P) ⊊ P (строга власна підмножина).
- CYCLIC якщо існує мінімальне k > 1: Fᵏ(P) = P та F(P) ≠ P.
- CHAOTIC якщо F(P) ⊄ P та для всіх k > 1: Fᵏ(P) ≠ P.

### 8.1. Інтерпретація для «Одіссеї»

- STABLE:
  - Олімп / воля богів (якщо трактувати як зовнішнє правило).
  - Ітака до війни (ідеалізований дім).

- METASTABLE:
  - Ітака під час відсутності Одіссея: женихи поступово руйнують лад, Телемах дорослішає.

- CYCLIC:
  - Цикл випробувань у морі.
  - Острів Каліпсо (повторювані роки забуття).

- CHAOTIC:
  - Повний простір фільму P_full (Троя + море + підземний світ + Ітака + Олімп).

---

## 9. Алгебра Ω і порядок стабільності

На множині Ω = { STABLE, METASTABLE, CYCLIC, CHAOTIC } визначено лінійний порядок:

CHAOTIC < CYCLIC < METASTABLE < STABLE

Це можна інтерпретувати як ступінь упорядкованості сюжетної підсистеми:

- CHAOTIC — максимальна невизначеність, відсутність інваріантів.
- STABLE — повний інваріант, незмінний лад.

---

## 10. Категорія SUBIT-ODYSSEY

Означення 10.1. Категорія SUBIT-ODYSSEY визначається так:

- Об’єкти: множини станів P ⊆ S₀ × ℛ (наприклад, «Ітака», «Море», «Підземний світ»).
- Морфізми: функції φ : P → Q, сумісні з оператором F, тобто F_Q ∘ φ = φ ∘ F_P.

---

## 11. Динамічна теорія типів

Базові типи для «Одіссеї»:

- Hero — тип, що проходить через усі класи Ω (від CHAOTIC до STABLE).
- Home — тип, що прагне до STABLE (Ітака, Пенелопа).
- Gods — тип, що стабільний за побудовою (Олімп, доля).
- Monsters — тип, що реалізує CYCLIC / CHAOTIC (циклоп, сирени, Скілла/Харибда).
- Suitors — тип, що починається як METASTABLE і завершується як CHAOTIC (руйнування ладу, потім покара).

---

## 12. Модальна логіка

Вводяться модальні оператори:

- □φ — «φ необхідно» (φ випливає з динаміки).
- ◇φ — «φ можливо» (φ сумісне з динамікою).
- ¬φ — «φ неможливо» (φ суперечить динаміці).

Для «Одіссеї»:

- □(Одіссей повертається) — необхідно згідно з пророцтвом та структурою епосу.
- ◇(команда виживає) — можливо структурно, але не реалізується.
- ¬(Ітака залишається під владою женихів) — неможливо у довгостроковій динаміці.

# ЧАСТИНА IV. SUBIT-∞ᴼᴰ — рекурсивний нескінченний простір оповіді

## 13. Простір станів S_∞ як дерева епізодів

Означення 13.1. Простір станів S_∞ визначається як рекурсивна коіндуктивна структура дерев із мітками:

- Корінь = початок оповіді (Троя / бард).
- Гілки = епізоди / сцени.
- Мітки = стани ŝ ∈ S₀ × ℛ.

У «Одіссеї» Нолана це відповідає:

- нелінійній оповіді (флешбеки, перекази барда);
- вкладеним історіям (Троянська війна всередині розповіді про повернення).

---

## 14. Динаміка на рівні S_∞

На рівні S_∞ оператор F діє не тільки на стани, а й на структуру дерева:

- F може змінювати порядок гілок (монтаж, флешбеки).
- g(ρ, s) може змінювати правило оповіді ρ_narration:
  - змінювати точку зору (Одіссей / Пенелопа / бард),
  - змінювати часовий порядок (початок у кінці тощо).

---

## 15. Семантична ультраметрика d_Ω

Означення 15.1. Семантична відстань між станами визначається через їхні класи стабільності:

- d_Ω(s₁, s₂) = 0, якщо Ω(s₁) = Ω(s₂).
- d_Ω(s₁, s₂) = 2⁻ᵏ, де k — рівень ієрархії, на якому вони розрізняються.

Приклад:

- d_Ω(ŝ_war, ŝ_voyage) мала (обидва — динамічні стани, близькі за типом).

## 16. Метатеоретичні властивості

SUBIT-ODYSSEY є інструментом формулювання й структурування гіпотез про структуру фільму, а не емпіричною теорією реальності. Вона дозволяє:

- порівнювати різні монтажні стратегії;

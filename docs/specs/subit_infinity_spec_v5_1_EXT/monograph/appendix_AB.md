### A.2. Критичний коментар: комбінаторна семантика

Математично гексаграмна нотація є бієкцією між множиною S₀ (потужності 64) та множиною гексаграм І-Цзін (також потужності 64). Ця бієкція не зберігає жодної структури, окрім потужності: вона не є гомоморфізмом алгебр, не зберігає порядків, не комутує з оператором F. Її єдина функція — надати *компактний однозначний запис* 6-бітного слова.

З точки зору комбінаторики, гексаграми можна розглядати як елементи продукту {0,1}⁶, розбитого на два блоки по 3 біти (тригами). Триграма — це елемент {0,1}³, існує рівно 8 триграм. Гексаграма — пара триграм (нижня та верхня), існує 8² = 64 гексаграми. Відповідність між триграмою та лініями І-Цзін:
- 111 (☰) — три суцільні лінії (янь, тай чи)
- 000 (☷) — три перервані лінії (інь, туй чи)
- інші — комбінації

### A.3. Критичний коментар: культурна семантика та герменевтичний ризик

Кожна гексаграма І-Цзін має власне традиційне тлумачення, що сягає понад дві з половиною тисячі років. Наприклад:
- ䷀ (乾, qián) — «Творчість», «Небо», символ чистого янь
- ䷁ (坤, kūn) — «Підкорення», «Земля», символ чистого інь
- ䷂ (屯, zhūn) — «Скрута на початку», символ труднощів ініціації

Специфікація категорично заявляє, що «жодне додаткове тлумачення традиційної символіки триграм не є частиною формальної специфікації». Проте сама наявність цієї нотації створює *герменевтичний ризик*: читач, зустрівши символ ䷀, неминуче активує культурні асоціації, незважаючи на методологічну заборону.

Цей ризик є не логічним, а *прагматичним*. Він не впливає на формальну коректність, але впливає на *сприйняття* та *інтерпретацію* результатів. Дослідник, який повідомляє, що система перейшла «у стан ䷀», несвідомо передає коннотацію «творчості» або «небесного порядку», що може вплинути на аудиторію.

### A.4. Рекомендація

Для академічних застосувань, де культурна семантика є перешкодою, рекомендується використовувати нейтральну позиційну нотацію (наприклад, номери від 0 до 63 або 6-бітні слова). Гексаграмна нотація може бути збережена як історико-культурний коментар, але не як обов'язковий формальний елемент.

## Додаток B. Розширене доведення Леми B.3: невиродженість νX.(A ⊔ X³)

### B.1. Постановка задачі

Нехай A — скінченна множина, |A| ≥ 2. Розглянемо функтор Φ: Set → Set, визначений формулою:

Φ(X) = A ⊔ X³, де X³ = X × X × X.

**Твердження (Лема B.3).** Кінцева коалгебра νX.Φ(X) не є одноелементною множиною. Більш того, вона містить принаймні |A| попарно різних елементів, що відповідають листкам з мітками a ∈ A.

### B.2. Термінальна послідовність

Кінцеву коалгебру поліноміального функтора на Set можна побудувати як границю термінальної послідовності:

1 ← Φ(1) ← Φ²(1) ← Φ³(1) ← ... ← Φⁿ(1) ← ...

де 1 = {*} — термінальний об'єкт категорії Set (довільна одноелементна множина), а стрілки pₙ: Φⁿ⁺¹(1) → Φⁿ(1) визначаються індукцією:

- p₀: Φ(1) → 1 — єдиний можливий морфізм (константне відображення).
- pₙ₊₁ = Φ(pₙ): Φ(Φⁿ⁺¹(1)) → Φ(Φⁿ(1)).

Обчислимо перші члени послідовності:

**Крок 0:** Φ⁰(1) = 1 = {*}

**Крок 1:** Φ¹(1) = Φ(1) = A ⊔ 1³ = A ⊔ {(*,*,*)}

Позначимо єдиний елемент 1³ як •. Тоді:

Φ¹(1) = A ⊔ {•}

Це диз'юнктне об'єднання множини A та одноелементної множини {•}. Оскільки |A| ≥ 2, маємо |Φ¹(1)| = |A| + 1 ≥ 3.

**Крок 2:** Φ²(1) = Φ(Φ¹(1)) = A ⊔ (Φ¹(1))³

(Φ¹(1))³ = (A ⊔ {•})³ — множина всіх упорядкованих трійок елементів A ⊔ {•}.

Кількість елементів: |Φ²(1)| = |A| + (|A| + 1)³.

**Крок n (індукція):** Φⁿ⁺¹(1) = A ⊔ (Φⁿ(1))³.

### B.3. Нестабільність послідовності

**Лема.** Для всіх n ≥ 1 проекція pₙ: Φⁿ⁺¹(1) → Φⁿ(1) не є бієкцією.

*Доведення.* Розглянемо p₀: Φ(1) = A ⊔ {•} → 1. Це константне відображення, і |Φ(1)| = |A| + 1 > 1 = |1|, отже p₀ не є ін'єкцією.

Припустимо, що pₙ не є бієкцією для деякого n. Тоді |Φⁿ⁺¹(1)| > |Φⁿ(1)| (бо pₙ сюр'єктивна як термінальна проекція, але не ін'єктивна). Тоді:

|Φⁿ⁺²(1)| = |A| + |Φⁿ⁺¹(1)|³ > |A| + |Φⁿ(1)|³ = |Φⁿ⁺¹(1)|.

Отже, pₙ₊₁ також не є бієкцією. За індукцією, жодна проекція не є бієкцією. ∎

**Наслідок.** Послідовність не стабілізується: Φⁿ(1) ≇ Φⁿ⁺¹(1) для всіх n.

### B.4. Границя послідовності

Границя (limit) термінальної послідовності визначається як:

S̃_∞ = lim← Φⁿ(1) = { (x₀, x₁, x₂, ...) ∈ ∏ₙ Φⁿ(1) | ∀n: pₙ(xₙ₊₁) = xₙ }.

Елементи S̃_∞ — це послідовності (xₙ), узгоджені з проекціями. Канонічні проекції πₙ: S̃_∞ → Φⁿ(1) витягують n-й компонент.

**Лема.** |S̃_∞| > 1.

*Доведення.* Побудуємо принаймні два різні елементи S̃_∞. Нехай a₁, a₂ ∈ A, a₁ ≠ a₂ (такі існують, бо |A| ≥ 2).

Визначимо послідовність α⁽¹⁾ = (xₙ⁽¹⁾) індуктивно:
- x₀⁽¹⁾ = * ∈ 1
- x₁⁽¹⁾ = a₁ ∈ A ⊂ Φ(1)
- x₂⁽¹⁾ = a₁ ∈ A ⊂ Φ²(1) (де a₁ вкладається як листок)
- Загалом: xₙ⁽¹⁾ = a₁ для всіх n ≥ 1.

Перевіримо узгодженість: pₙ(xₙ₊₁⁽¹⁾) = pₙ(a₁). За визначенням, pₙ на компоненті A (якщо xₙ₊₁ ∈ A ⊂ Φⁿ⁺¹(1)) відображає a₁ в a₁ ∈ A ⊂ Φⁿ(1) (тотожно на листках). Отже, pₙ(xₙ₊₁⁽¹⁾) = a₁ = xₙ⁽¹⁾. Узгодженість виконується.

Аналогічно визначимо α⁽²⁾ з a₂. Оскільки a₁ ≠ a₂, маємо α⁽¹⁾ ≠ α⁽²⁾. Отже, |S̃_∞| ≥ 2. ∎

### B.5. Бісимуляція та кінцева коалгебра

Границя S̃_∞ є коалгеброю з відображенням-структурою γ: S̃_∞ → Φ(S̃_∞), побудованим за універсальною властивістю границі. Проте S̃_∞ ще не є *кінцевою* коалгеброю: вона може містити «зайві» елементи, що ототожнюються за бісимуляцією.

**Означення (бісимуляція).** Відношення R ⊆ S̃_∞ × S̃_∞ називається бісимуляцією, якщо для будь-якого (x, y) ∈ R:
- якщо γ(x) ∈ A (тобто x — листок), то γ(y) ∈ A і γ(x) = γ(y);
- якщо γ(x) = (x₁, x₂, x₃) ∈ S̃_∞³, то γ(y) = (y₁, y₂, y₃) ∈ S̃_∞³ і (xᵢ, yᵢ) ∈ R для всіх i = 1, 2, 3.

Кінцева коалгебра S_∞ = νX.Φ(X) отримується факторизацією S̃_∞ за найбільшою бісимуляцією.

**Лема.** Елементи α⁽¹⁾ та α⁽²⁾ (побудовані в B.4) не є бісимулярними.

*Доведення.* Для α⁽¹⁾ маємо γ(α⁽¹⁾) = a₁ ∈ A (листок). Для α⁽²⁾ маємо γ(α⁽²⁾) = a₂ ∈ A. Оскільки a₁ ≠ a₂, перша умова бісимуляції порушується: листки з різними мітками не можуть бути бісимулярними. ∎

**Наслідок.** В кінцевій коалгебрі S_∞ образи [α⁽¹⁾] та [α⁽²⁾] є різними елементами. Отже, |S_∞| ≥ |A| ≥ 2.

### B.6. Вкладення S₀

**Лема.** Множина S₀ = {(a, b, c) | a, b, c ∈ A} вкладається в S_∞ канонічно.

*Доведення.* Для кожного (a, b, c) ∈ S₀ побудуємо послідовність β = (yₙ):
- y₁ = (a, b, c) ∈ A³ ⊂ Φ¹(1)? Ні, бо Φ¹(1) = A ⊔ {•}. Потрібен інший підхід.

Коректніше: розглянемо елементи глибини 2. На кроці 2:

Φ²(1) = A ⊔ (A ⊔ {•})³.

Елемент (a, b, c) ∈ A³ ⊂ (A ⊔ {•})³ ⊂ Φ²(1). Визначимо послідовність:
- y₀ = *
- y₁ = • (єдиний елемент 1³)
- y₂ = (a, b, c) ∈ (A ⊔ {•})³
- y₃ = ?

Для n ≥ 2 визначимо yₙ₊₁ індуктивно як трійку (yₙ⁽ᵃ⁾, yₙ⁽ᵇ⁾, yₙ⁽ᶜ⁾), де yₙ⁽ᵃ⁾ — послідовність для a (тотожно a на всіх рівнях), і аналогічно для b, c.

Тоді проекція pₙ на yₙ₊₁ дає yₙ (за визначенням проекції на компоненти трійки). Отже, послідовність узгоджена. Вона представляє дерево глибини 1 з трьома листками a, b, c. Різні трійки (a,b,c) дають різні послідовності, і вони не бісимулярні (бо мають різні мітки на листках). Отже, S₀ вкладається в S_∞ зі збереженням потужності |S₀| = |A|³ = 64. ∎

### B.7. Висновок

Доведення завершено. Ключові кроки:
1. Термінальна послідовність для Φ(X) = A ⊔ X³ не стабілізується на одноелементній множині (на відміну від випадку Φ′(X) = X³).
2. Границя послідовності містить принаймні |A| різних послідовностей, що відповідають листкам з мітками a ∈ A.
3. Ці послідовності залишаються розрізненими в кінцевій коалгебрі за бісимуляцією, оскільки листки з різними мітками не можуть бути бісимулярними.
4. Множина дерев глибини 1 (S₀) вкладається в S_∞ канонічно.

Це обґрунтовує використання функтора Φ(X) = A ⊔ X³ замість Φ′(X) = X³ у конструкції S_∞. ∎

## Додаток D. Повний перелік формул специфікації з індексацією

### Частина I. SUBIT-64

**Означення 1.1 (Алфавіт).**
A_WHO = {ME, WE, YOU, THEY}
A_WHERE = {EAST, SOUTH, WEST, NORTH}
A_WHEN = {SPRING, SUMMER, AUTUMN, WINTER}
𝔸 = {T, F, B, N}

**Означення 1.2 (Білаттис).**
F <ₜ N <ₜ T, F <ₜ B <ₜ T
N <ᵢ F <ᵢ B, N <ᵢ T <ᵢ B

**Означення 2.1 (Простір станів).**
S₀ = A_WHO × A_WHERE × A_WHEN = 𝔸³
\|S₀\| = 4³ = 64

**Кодування.**
s = (α, β, γ) ↦ b₁b₂b₃b₄b₅b₆
b₁b₂ кодує WHO, b₃b₄ — WHERE, b₅b₆ — WHEN

### Частина II. SUBIT⁺

**Означення 3.1 (Простір правил).**
ℛ = {ρ₁, ρ₂, …, ρₙ}, ρᵢ : S₀ → S₀

**Означення 3.2 (Розширений стан).**
ŝ = (s, ρ) ∈ S₀ × ℛ

**Означення 4.1 (Оператор еволюції).**
F : S₀ × ℛ → S₀ × ℛ
F(s, ρ) = ( f_ρ(s), g(ρ, s) )

**Аксіома 4.1 (Детермінованість).**
F — тотальна функція.

**Твердження 5.1 (Скінченна періодичність).**
∃m ≥ 0, k ≥ 1: ŝ_{m+k} = ŝ_m

**Алгоритм 5.1 (Класифікація).**
Вхід: ŝ₀, N_max
visited ← ∅
для n = 0, …, N_max:
    якщо ŝ_n ∈ visited: повернути цикл
    додати ŝ_n до visited
    ŝ_{n+1} ← F(ŝ_n)
повернути "цикл довший за N_max"

### Частина III. SUBIT-TOPOS

**Означення 6.1 (Класифікатор Ω).**
STABLE  ⟺ F(P) = P
METASTABLE ⟺ F(P) ⊊ P
CYCLIC  ⟺ ∃ мінімальне k > 1: Fᵏ(P) = P, F(P) ≠ P
CHAOTIC ⟺ F(P) ⊄ P ∧ ∀k > 1: Fᵏ(P) ≠ P

**Означення 6.2 (Семантична істина).**
P істинне ⟺ F(P) = P

**Означення 7 (Алгебра Ω).**
CHAOTIC < CYCLIC < METASTABLE < STABLE
∧ = min, ∨ = max
a → b = ⊤, якщо a ≤ b; інакше b
¬a = a → ⊥

**Твердження 7.1 (Невиконання ВЕТ).**
METASTABLE ∨ ¬METASTABLE = METASTABLE ≠ STABLE

**Означення 8.1 (Об'єкти категорії).**
X = (S_X, ℛ_X, F_X, g_X), F_X(S_X × ℛ_X) ⊆ S_X × ℛ_X

**Означення 8.2 (Морфізми).**
φ = (φ_S, φ_ℛ): X → Y
φ_S(π_S(F_X(ŝ))) = π_S(F_Y(φ_S(π_S(ŝ)), φ_ℛ(π_ℛ(ŝ))))

**Конструкції.**
1: S₁ = {*}, ℛ₁ = {id}
X × Y: S_{X×Y} = S_X × S_Y, ℛ_{X×Y} = ℛ_X × ℛ_Y
Yˣ: F_{Yˣ}(φ)(s) = F_Y(φ(F_X⁻¹(s)))

**Означення 10 (Динамічна теорія типів).**
Γ ⊢ t : A @ τ

**Правила виведення.**
Рефлексивність: Γ, x:A@τ ⊢ x : A@τ
Еволюція: Γ ⊢ t:A@τ, F(A) ⊆ B ⊢ Γ ⊢ F(t) : B @ (τ+1)
Стабільний: Γ ⊢ t:A@τ, F(A) = A ⊢ Γ ⊢ t : □A @ τ
Потенційний: Γ ⊢ t:A@τ, ∃k: Fᵏ(A) ⊆ B ⊢ Γ ⊢ t : ◇B @ τ
Циклічний: Γ ⊢ t:A@τ, ∃k>1: Fᵏ(A) = A ⊢ Γ ⊢ t : ◯A @ τ

**Означення 11 (Модальна логіка).**
□A ⟺ F(A) = A
◇A ⟺ ∃k ≥ 0: Fᵏ(s) ∈ A
◯A ⟺ ∃k > 1: Fᵏ(s) ∈ A ∧ Fᵏ(A) = A

**Аксіоми M1–M8.**
(M1) □A → A
(M2) □A → □□A
(M3) □(A → B) → (□A → □B)
(M4) ◇A ↔ ¬□¬A
(M5) ◯A → ◇A
(M6) □A → ◯A
(M7) ◯◯A ↔ ◯A
(M8) □A ∧ □B → □(A ∧ B)

**Означення 12 (Внутрішня мова).**
Примітивні терми: s, t, u : State; ρ, σ : Rule; p, q : Prop
Конструктори: who(s), where(s), when(s), rule(ŝ), evolve(ŝ) = F(ŝ)

**Універсальний об'єкт.**
U = (S₀ × ℛ*, F*, g*)
∀X ∈ SUBIT: ∃! φ_X: U → X

**Принцип симуляції.**
∀(Q, δ) — скінченний автомат: ∃ ін'єкція ι: Q → S₀, ρ_a ∈ ℛ: f_{ρ_a}(ι(q)) = ι(δ(q,a))

### Частина IV. SUBIT_∞

**Означення 13.1 (Простір S_∞).**
S_∞ = νX.(A ⊔ X × X × X)
out : S_∞ → A ⊔ S_∞³

**Вкладення S₀.**
S₀ := {(a, b, c) ∈ S_∞ | a, b, c ∈ A ⊂ S_∞}
\|S₀\| = 64

**Означення 14 (Динаміка на S_∞).**
F : S_∞ × ℛ → S_∞ × ℛ
F(s, ρ) = (f_ρ(s), g(ρ, s))

**Теорема 15.1 (Властивості d_Ω).**
d_Ω(ŝ, t̂) = 2^(−n₀(ŝ,t̂))
n₀(ŝ, t̂) = min{n ≥ 0 : Ω(Fⁿŝ) ≠ Ω(Fⁿt̂)}

(1) d_Ω(ŝ, t̂) = 0 ⟺ ∀n ≥ 0: Ω(Fⁿŝ) = Ω(Fⁿt̂)
(2) d_Ω(ŝ, t̂) = d_Ω(t̂, ŝ)
(3) d_Ω(ŝ, û) ≤ max(d_Ω(ŝ, t̂), d_Ω(t̂, û))

**Теорема 15.2 (Нульвимірність).**
((S_∞ × ℛ)/~_Ω, d_Ω) — тотально незв'язаний ультраметричний простір.

### Додаток B специфікації

**Лема B.1.**
νX.X³ ≅ 1

**Лема B.3.**
νX.(A ⊔ X³) ≇ 1, якщо \|A\| > 1

### Підсумкова формула

SUBIT-∞ = (S_∞, ℛ, F, g, Ω, d_Ω, U, ℒ)
S_∞ = νX.(A ⊔ X × X × X)

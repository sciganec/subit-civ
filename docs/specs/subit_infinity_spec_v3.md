## Передмова: як читати цю специфікацію

Ця робота об'єднує дві раніше окремі специфікації SUBIT в одну ієрархічну структуру:

- **SUBIT-64 / SUBIT⁺** — скінченна версія (простір із 64 станів, розширений внутрішнім правилом ρ);
- **SUBIT_∞** — нескінченна, рекурсивна версія (простір станів як коіндуктивна нерухома точка);
- **SUBIT-TOPOS** — категоріальна й логічна надбудова над обома (топосна структура, типи, модальна логіка).

Разом вони утворюють єдину ієрархію:

```
SUBIT-64  ⊂  SUBIT⁺  ⊂  SUBIT-TOPOS  ⊂  SUBIT_∞
```

**Перш ніж переходити до формалізму, важливе методологічне застереження**, яке розгорнуто в розділі 15: SUBIT-∞ — це **нотаційна й евристична система**, а не емпірично підтверджена теорія про світ. Усе, що доводиться в цій специфікації (несуперечність, категоріальні властивості, властивості метрики), є твердженнями **про саму нотацію**, а не про будь-яку конкретну емпіричну систему, до якої її застосовують. Розділ 15 дає явні правила того, як коректно й некоректно використовувати цей апарат у дослідницькій роботі.

## 1. Вступ і мотивація

Класичні формальні системи розділяють три рівні опису:

```
Дані          — те, що описується
Програма      — правила опису
Метапрограма  — правила зміни правил
```

У теорії автоматів функція переходу δ задається наперед і не є частиною стану q; у класичній логіці істина визначається незалежно від часу; дані й програма традиційно розділені.

SUBIT-∞ усуває цю межу, постулюючи, що **стан, правило, інтерпретація правила та зміна правила належать до єдиної внутрішньої структури**. Це не емпіричне спостереження про природу — це дизайн-рішення нотації, обране для того, щоб зробити явним те, що в наративних описах (історичних, біологічних, соціальних) зазвичай залишається імпліцитним: яке саме "правило" дослідник постулює для переходу від одного стану системи до іншого.

## 2. Алфавіт примітивів (дві ізоморфні реалізації)

В основі лежить довільна скінченна множина примітивних маркерів потужності 4:

```
A = { a₁, a₂, a₃, a₄ }
```

SUBIT-∞ **параметризований** вибором конкретної реалізації A. Специфікація підтримує щонайменше дві стандартні, взаємно ізоморфні реалізації (обидві мають потужність |A| = 4, тому дають однакову комбінаторику):

**(а) Семантична реалізація** (для прикладного моделювання конкретних систем — історичних, соціальних, екологічних):

```
A_WHO   = { ME, WE, YOU, THEY }
A_WHERE = { EAST, SOUTH, WEST, NORTH }
A_WHEN  = { SPRING, SUMMER, AUTUMN, WINTER }
```

**(б) Логічна реалізація** (для формально-логічного, білаттисного трактування):

```
𝔸 = { T, F, B, N }
```

де T = True (Yang), F = False (Yin), B = Both (діалетеїчне), N = Neither (паракомплетне). Ця множина є білаттисом Белнапа з двома частковими порядками:

```
Порядок істинності:  F <ₜ N <ₜ T,  F <ₜ B <ₜ T
Порядок інформації:  N <ᵢ F <ᵢ B,  N <ᵢ T <ᵢ B
```

**Бінарне кодування.** Обидві реалізації допускають кодування кожного значення двома бітами (bigram = b₁b₂, де b₁ — "Yang-біт", b₂ — "Yin-біт"):

| Bigram | Семантична (WHO / WHERE / WHEN) | Логічна (𝔸) |
|---|---|---|
| 10 | ME / EAST / SPRING | T |
| 11 | WE / SOUTH / SUMMER | B |
| 01 | YOU / WEST / AUTUMN | F |
| 00 | THEY / NORTH / WINTER | N |

**Важливо:** відповідність між семантичною і логічною реалізаціями — це ізоморфізм множин потужності 4, а не змістовне твердження, що "ME логічно означає True". Це технічний факт про комбінаторику алфавіту, який дозволяє переносити алгебраїчні результати (напр., структуру Ω) між обома реалізаціями, не більше.

## 3. Простір станів: скінченний S₀ і рекурсивний S_∞

### 3.1 Скінченний простір SUBIT-64

```
S₀ = A³ = A_WHO × A_WHERE × A_WHEN   (або 𝔸³ у логічній реалізації)
|S₀| = 4³ = 64
```

Кожен стан s ∈ S₀ — трійка s = (α, β, γ). Кожному стану відповідає унікальна **гексаграма І-Цзін** (Додаток A): s = (b₁b₂b₃)(b₄b₅b₆), де перша тригама — Lower Trigram (WHO + перший біт WHERE), друга — Upper Trigram (другий біт WHERE + WHEN).

S₀ сам по собі є **статичним** простором: жодного оператора переходу, жодної внутрішньої динаміки, класифікатор істини тривіальний (Ω₀ = {⊤, ⊥}). **S₀ — необхідна, але недостатня структура**; це радше "алфавіт архетипів", ніж динамічна система.

### 3.2 Рекурсивний (нескінченний) простір S_∞

Це — концептуально ключове розширення, відсутнє в SUBIT-64. Означення 3.1. Простір станів S_∞ визначається як найбільша коалгебраїчна нерухома точка:

```
S_∞ = νX. (X × X × X)
```

де ν — коіндуктивний фікс-пойнт-оператор. Експліцитно: S_∞ — множина всіх скінченних та нескінченних дерев глибини ≤ ω, де кожен вузол має рівно трьох нащадків, а листя належать A; склеювання за бісимуляцією (у сенсі Aczel, 1988) допускає цикли. Елемент s ∈ S_∞ записується як s = (w, x, y), де w, x, y ∈ S_∞ (якщо s — листок/примітивний маркер, w, x, y вважаються тотожними самому s або фіктивними).

**Зв'язок S₀ і S_∞ (уніфікація двох попередніх специфікацій).** S₀ (SUBIT-64) вкладається в S_∞ як множина листків глибини 1:

```
S₀ = { (w, x, y) | w, x, y ∈ A } ⊂ S_∞
```

Еволюція F, визначена на S_∞ (розділ 5), обмежується на S₀, якщо правило ρ також обмежене нею. **Отже, SUBIT-64 є скінченною апроксимацією глибини 1 нескінченного об'єкта S_∞** — це і є сенс назви SUBIT-∞: одна й та сама рекурсивна структура одночасно підтримує компактну 64-станову модель (для прикладного застосування) і необмежено глибоку рекурсію (для випадків, коли WHO, WHERE чи WHEN самі мають внутрішню структуру, що вимагає розгортання — наприклад, "громада" (WHO), яка сама складається з підгруп зі своїми WHO/WHERE/WHEN).

### 3.3 Простір правил

```
ℛ = множина всіх допустимих функцій f: S_∞ → S_∞
```

де "допустимі" означає обчислювані в розширеному сенсі (задані скінченним описом). Для практичних цілей ℛ обмежується функціями, що залежать лише від скінченної глибини рекурсії (апроксимація) — на практиці, для роботи з S₀, це просто ℛ|_{S₀} = {ρ₁, …, ρₙ}, ρᵢ: S₀ → S₀.

## 4. Розширений стан

Означення 4.1. Розширеним станом називається пара:

```
ŝ = (s, ρ) ∈ S_∞ × ℛ
```

де ρ — **активне правило еволюції**, що належить самому стану, а не задається ззовні. Принципова відмінність від класичних автоматів: правило є частиною стану, інтерпретатор — частиною динаміки, еволюція правил — внутрішньою.

---

## 5. Оператор еволюції F, траєкторії, ієрархія рівнів

### 5.1 Оператор еволюції

```
F: S_∞ × ℛ → S_∞ × ℛ
F(s, ρ) = (f_ρ(s), g(ρ, s))
```

де f_ρ: S_∞ → S_∞ — застосування правила ρ до стану s; g: ℛ × S_∞ → ℛ — функція метаеволюції (зміна самого правила).

**Аксіома детермінованості.** F — тотальна функція (визначена для всіх (s, ρ)).

### 5.2 Траєкторії

```
τ(ŝ₀) = (ŝ₀, ŝ₁, ŝ₂, …),  де ŝₙ₊₁ = F(ŝₙ)
```

Проекції π_S(ŝ) = s, π_ℛ(ŝ) = ρ дозволяють записати еволюцію покомпонентно:

```
π_S(ŝₙ₊₁) = f_{π_ℛ(ŝₙ)}(π_S(ŝₙ))
π_ℛ(ŝₙ₊₁) = g(π_ℛ(ŝₙ), π_S(ŝₙ))
```

**Типи траєкторій:**

| Тип | Формальна умова |
|---|---|
| Атрактор (нерухома точка) | F(ŝ) = ŝ ⟺ f_ρ(s) = s та g(ρ, s) = ρ |
| Орбіта (замкнений цикл довжини k) | Fᵏ(ŝ) = ŝ та ∀i<k: Fⁱ(ŝ) ≠ ŝ |
| Нестабільна траєкторія | не досягає атрактора чи орбіти за скінченний час |
| Хаотична траєкторія | щільна в просторі станів (у скінченній апроксимації — максимально довгий цикл без повторення) |

### 5.3 Ієрархія рівнів самореференції

```
Рівень 0:  s = (α, β, γ)       — базовий стан SUBIT-64 (без правила)
Рівень 1:  ŝ = (s, ρ)          — стан з внутрішнім правилом
Рівень 2:  F(ŝ) = (s', ρ')     — еволюція стану і правила
Рівень 3:  g(ρ, s) → ρ'        — метаеволюція: зміна способу зміни
```

Класичні автомати мають лише Рівень 0 і фіксований Рівень 2 (δ задається наперед і не змінюється). SUBIT-∞ додає Рівні 1 і 3, роблячи систему самореферентною.

## 6. Ω-класифікатор, алгебра Гейтінга, семантична ультраметрика

### 6.1 Визначення класифікатора

Нехай P ⊆ S_∞ × ℛ — довільна множина розширених станів.

```
STABLE      ⟺  F(P) ⊆ P
METASTABLE  ⟺  F(P) ⊆ P,  але  P ⊄ F(P)
CYCLIC      ⟺  ∃k > 0: Fᵏ(P) = P  (і жодне з попередніх не виконується)
CHAOTIC     ⟺  жодна з вищенаведених умов не виконується
```

**Семантична істина.** P є істинним ⇔ P є stable ⇔ F(P) ⊆ P. Це визначення не потребує зовнішнього спостерігача — це внутрішній критерій, що випливає з динаміки. Істина — динамічний інваріант, а не статична відповідність.

### 6.2 Частковий порядок і алгебра Гейтінга

```
CHAOTIC < CYCLIC < METASTABLE < STABLE
```

Ω з операціями ∧ (кон'юнкція), ∨ (диз'юнкція) і ¬ (заперечення у сенсі Гейтінга, ¬a = a → CHAOTIC) утворює **алгебру Гейтінга**, а не булеву алгебру:

| ∧ | STABLE | METASTABLE | CYCLIC | CHAOTIC |
|---|---|---|---|---|
| **STABLE** | STABLE | METASTABLE | CYCLIC | CHAOTIC |
| **METASTABLE** | METASTABLE | METASTABLE | CYCLIC | CHAOTIC |
| **CYCLIC** | CYCLIC | CYCLIC | CYCLIC | CHAOTIC |
| **CHAOTIC** | CHAOTIC | CHAOTIC | CHAOTIC | CHAOTIC |

| ∨ | STABLE | METASTABLE | CYCLIC | CHAOTIC |
|---|---|---|---|---|
| **STABLE** | STABLE | STABLE | STABLE | STABLE |
| **METASTABLE** | STABLE | METASTABLE | METASTABLE | METASTABLE |
| **CYCLIC** | STABLE | METASTABLE | CYCLIC | CYCLIC |
| **CHAOTIC** | STABLE | METASTABLE | CYCLIC | CHAOTIC |

**Наслідок (не-класичність).** Закон виключеного третього не виконується: METASTABLE ∨ ¬METASTABLE = METASTABLE ∨ CYCLIC = CYCLIC ≠ STABLE. Це прямо відповідає **інтуїціоністській логіці**, а не класичній булевій.

### 6.3 Семантична ультраметрика d_Ω

Означення. Нехай δ(ŝ, t̂) = 0, якщо ŝ і t̂ належать одному Ω-класу, і 1 — інакше. Тоді:

```
d_Ω(ŝ, t̂) = Σ_{n=0}^{∞} 2⁻ⁿ · δ(Fⁿ(ŝ), Fⁿ(t̂))
```

**Теорема 6.1.** d_Ω є ультраметрикою: (1) d_Ω(ŝ,t̂)=0 ⇔ ŝ=t̂ (нерозрізненість за Ω-класами на всіх кроках); (2) симетричність; (3) сильна нерівність трикутника d_Ω(ŝ,û) ≤ max(d_Ω(ŝ,t̂), d_Ω(t̂,û)). *Доведення (схема): (3) випливає з бінарності δ і збереження ультраметричності при сумуванні з вагами 2⁻ⁿ, за аналогією з p-адичними метриками.*

**Теорема 6.2.** Простір (S_∞ × ℛ, d_Ω) є тотально незв'язним: кожна куля одночасно відкрита й замкнена (clopen). Топологія — нульвимірна.

**Практичний сенс для дослідника:** d_Ω дає кількісну міру того, наскільки "по-різному" еволюціонують дві історичні/емпіричні траєкторії, а не лише якісну відмінність в Ω-класах на одному кроці — це дозволяє порівнювати не тільки "чи це stable", а й "наскільки швидко дві гіпотези розходяться в передбаченнях".

## 7. Категорія SUBIT

### 7.1 Об'єкти й морфізми

```
X = (S_X, ℛ_X, F_X, g_X),  S_X ⊆ S_∞, ℛ_X ⊆ ℛ
Аксіома замкненості: F_X(S_X × ℛ_X) ⊆ S_X × ℛ_X
```

Морфізм φ: X → Y — пара (φ_S, φ_ℛ), що задовольняє умову **динамічної сумісності** (еволюція, потім відображення = відображення, потім еволюція):

```
φ_S(π_S(F_X(ŝ))) = π_S(F_Y(φ_S(π_S(ŝ)), φ_ℛ(π_ℛ(ŝ))))
```

Композиція і тотожні морфізми визначаються покомпонентно; SUBIT є категорією (асоціативність і нейтральність тотожності виконуються автоматично).

### 7.2 Спеціальні конструкції

- **Термінальний об'єкт 1**: S₁ = {∗}, ℛ₁ = {id}; для будь-якого X існує рівно один морфізм X → 1.
- **Добуток X × Y**: S_{X×Y}=S_X×S_Y, F_{X×Y}((s₁,s₂),(ρ₁,ρ₂))=(F_X(s₁,ρ₁), F_Y(s₂,ρ₂)).
- **Експоненціал Yˣ**: S_{Yˣ} = {динамічно сумісні відображення S_X → S_Y}; наслідок — **SUBIT є декартово замкненою категорією (CCC)**: Hom(X×Y, Z) ≅ Hom(X, Zˣ).
- **Універсальний об'єкт U** = (S_∞ × ℛ*, F*, g*), де ℛ* — коди всіх допустимих локальних правил, F* — інтерпретатор, g* — переписувач правил. Для будь-якого X існує морфізм φ_X: U → X (U — внутрішній Universal Interpreter, аналог λ-числення: стан ↔ λ-терм, правило ↔ λ-функція, F ↔ β-редукція).

## 8. SUBIT як proto-topos

Категорія є топосом, якщо вона має (T1) скінченні ліміти, (T2) експоненціали, (T3) субоб'єктний класифікатор Ω. SUBIT задовольняє (T1) і (T2). Умова (T3) виконується в **динамічній версії**: замість бінарного Ω={⊤,⊥} — Ω_SUBIT={stable, metastable, cyclic, chaotic}, що утворює алгебру Гейтінга (розділ 6.2), а не булеву алгебру. Тому SUBIT є **proto-topos**: структура, що задовольняє всі умови топосу, але з нестандартним, динамічним Ω. Чи є SUBIT_∞ топосом у строго класичному сенсі, залишається відкритим питанням (розділ 14).

## 9. Динамічна теорія типів і модальна логіка

### 9.1 Судження й типи

```
Γ ⊢ t : A @ τ
```

означає: у контексті Γ стан t має тип A на фазі еволюції τ. Тип A — не статична класифікація, а **клас траєкторій зі спільним режимом стабільності**: A = {ŝ ∈ S_∞×ℛ | stability_class(ŝ) = mode_A}.

**Правила виведення (вибірково):**

```
Рефлексивність:        Γ, x:A@τ ⊢ x : A@τ

Еволюція типу:          Γ ⊢ t:A@τ,  F(A)⊆B  ⟹  Γ ⊢ F(t):B@(τ+1)

Стабільний тип:         Γ ⊢ t:A@τ,  F(A)⊆A  ⟹  Γ ⊢ t:□A@τ

Потенційний тип:        Γ ⊢ t:A@τ,  ∃k:Fᵏ(A)⊆B  ⟹  Γ ⊢ t:◇B@τ

Циклічний тип:          Γ ⊢ t:A@τ,  ∃k:Fᵏ(A)=A  ⟹  Γ ⊢ t:◯A@τ
```

**Атракторна рівність** замінює класичну ідентичність: s ~_F t ⟺ ∃k: Fᵏ(s) = Fᵏ(t) — два стани еквівалентні, якщо їхні траєкторії зрештою збігаються.

### 9.2 Модальна логіка

| Модальність | Визначення | Сенс |
|---|---|---|
| □A | F(A) ⊆ A | стабільна/необхідна істина (A — F-інваріант) |
| ◇A | ∃k≥0: Fᵏ(s) ∈ A | потенційна стабілізація |
| ◯A | ∃k>0: Fᵏ(s)∈A та Fᵏ(A)=A | циклічне повернення |

**Аксіоми:** (M1) □A→A; (M2) □A→□□A; (M3) □(A→B)→(□A→□B); (M4) ◇A↔¬□¬A; (M5) ◯A→◇A; (M6) □A→◯A; (M7) ◯◯A↔◯A; (M8) □A∧□B→□(A∧B). **НЕ виконуються** ◇A∨◇¬A і □A∨□¬A — не кожна траєкторія стабілізується, класичний виключений третій не діє.

**Відповідність Ω:** stable ↔ □A; metastable ↔ A∧¬□A; cyclic ↔ ◯A∧¬□A; chaotic ↔ ¬◇A.

### 9.3 Внутрішня мова

Примітивні терми: s,t,u (State), ρ,σ (Rule), p,q (Prop). Конструктори: who(s), where(s), when(s) — проекції на координати; rule(ŝ) — витягування правила; evolve(ŝ) — застосування F. Пропозиційні конструктори: stable(p), reaches(s,A), cycle(A), morphism(φ,X,Y), iso(φ).

## 10. Принцип симуляції

**Теорема (Внутрішня симуляція).** Будь-який скінченний автомат (Q, δ) вкладається в SUBIT⁺: ∀(Q,Σ,δ,q₀,F_accept) ∃φ: (Q,δ) → SUBIT⁺, де φ зберігає стани (q ↦ s_q ∈ S₀), переходи (δ(q,a)=q' ↦ F(s_q,ρ_a)=s_{q'}), і прийняття (q∈F_accept ↦ s_q∈Fix(F)).

**Конструкція:** обрати ін'єкцію ι: Q→S₀; для кожного символу a∈Σ побудувати ρ_a∈ℛ* такий, що f_{ρ_a}(ι(q))=ι(δ(q,a)); визначити g: ρ_a ↦ ρ_{next_symbol}. **Наслідок:** SUBIT⁺ є умовно універсальною симуляційною системою — універсальність досягається не через нескінченність множини станів, а через внутрішню самореференцію (здатність системи переписувати власні правила).

## 11. Конструктивні процедури (алгоритми)

### 11.1 Обчислення Ω-класу для скінченної апроксимації

```
Вхід: ŝ₀ = (s₀, ρ₀), скінченна глибина d, N_max
visited ← ∅
для n = 0, 1, …, N_max:
    якщо ŝₙ ∈ visited:
        L ← n − visited(ŝₙ)
        якщо L = 1: повернути STABLE
        якщо L ≤ L_thresh (напр., 8): повернути CYCLIC
        інакше: повернути METASTABLE
    додати ŝₙ до visited
    ŝₙ₊₁ ← F(ŝₙ)
якщо N_max досягнуто без повтору: повернути CHAOTIC
```

### 11.2 Обчислення семантичної відстані

```
Вхід: ŝ, t̂, максимальна глибина K
d ← 0
для n = 0 до K:
    якщо Ω(ŝₙ) ≠ Ω(t̂ₙ): d ← d + 2⁻ⁿ
    ŝₙ₊₁ ← F(ŝₙ);  t̂ₙ₊₁ ← F(t̂ₙ)
повернути d   (при K→∞ — наближення d_Ω)
```

### 11.3 Побудова універсального об'єкта U

U реалізується як інтерпретатор: стан U — кодоване представлення довільної системи X; правило U — універсальна функція eval, яка приймає код (s,ρ) системи X, обчислює f_ρ(s) (симуляція одного кроку X) і повертає код нового стану.

## 12. Уніфікована аксіоматична система

**Базова структура:**
- (A1) S_∞ = νX.(X×X×X); S₀ = A³ ⊂ S_∞ як листки глибини 1, |S₀|=64.
- (A2) ℛ — непорожня множина допустимих (обчислюваних) правил еволюції.
- (A3) F: S_∞×ℛ → S_∞×ℛ — тотальна функція; F(s,ρ)=(f_ρ(s), g(ρ,s)).
- (A4) ∀ŝ: F(ŝ) визначається внутрішнім правилом ρ∈ŝ (правило — частина стану).

**Категоріальна структура:**
- (A5)–(A8) Композиція морфізмів ∘ асоціативна; id_X — нейтральний елемент.
- (A9)–(A11) Існують скінченні добутки, термінальний об'єкт 1, експоненціали Yˣ (⟹ CCC).

**Динамічний класифікатор:**
- (A12) Ω = {stable, metastable, cyclic, chaotic}, з операціями ∧,∨,¬ за розділом 6.2 (алгебра Гейтінга).
- (A13)–(A15) Визначення stable/cyclic/chaotic за F(P)⊆P, Fᵏ(P)=P відповідно.
- (A16) stable > metastable > cyclic > chaotic (частковий порядок).

**Метрика:**
- (A17) d_Ω(ŝ,t̂) = Σ 2⁻ⁿ δ(Fⁿ(ŝ),Fⁿ(t̂)) — ультраметрика (Теорема 6.1).

**Динамічна теорія типів:**
- (A18) Кожен тип A — F-інваріантний клас траєкторій.
- (A19) Γ⊢t:A@τ та Γ⊢A→B@τ ⟹ Γ⊢t:B@τ.
- (A20) □A ⟹ Γ⊢t:A@τ для будь-якого τ.
- (A21) s ~_F t ⟺ ∃k: Fᵏ(s)=Fᵏ(t) (атракторна рівність).

**Універсальність:**
- (A22) ∃U∈SUBIT: ∀X∈SUBIT ∃φ:U→X, і U може симулювати власний оператор F зсередини.

## 13. Метатеоретичні властивості

**Несуперечність.** У скінченній апроксимації (S₀, ℛ скінченні, F — тотальна функція на скінченній множині) усі аксіоми виконуються в скінченній моделі — SUBIT-64/SUBIT⁺ несуперечні за побудовою. Для повного S_∞ несуперечність спадкує від коіндуктивної конструкції (Aczel, 1988) і не є тривіальною для довільного ℛ.

**Неповнота (аналогія з Гьоделем).** Якщо ℛ достатньо багата (містить правила самоопису), то існують твердження внутрішньої мови SUBIT, які є істинними (у сенсі F(P)⊆P), але не доводяться в системі. Формально: SUBIT-∞ з достатньо багатим ℛ є **семантично повною, але синтаксично неповною**.

**Ієрархія виразності:**

```
SUBIT-64  ⊂  SUBIT⁺  ⊂  SUBIT-TOPOS  ⊂  SUBIT_∞
```

| Рівень | Що додає |
|---|---|
| SUBIT-64 | класифікація без динаміки (статичний алфавіт архетипів) |
| SUBIT⁺ | динаміка з внутрішніми правилами (F, g) |
| SUBIT-TOPOS | категоріальна структура, Ω, U, внутрішня мова, типи, модальна логіка |
| SUBIT_∞ | рекурсивний, потенційно нескінченно глибокий простір станів (νX.(X×X×X)), семантична ультраметрика |

**Відношення до відомих систем:**

| Система | Відношення до SUBIT-∞ |
|---|---|
| Скінченні автомати (DFA/NFA) | Вкладаються через принцип симуляції (розділ 10) |
| Класична логіка | Спеціальний випадок при Ω = {⊤, ⊥} |
| Інтуїціоністська логіка | Реалізується через Ω-алгебру Гейтінга |
| Лямбда-числення | Аналог: U — λ-інтерпретатор, F ↔ β-редукція |
| Класичні топоси (Гротендік) | SUBIT — узагальнення (proto-topos із динамічним Ω) |
| Білаттис Белнапа (FOUR) | Логічна реалізація базового алфавіту 𝔸 |
| І-Цзін (64 гексаграми) | Комбінаторна реалізація S₀ |
| p-адичні метрики | Структурна аналогія для d_Ω (нульвимірна, ультраметрична топологія) |

## 14. Відкриті питання та гіпотези

- **Гіпотеза 1 (Семантична повнота).** Будь-яка система, що описується змінюваними правилами, реалізовна як об'єкт SUBIT_∞. *(Не доведено; правдоподібно за принципом симуляції для скінченних автоматів, статус для нескінченних/неперервних систем відкритий.)*
- **Гіпотеза 2 (Фрактальна межа).** Множина правил ρ, для яких траєкторія фіксованого s₀ є chaotic, утворює множину з дробовою Хаусдорфовою розмірністю відносно природної топології на ℛ. *(Відкрито; аналогія з множинами Жюліа не доведена формально.)*
- **Гіпотеза 3 (Нерухома точка інтерпретації).** Існує стан s* такий, що F(s,ρ)=(s,ρ) — "абсолютна інтерпретація". *(Слідує з теореми про нерухому точку для компактних просторів за певних умов неперервності F; загальний випадок відкритий.)*
- **Відкрите питання.** Чи є SUBIT_∞ топосом у строго класичному сенсі (тобто чи Ω_SUBIT дійсно задовольняє всі аксіоми субоб'єктного класифікатора, а не лише неформально їх нагадує)? Це вимагає окремого категоріального доведення, не наданого в жодній із вихідних специфікацій.

## 15. Епістемологічний статус: SUBIT-∞ як евристичний інструмент

Це — розділ, доданий при об'єднанні специфікацій, і він є **нормативним**: усі подальші застосування SUBIT-∞ мають його дотримуватися.

### 15.1 Що SUBIT-∞ доводить, а що — ні

**Доводить (як формальна система):**
- Внутрішню несуперечність визначень у скінченній апроксимації.
- Замкненість категоріальних операцій (добутки, експоненціали, CCC).
- Що Ω з операціями ∧,∨,¬ утворює алгебру Гейтінга, а не булеву алгебру (Наслідок 6.2).
- Що d_Ω є ультраметрикою (Теорема 6.1) за умови, що δ визначена коректно.

**Не доводить і не може довести:**
- Що будь-яка конкретна емпірична система (історична цивілізація, екосистема, соціальний процес), до якої застосовують SUBIT-∞, дійсно еволюціонує за правилом ρ, яке дослідник обрав.
- Що присвоєння Ω-класу (stable/metastable/cyclic/chaotic) конкретній емпіричній множині станів P є істинним у сенсі відповідності реальності — це **завжди** якісне судження дослідника, підігнане під уже наявні дані, а не обчислена величина.
- Саме по собі "гарне накладання" SUBIT-мітки на дані не є додатковим емпіричним підтвердженням жодної гіпотези про світ.

### 15.2 Коректний і некоректний режими використання

| Коректно | Некоректно |
|---|---|
| Використовувати ρ як явний, чіткий запис конкретного причинного механізму, який потім перевіряється незалежними емпіричними даними. | Використовувати присвоєння Ω-класу як самостійний доказ чи "пояснення" історичної/наукової події. |
| Використовувати Ω-класифікацію, щоб розрізнити типи переходів (напр., "chaotic-колапс" проти "metastable-переналаштування"), а потім шукати емпіричну ознаку (стратиграфічну, статистичну, поведінкову), яка відрізняє ці типи. | Стверджувати, що математичні властивості нотації (несуперечність, CCC-структура, ультраметричність) переносяться на істинність тверджень про світ. |
| Формулювати розрізняльні тести: "якщо гіпотеза A вірна, ми маємо спостерігати X; якщо гіпотеза B — Y", і потім шукати X чи Y в реальних даних. | Використовувати SUBIT-жаргон (F(P)⊆P, hexagram, Ω) як замінник, а не доповнення до емпіричної верифікації. |
| Явно позначати статус кожного твердження: "формально доведено в нотації" проти "емпірично підтверджено джерелом [X]" проти "інтерпретаційна пропозиція дослідника". | Змішувати ці три статуси в одному реченні без розрізнення. |

### 15.3 Мінімальний робочий протокол застосування (рекомендований)

1. Визначити емпіричну систему і питання (напр., "чому суспільство X зникло в період Y").
2. Сформулювати 2–3 конкуруючі гіпотези як конкретні правила ρ₁, ρ₂, ρ₃ — кожне з чітким механізмом.
3. Для кожного ρᵢ вивести конкретне, відмінне від інших емпіричне передбачення (розрізняльний тест).
4. Знайти або зібрати реальні дані (першоджерела, а не переказ), що можуть підтвердити чи спростувати кожне передбачення.
5. Лише після цього — за бажанням — присвоїти Ω-клас переходу як **компактний підсумковий ярлик** уже здобутого емпіричного висновку, а не як заміну кроку 4.
6. Явно вказати, які частини висновку спираються на джерела, а які є інтерпретаційною пропозицією самого дослідника.

Цей протокол було застосовано (і перевірено на практиці) у супровідному дослідженні формування й занепаду цивілізації Караль-Супе, де SUBIT-евристика допомогла: (а) розкласти розмиту причину на окремі перевірювані механізми; (б) виявити внутрішню суперечність у самій першоджерельній літературі; (в) дати мову для категорії переходу ("metastable-переналаштування"), яка точніше відповідала задокументованому патерну, ніж бінарне "колапс/не колапс" — без жодного разу, коли сам факт застосування формалізму видавався б за нову емпіричну знахідку.

## Додаток A. Гексаграмна реалізація SUBIT-64

Кожному з 64 станів s=(b₁b₂b₃)(b₄b₅b₆) відповідає унікальна гексаграма І-Цзін — від ䷀ (111111) до ䷿ (010101). Повна таблиця відповідності (64 гексаграми з їхніми бітовими кодами) успадковується з початкової специфікації SUBIT-TOPOS без змін і використовується виключно як **комбінаторна нотація** (компактний однознаковий запис 6-бітного стану), без додаткових езотеричних тверджень про сенс і-цзінівських триграм — таке тлумачення виходить за межі формальної специфікації і, якщо потрібне, має обговорюватися окремо як культурно-інтерпретаційний, а не формальний шар.

## Підсумкова формула

```
SUBIT-∞ = ( S_∞, ℛ, F, g, Ω, d_Ω, U, ℒ )
```

де S_∞ = νX.(X×X×X) — рекурсивний простір станів (з S₀=A³, |S₀|=64, як вкладеною скінченною апроксимацією); ℛ — внутрішні правила; F — динаміка; g — метадинаміка; Ω — динамічна структура істини (алгебра Гейтінга на 4 значеннях); d_Ω — семантична ультраметрика; U — універсальний об'єкт-інтерпретатор; ℒ — внутрішня мова (динамічна теорія типів і модальна логіка).

**Центральна теза:** правило належить стану; інтерпретація є частиною еволюції; істина визначається стабільністю (F(P)⊆P); відстань вимірює розбіжність траєкторій; існує універсальний інтерпретатор; категорія декартово замкнена.

**Центральне методологічне застереження (розділ 15):** ніщо з вищенаведеного не є твердженням про те, що будь-яка конкретна річ у світі справді є "stable" чи "chaotic" — це завжди інтерпретаційний крок дослідника, який мусить бути підкріплений незалежними емпіричними даними, а не самою нотацією.

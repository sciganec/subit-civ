# SUBIT-∞ (SUBIT-INFINITY)

## Ієрархічна специфікація: від елементарного рівня до повної системи

**Версія 4.0 · Уніфікована й математично перевірена специфікація · 2026**

```
SUBIT-64  ⊂  SUBIT⁺  ⊂  SUBIT-TOPOS  ⊂  SUBIT_∞
```

---

## Передмова до версії 4.0: що змінилося

Ця версія повністю переструктурована за принципом **кумулятивної ієрархії**: кожна Частина є самодостатньою специфікацією свого рівня — її можна прочитати й використати окремо, — а кожна наступна Частина додає *рівно той новий апарат*, якого не було на попередньому рівні, і нічого не переозначає.

Крім реструктуризації, при повторній перевірці математики виявлено й виправлено **п'ять реальних неточностей** у вихідних специфікаціях. Кожна позначена блоком `⚠ ВИПРАВЛЕННЯ`. Коротко:

1. **Ω-класифікатор** у вихідній "Семантичний Універсум v2.0" був визначений суперечливо (умова METASTABLE була підмножиною умови STABLE, тобто недосяжна as written) — виправлено на чітку, неперетинну систему умов.
2. **CHAOTIC не є математично досяжним на скінченному рівні SUBIT⁺** — у скінченному просторі станів кожна траєкторія за принципом Діріхле (pigeonhole) зрештою періодична; це не було explicit у вихідних текстах, а мало б бути головним аргументом *навіщо* потрібен перехід до S_∞.
3. **Таблиця заперечення ¬ в алгебрі Гейтінга** мала дві помилки (¬metastable і ¬cyclic обчислені невірно) — перераховано коректно за стандартною формулою відносного псевдодоповнення для лінійного порядку.
4. **"Теорема" про те, що d_Ω є ультраметрикою**, була сформульована для формули-суми Σ2⁻ⁿδₙ, яка **не** задовольняє строгу нерівність трикутника (наведено контрприклад) — замінено на стандартну конструкцію "перша розбіжність" (valuation-style), яка справді дає ультраметрику.
5. **Твердження, що SUBIT — декартово замкнена категорія (CCC)**, спиралося на конструкцію експоненціала, яка коректна лише для оборотних F_X — це вже було позначено в оригіналі як застереження, але тепер явно позначено як **відкриту технічну прогалину**, а не доведений факт.

Розділ епістемологічного статусу (раніше розділ 15) тепер винесено в окрему коротку **Частину V** наприкінці.

# ЧАСТИНА I. SUBIT-64 — статичний алфавіт станів

*Найелементарніший рівень. Тут немає динаміки: лише множина станів і спосіб їх позначення.*

## I.1 Алфавіт примітивів

Нехай A — довільна скінченна множина потужності 4. Специфікація параметризована вибором конкретної реалізації A; підтримуються дві стандартні, взаємно ізоморфні реалізації:

**(а) Семантична реалізація** (для прикладного моделювання конкретних емпіричних систем):

```
A_WHO   = { ME, WE, YOU, THEY }
A_WHERE = { EAST, SOUTH, WEST, NORTH }
A_WHEN  = { SPRING, SUMMER, AUTUMN, WINTER }
```

**(б) Логічна реалізація** (білаттис Белнапа, для формально-логічного трактування):

```
𝔸 = { T, F, B, N }
```

де T=True (Yang), F=False (Yin), B=Both (діалетеїчне), N=Neither (паракомплетне), з двома частковими порядками:

```
Порядок істинності:  F <ₜ N <ₜ T,  F <ₜ B <ₜ T
Порядок інформації:  N <ᵢ F <ᵢ B,  N <ᵢ T <ᵢ B
```

**Бінарне кодування** (bigram = b₁b₂):

| Bigram | Семантична реалізація | Логічна реалізація |
|---|---|---|
| 10 | ME / EAST / SPRING | T |
| 11 | WE / SOUTH / SUMMER | B |
| 01 | YOU / WEST / AUTUMN | F |
| 00 | THEY / NORTH / WINTER | N |

Відповідність між реалізаціями — це **ізоморфізм множин потужності 4, а не змістовне ототожнення** ("ME" не "означає" True); це технічний факт про комбінаторику, що дозволяє переносити алгебраїчні результати між реалізаціями.

## I.2 Простір станів S₀

```
S₀ = A³ = A_WHO × A_WHERE × A_WHEN   (або 𝔸³)
|S₀| = 4³ = 64
```

Кожен стан — трійка s = (α, β, γ). Кожному стану відповідає унікальна **гексаграма І-Цзін** (повна таблиця відповідності — Додаток A): s = (b₁b₂b₃)(b₄b₅b₆), де перша тригама (Lower Trigram) кодує WHO + перший біт WHERE, друга (Upper Trigram) — другий біт WHERE + WHEN.

## I.3 Властивості й межі рівня SUBIT-64

- S₀ — **статичний** простір: жодного оператора переходу, жодної внутрішньої динаміки.
- Класифікатор істини на цьому рівні тривіальний: Ω₀ = {⊤, ⊥} (класична двозначна логіка — стан або належить множині, або ні).
- Гексаграмна нотація — це виключно **комбінаторний запис** 6-бітного слова; будь-яке додаткове тлумачення і-цзінівських триграм (стихії, кольори, напрямки з есе-частини вихідних матеріалів) виходить за межі формальної специфікації й не використовується далі як математичний об'єкт.

**Висновок рівня I:** SUBIT-64 — необхідний, але недостатній рівень: це "алфавіт архетипів", а не динамічна система. Він не може моделювати зміну, причинність чи перехід між станами. Це мотивує Частину II.

# ЧАСТИНА II. SUBIT⁺ — скінченна самореферентна динаміка

*Додається рівно одне: правило еволюції, яке належить самому стану, і оператор, що змінює і стан, і правило.*

## II.1 Простір правил ℛ (скінченний)

```
ℛ = { ρ₁, ρ₂, …, ρₙ },  де кожне ρᵢ : S₀ → S₀
```

На цьому рівні ℛ обов'язково скінченна (n правил, кожне — конкретна, явно задана функція S₀→S₀).

## II.2 Розширений стан

```
ŝ = (s, ρ) ∈ S₀ × ℛ
```

**Принципова відмінність від класичних скінченних автоматів**: у класичному автоматі функція переходу δ зовнішня щодо стану q і фіксована раз і назавжди. У SUBIT⁺ правило ρ — **частина самого стану**, і саме воно теж змінюється в часі.

## II.3 Оператор еволюції F

```
F: S₀ × ℛ → S₀ × ℛ
F(s, ρ) = (f_ρ(s), g(ρ, s))
```

де f_ρ: S₀→S₀ — застосування правила ρ; g: ℛ×S₀→ℛ — **метаеволюція** (функція, що змінює саме правило).

**Аксіома детермінованості.** F — тотальна функція, визначена для всіх (s,ρ) ∈ S₀×ℛ.

## II.4 Ієрархія рівнів самореференції

```
Рівень 0:  s = (α, β, γ)        — базовий стан (SUBIT-64, без правила)
Рівень 1:  ŝ = (s, ρ)           — стан із внутрішнім правилом
Рівень 2:  F(ŝ) = (s', ρ')      — еволюція стану і правила за один крок
Рівень 3:  g(ρ, s) → ρ'         — метаеволюція: зміна способу зміни
```

Класичні автомати мають лише Рівень 0 і фіксований Рівень 2 (δ незмінна). SUBIT⁺ додає Рівні 1 і 3.

## II.5 Траєкторії й фундаментальний скінченнісний факт

```
τ(ŝ₀) = (ŝ₀, ŝ₁, ŝ₂, …),  де ŝₙ₊₁ = F(ŝₙ)
```

> **⚠ ВИПРАВЛЕННЯ / уточнення, відсутнє у вихідних текстах.**
> Оскільки S₀×ℛ — **скінченна** множина (за побудовою цього рівня), а F — детермінована функція цієї скінченної множини в саму себе, за принципом Діріхле **кожна траєкторія ŝ₀, ŝ₁, ŝ₂, … рано чи пізно входить у цикл** (можливо, після скінченного "хвоста"). Формально: ∀ŝ₀ ∃m≥0, k≥1: ŝ_{m+k}=ŝ_m. Це означає, що на рівні SUBIT⁺ **не існує генуїнно неперіодичних (у строгому сенсі "щільних у просторі") траєкторій** — усі вони мають форму "пуголовка": скінченний хвіст + цикл.
>
> **Наслідок для класифікації (розділ III.3):** справжня категорія *CHAOTIC* у сенсі "немає жодного циклу взагалі" **математично порожня на рівні SUBIT⁺** для одноточкових траєкторій. Те, що конструктивний алгоритм (II.6) повертає "CHAOTIC", коли цикл не знайдено за N_max кроків, — це **артефакт обмеженого пошуку**, а не справжня математична категорія: він означає "цикл існує, але довший за N_max", а не "циклу не існує". Генуїнно нескінченні, неперіодичні траєкторії стають математично можливими лише на рівні S_∞ з нескінченним чи неперервним ℛ (Частина IV). Це — головна причина, чому ієрархія взагалі потребує переходу за межі скінченного рівня.

Типи одноточкових траєкторій, коректні на рівні SUBIT⁺:

| Тип | Формальна умова |
|---|---|
| Атрактор (нерухома точка, k=1) | F(ŝ)=ŝ ⟺ f_ρ(s)=s і g(ρ,s)=ρ |
| Орбіта (цикл довжини k>1) | Fᵏ(ŝ)=ŝ і ∀i<k: Fⁱ(ŝ)≠ŝ |
| Передперіодична ("пуголовка") траєкторія | ∃m>0,k≥1: ŝ_{m+k}=ŝ_m, але ŝ₀,…,ŝ_{m-1} не повторюються |

## II.6 Конструктивний алгоритм класифікації (скінченне наближення)

```
Вхід: ŝ₀ = (s₀, ρ₀), N_max
visited ← ∅
для n = 0, 1, …, N_max:
    якщо ŝₙ ∈ visited:
        L ← n − visited(ŝₙ)                 # довжина знайденого циклу
        якщо L = 1: повернути STABLE (атрактор)
        інакше: повернути CYCLIC (період L)
    додати ŝₙ → visited з позначкою n
    ŝₙ₊₁ ← F(ŝₙ)
якщо N_max вичерпано без повтору: повернути "НЕВИЗНАЧЕНО (цикл довший за N_max)"
```

*(Порівняно з попередньою версією специфікації, останній випадок тут коректно перейменовано з "CHAOTIC" на "невизначено", згідно з пунктом II.5 вище — це не окрема математична категорія, а межа обчислювальних ресурсів.)*

**Висновок рівня II:** SUBIT⁺ дає повноцінну скінченну самореферентну динаміку, але (а) не має мови для опису *множин* станів (тільки одноточкові траєкторії), (б) не має структури категорії/типів, (в) математично не підтримує справжню хаотичність. Це мотивує Частину III.

# ЧАСТИНА III. SUBIT-TOPOS — категорія, класифікатор множин, типи й логіка

*Додається: (1) класифікація довільних множин станів P (а не лише одноточкових траєкторій), (2) категоріальна структура, (3) динамічна теорія типів і модальна логіка.*

## III.1 Ω-класифікатор для множин станів (виправлена версія)

Нехай P ⊆ S₀×ℛ — довільна множина розширених станів (не обов'язково одна траєкторія).

> **⚠ ВИПРАВЛЕННЯ.** У вихідній специфікації "Семантичний Універсум v2.0" визначення було:
> "1. STABLE, якщо F(P)⊆P. 2. METASTABLE, якщо F(P)⊆P, але P⊈F(P)."
> Умова METASTABLE (F(P)⊆P і P⊈F(P)) є **підмножиною** умови STABLE (F(P)⊆P) — тобто за правилом 1 будь-яка множина, що задовольняє умову METASTABLE, вже класифікувалася б як STABLE, і правило 2 ніколи фактично не спрацювало б, якщо читати означення як незалежні, невпорядковані твердження. Нижче — виправлена, логічно неперетинна версія (еквівалентна до того, що, найімовірніше, малося на увазі, і узгоджена з паралельним означенням у вихідній специфікації SUBIT-TOPOS v1.0, яка використовувала F⁻¹(P)⊆P для повної інваріантності):

```
STABLE      ⟺  F(P) = P                       (точна нерухома множина: і пряма, і зворотна інваріантність)
METASTABLE  ⟺  F(P) ⊊ P                        (строго пряма інваріантність: «пастка», що стискається)
CYCLIC      ⟺  ∃k>1 (мінімальне): Fᵏ(P) = P,  і F(P) ≠ P
CHAOTIC     ⟺  жодна з умов вище не виконується за жодного k у розглянутому горизонті
```

Ці чотири умови взаємовиключні за побудовою: перевірка відбувається послідовно (STABLE → METASTABLE → CYCLIC → CHAOTIC), і кожна наступна умова явно виключає попередні (на відміну від вихідної версії). Ω = {STABLE, METASTABLE, CYCLIC, CHAOTIC}.

**Семантична істина.** P є істинним ⟺ P є STABLE ⟺ F(P)=P. Це — внутрішній критерій, що не потребує зовнішнього спостерігача: істина — динамічний інваріант, а не статична відповідність.

**Важливо (наслідок Частини II.5):** для P, що є одноточковою множиною чи скінченною траєкторією в S₀×ℛ, CHAOTIC математично недосяжний з тих самих причин, що й на рівні SUBIT⁺ — цей клас стає нетривіальним лише для нескінченних P у S_∞ (Частина IV).

## III.2 Алгебра Ω (виправлена таблиця заперечення)

Частковий порядок: `CHAOTIC < CYCLIC < METASTABLE < STABLE` (лінійний порядок — ланцюг).

Для довільного скінченного ланцюга операції ∧=min, ∨=max автоматично утворюють дистрибутивну ґратку, а разом із релятивним псевдодоповненням `a→b := ⊤, якщо a≤b; інакше b` — **алгебру Гейтінга** (стандартний факт: лінійно впорядкована множина завжди є алгеброю Гейтінга, відому як алгебра Ґеделя).

**Кон'юнкція (∧ = min):**

| ∧ | STABLE | METASTABLE | CYCLIC | CHAOTIC |
|---|---|---|---|---|
| **STABLE** | STABLE | METASTABLE | CYCLIC | CHAOTIC |
| **METASTABLE** | METASTABLE | METASTABLE | CYCLIC | CHAOTIC |
| **CYCLIC** | CYCLIC | CYCLIC | CYCLIC | CHAOTIC |
| **CHAOTIC** | CHAOTIC | CHAOTIC | CHAOTIC | CHAOTIC |

**Диз'юнкція (∨ = max):**

| ∨ | STABLE | METASTABLE | CYCLIC | CHAOTIC |
|---|---|---|---|---|
| **STABLE** | STABLE | STABLE | STABLE | STABLE |
| **METASTABLE** | STABLE | METASTABLE | METASTABLE | METASTABLE |
| **CYCLIC** | STABLE | METASTABLE | CYCLIC | CYCLIC |
| **CHAOTIC** | STABLE | METASTABLE | CYCLIC | CHAOTIC |

**Заперечення ¬a = a→CHAOTIC** (тобто a→⊥, де ⊥=CHAOTIC — найменший елемент ланцюга):

> **⚠ ВИПРАВЛЕННЯ.** За формулою a→b=⊤ якщо a≤b, інакше b: якщо a=CHAOTIC (=⊥), то a≤⊥, тож ¬CHAOTIC=⊤=STABLE. Для будь-якого **іншого** a (METASTABLE, CYCLIC, STABLE) маємо a>⊥, тож за формулою ¬a = b = CHAOTIC. Тобто **заперечення будь-якого не-нижнього елемента лінійного ланцюга дорівнює найнижчому елементу**. Вихідна специфікація стверджувала ¬METASTABLE=CYCLIC і ¬CYCLIC=METASTABLE ("слабке") — це не відповідає стандартній формулі відносного псевдодоповнення. Коректна таблиця:

| a | ¬a (виправлено) |
|---|---|
| STABLE | CHAOTIC |
| METASTABLE | CHAOTIC |
| CYCLIC | CHAOTIC |
| CHAOTIC | STABLE |

**Виключений третій усе одно не виконується** (висновок зберігається, лише хід доведення виправлено): METASTABLE ∨ ¬METASTABLE = METASTABLE ∨ CHAOTIC = METASTABLE ≠ STABLE. Це — ознака **інтуїціоністської (точніше, Ґеделевої лінійної)** логіки.

## III.3 Категорія SUBIT

**Об'єкти:** X = (S_X, ℛ_X, F_X, g_X), S_X⊆S₀ (на цьому рівні — підмножина скінченного простору; узагальнення на S_∞ — Частина IV), з аксіомою замкненості F_X(S_X×ℛ_X)⊆S_X×ℛ_X.

**Морфізми:** φ: X→Y — пара (φ_S, φ_ℛ), що задовольняє умову динамічної сумісності (еволюція-потім-відображення = відображення-потім-еволюція):

```
φ_S(π_S(F_X(ŝ))) = π_S(F_Y(φ_S(π_S(ŝ)), φ_ℛ(π_ℛ(ŝ))))
```

Композиція і тотожні морфізми — покомпонентно; асоціативність і нейтральність id спадкуються автоматично від композиції функцій. **SUBIT є категорією.**

**Спеціальні конструкції:**
- Термінальний об'єкт 1: S₁={∗}, ℛ₁={id}; для будь-якого X — рівно один морфізм X→1.
- Добуток X×Y: S_{X×Y}=S_X×S_Y, F_{X×Y}((s₁,s₂),(ρ₁,ρ₂))=(F_X(s₁,ρ₁),F_Y(s₂,ρ₂)).
- Експоненціал Yˣ: S_{Yˣ} = {динамічно сумісні відображення S_X→S_Y}.

> **⚠ ВИПРАВЛЕННЯ / застереження, посилене порівняно з вихідним текстом.** Вихідна конструкція експоненціала F_{Yˣ}(φ)(s)=F_Y(φ(F_X⁻¹(s))) явно вимагає **оборотності F_X** (сама специфікація це зазначала дужкою "якщо F_X оборотний", але потім все одно стверджувала загальний висновок "SUBIT — декартово замкнена категорія" як доведений факт). Для довільного об'єкта X, чия динаміка F_X незворотна (типовий випадок — детерміновані динамічні системи зазвичай стискають простір станів і не є бієкціями), ця конструкція експоненціала **не визначена**. Тому твердження "SUBIT — CCC" **не є доведеним у загальному вигляді** цією конструкцією; воно справджується щонайбільше на повній підкатегорії об'єктів з оборотним F, або вимагає окремої, тут не наданої конструкції (наприклад, через часткові функції чи інший функтор експоненціювання). Це залишено як **відкрите питання** (див. також Частину IV.6).

## III.4 SUBIT як proto-topos

Категорія є топосом, якщо вона має (T1) скінченні ліміти, (T2) експоненціали, (T3) субоб'єктний класифікатор. SUBIT задовольняє (T1) безумовно; (T2) — лише умовно (III.3 вище). Умова (T3) виконується в **динамічній версії**: замість Ω={⊤,⊥} — Ω_SUBIT={stable,metastable,cyclic,chaotic}, що утворює алгебру Гейтінга (III.2), а не булеву алгебру. **SUBIT — proto-topos**: структура, що прагне задовольнити умови топосу, з двома застереженнями (умовний T2, нестандартний Ω замість T3 у строгому сенсі). Чи є SUBIT топосом у строго класичному сенсі — відкрите питання (Частина IV.7).

## III.5 Динамічна теорія типів

```
Γ ⊢ t : A @ τ
```

означає: у контексті Γ стан t має тип A на фазі еволюції τ. Тип A — не статична класифікація, а **клас траєкторій зі спільним режимом стабільності**: A = {ŝ | stability_class(ŝ)=mode_A}.

**Правила виведення (вибірково):**

```
Рефлексивність:   Γ, x:A@τ ⊢ x : A@τ
Еволюція типу:    Γ⊢t:A@τ,  F(A)⊆B  ⟹  Γ⊢F(t):B@(τ+1)
Стабільний тип:   Γ⊢t:A@τ,  F(A)=A  ⟹  Γ⊢t:□A@τ
Потенційний тип:  Γ⊢t:A@τ,  ∃k:Fᵏ(A)⊆B  ⟹  Γ⊢t:◇B@τ
Циклічний тип:    Γ⊢t:A@τ,  ∃k:Fᵏ(A)=A  ⟹  Γ⊢t:◯A@τ
```

*(Умову "Стабільного типу" виправлено з F(A)⊆A на F(A)=A відповідно до виправленого означення STABLE у III.1.)*

**Атракторна рівність** (замінює класичну ідентичність): s ~_F t ⟺ ∃k: Fᵏ(s)=Fᵏ(t).

## III.6 Модальна логіка

| Модальність | Визначення | Сенс |
|---|---|---|
| □A | F(A)=A | стабільна/необхідна істина |
| ◇A | ∃k≥0: Fᵏ(s)∈A | потенційна стабілізація |
| ◯A | ∃k>0: Fᵏ(s)∈A і Fᵏ(A)=A | циклічне повернення |

**Аксіоми:** (M1) □A→A; (M2) □A→□□A; (M3) □(A→B)→(□A→□B); (M4) ◇A↔¬□¬A; (M5) ◯A→◇A; (M6) □A→◯A; (M7) ◯◯A↔◯A; (M8) □A∧□B→□(A∧B). **Не виконуються** ◇A∨◇¬A і □A∨□¬A.

**Відповідність Ω:** stable↔□A; metastable↔A∧¬□A; cyclic↔◯A∧¬□A; chaotic↔¬◇A.

## III.7 Внутрішня мова й універсальний об'єкт (на скінченному рівні)

Примітивні терми: s,t,u (State), ρ,σ (Rule), p,q (Prop). Конструктори: who(s), where(s), when(s), rule(ŝ), evolve(ŝ)=F(ŝ). Пропозиційні: stable(p), reaches(s,A), cycle(A), morphism(φ,X,Y), iso(φ).

**Універсальний об'єкт U (скінченна версія)** = (S₀×ℛ*, F*, g*), де ℛ* — коди всіх допустимих правил, F* — інтерпретатор, g* — переписувач правил; для будь-якого X існує морфізм φ_X:U→X. *(Теорема існування U надана в оригінальних текстах лише як конструктивний ескіз, без повного доведення динамічної сумісності кодування для довільного X; тут це вказано явно, а не приховано — це асертивно правдоподібне, але не строго доведене твердження, аналогічне до універсальної машини Тюрінга.)*

**Принцип симуляції.** Будь-який скінченний автомат (Q,δ) вкладається в SUBIT⁺: обрати ін'єкцію ι:Q→S₀; для кожного a∈Σ побудувати ρ_a такий, що f_{ρ_a}(ι(q))=ι(δ(q,a)); визначити g:ρ_a↦ρ_{next}. **Наслідок:** SUBIT⁺ — умовно універсальна симуляційна система; універсальність — через внутрішню самореференцію, а не нескінченність множини станів.

**Висновок рівня III:** SUBIT-TOPOS дає повну категоріальну, логічну й типову структуру, але залишається **обмеженим скінченним простором станів S₀** — а отже, як показано в II.5, категорія CHAOTIC у ньому математично не досяжна, і глибина рекурсії WHO/WHERE/WHEN (якщо сама "громада" чи "фаза" має внутрішню структуру, що вимагає розгортання) не підтримується. Це мотивує Частину IV.

# ЧАСТИНА IV. SUBIT_∞ — рекурсивний нескінченний простір станів

*Додається: (1) простір станів як коіндуктивна нерухома точка (потенційно нескінченна глибина), (2) генуїнно недосяжна на попередніх рівнях категорія CHAOTIC, (3) справжня (виправлена) семантична ультраметрика.*

## IV.1 Рекурсивний простір станів S_∞

```
S_∞ = νX. (X × X × X)
```

де ν — коіндуктивний фікс-пойнт-оператор (найбільша нерухома точка функтора X↦X×X×X). Явно: S_∞ — множина всіх скінченних та нескінченних дерев глибини ≤ω з рівно трьома нащадками в кожному вузлі, листя яких належать A; склеювання за бісимуляцією (у сенсі антифундаційної аксіоми Aczel, 1988) допускає цикли (самореферентні стани s=(s,s,s) тощо). Елемент s∈S_∞ записується як s=(w,x,y), w,x,y∈S_∞.

## IV.2 Вкладення S₀ ⊂ S_∞

Кожен атом a∈A ототожнюється з "константним" самореферентним станом (a,a,a)∈S_∞ (нерухома точка розгалуження — коректний спосіб вкласти скінченний алфавіт у коіндуктивний універсум, стандартний у теорії неусталь­­кованих множин). Тоді:

```
S₀ = { (w,x,y) | w,x,y ∈ A-як-константні-стани } ⊂ S_∞
```

— вкладення як листків "глибини 1" (перший рівень розгалуження над константними атомами). **SUBIT-64 = скінченна апроксимація глибини 1 об'єкта S_∞.** Це дає змогу розгортати глибші структури — наприклад, якщо WHO ("громада") сама вимагає внутрішнього WHO/WHERE/WHEN опису (підгрупи зі своїми координатами), це природно представляється станом глибини >1 в S_∞, чого SUBIT-64 принципово не підтримує.

## IV.3 Простір правил ℛ (загальний випадок)

```
ℛ = { f: S_∞ → S_∞ | f обчислювана в розширеному сенсі (задана скінченним описом) }
```

На відміну від Частини II, тут ℛ **може бути нескінченною** (незлічена чи злічена множина допустимих функцій). Саме це знімає обмеження II.5: якщо S_∞×ℛ нескінченна, принцип Діріхле більше не гарантує зрештової періодичності, і генуїнно неперіодичні (chaotic у строгому сенсі) траєкторії стають математично можливими.

## IV.4 Оператор еволюції, розширений на S_∞

```
F: S_∞ × ℛ → S_∞ × ℛ
F(s, ρ) = (f_ρ(s), g(ρ, s))
```

— формально ідентичний до Частини II.3, але тепер визначений на потенційно нескінченному S_∞. Усі означення Частини III.1–III.6 (Ω-класифікатор, алгебра, типи, модальна логіка) переносяться дослівно, замінюючи S₀ на S_∞ — жодне з них не спиралося на скінченність S₀ по суті.

**Множина атракторів:** Fix(F) = {ŝ∈S_∞×ℛ | F(ŝ)=ŝ} — найменша F-інваріантна (STABLE) множина.

## IV.5 Семантична ультраметрика d_Ω (виправлена конструкція)

> **⚠ ВИПРАВЛЕННЯ (найважливіше в цій версії).** Вихідна специфікація визначала:
> `d_Ω(ŝ,t̂) = Σₙ₌₀^∞ 2⁻ⁿ · δ(Fⁿŝ, Fⁿt̂)`, де δ(x,y)=0 якщо Ω(x)=Ω(y), інакше 1, і стверджувала (Теорема 4.1), що це — ультраметрика.
>
> **Це невірно в загальному вигляді.** Контрприклад: нехай траєкторії x,y,z такі, що Ω(Fⁿx)=Ω(Fⁿy) для всіх n, крім n=5 (де вони відрізняються), і Ω(Fⁿy)=Ω(Fⁿz) для всіх n, крім n=3. Тоді, з поточковою ультраметричною властивістю самого δ (якщо Ω(x)=Ω(y) і Ω(y)=Ω(z), то Ω(x)=Ω(z)), необхідно матимемо Ω(F³x)≠Ω(F³z) *і* Ω(F⁵x)≠Ω(F⁵z) — тобто x і z відрізняються одразу на **двох** індексах. Тоді:
> ```
> d_Ω(x,z) = 2⁻³ + 2⁻⁵ = 0.15625
> max(d_Ω(x,y), d_Ω(y,z)) = max(2⁻⁵, 2⁻³) = 0.125
> ```
> `0.15625 > 0.125` — строга нерівність трикутника **порушена**. Формула-сума дає лише звичайну метрику (за умови, що взагалі є метрикою), а не ультраметрику.
>
> **Виправлена конструкція** (стандартна "перша розбіжність" / valuation-style, аналог p-адичної метрики):
> ```
> n₀(ŝ, t̂) := min{ n ≥ 0 : Ω(Fⁿŝ) ≠ Ω(Fⁿt̂) },   якщо таке n існує
> d_Ω(ŝ, t̂) := 2⁻ⁿ⁰⁽ŝ,t̂⁾,   або 0, якщо Ω(Fⁿŝ)=Ω(Fⁿt̂) для всіх n
> ```
> Ця конструкція **справді** задовольняє строгу нерівність трикутника: якщо x,y узгоджуються (за Ω-класом) до індексу n₁ (тобто n₀(x,y)≥n₁), а y,z — до n₂, то x,z узгоджуються щонайменше до min(n₁,n₂) (за поточковою транзитивністю δ), тобто n₀(x,z)≥min(n₁,n₂), звідки d_Ω(x,z)≤max(d_Ω(x,y),d_Ω(y,z)). Це стандартний і коректний результат (аналогічний до метрики на просторі нескінченних послідовностей / p-адичних чисел).

**Теорема IV.1 (виправлена).** d_Ω, визначена через першу розбіжність, є ультраметрикою на S_∞×ℛ **за модулем відношення** "мати однаковий Ω-клас на кожному кроці" — тобто це **псевдоультраметрика** на S_∞×ℛ: d_Ω(ŝ,t̂)=0 означає, що Ω-траєкторії ŝ і t̂ *назавжди* збігаються за класом, що **не** тягне за собою ŝ=t̂ буквально (дві різні точки можуть мати тотожні Ω-траєкторії). d_Ω стає **справжньою** метрикою лише на факторпросторі (S_∞×ℛ)/~_Ω, де ~_Ω ототожнює точки з однаковою нескінченною Ω-послідовністю. *(Вихідна специфікація стверджувала d_Ω(ŝ,t̂)=0 ⟺ ŝ=t̂ — це занадто сильне твердження; виправлено вище.)*

**Теорема IV.2 (зберігається).** Простір ((S_∞×ℛ)/~_Ω, d_Ω) — тотально незв'язний: кожна куля одночасно відкрита й замкнена (clopen); топологія нульвимірна. *(Це стандартний наслідок конструкції "перша розбіжність" і зберігається без змін після виправлення IV.5.)*

**Практичний сенс:** d_Ω дає кількісну міру того, наскільки швидко дві емпіричні гіпотези (як дві траєкторії) розходяться в передбаченнях: n₀ — це "горизонт узгодженості" (перший крок, на якому дві конкуруючі гіпотези дають різні Ω-передбачення), а не просто бінарне "відрізняються/ні".

## IV.6 Категорія SUBIT на рівні S_∞ і статус CCC

Усі означення III.3 переносяться, замінюючи S₀ на S_∞. Застереження щодо експоненціала (III.3, оборотність F_X) залишається в силі й на цьому рівні — воно не є артефактом скінченності, а стосується загальної (не)оборотності динамічних систем. **Статус "SUBIT — CCC" залишається умовним**, як і на рівні III.

**Універсальний об'єкт U (повна версія):** U=(S_∞×ℛ*, F*, g*), де ℛ* — коди всіх допустимих правил; для будь-якого X∈SUBIT існує морфізм φ_X:U→X через кодування encode_X:S_X→S_∞, encode_R:ℛ_X→ℛ*. **Аналогія з λ-численням:** стан↔λ-терм, правило↔λ-функція, F↔β-редукція. *(Як і на рівні III, це — правдоподібна, але не повністю доведена конструкція; повне доведення вимагало б явно пред'явити encode_X для довільного X і перевірити динамічну сумісність, чого вихідні тексти не роблять.)*

## IV.7 SUBIT_∞ як proto-topos: статус відкритого питання

Як і в III.4, (T1) і (T3-у-динамічній-версії) виконуються, (T2) — умовно. Додатково, на рівні S_∞ виникає питання: чи є Ω_SUBIT (з III.1–III.2, перенесений на S_∞) дійсно **внутрішнім об'єктом** категорії SUBIT у строгому категоріальному сенсі (тобто чи існує природне перетворення Hom(-,Ω)≅Sub(-))? Це категоріальне твердження **не доведено** в жодному з вихідних текстів і залишається відкритим питанням.

## IV.8 Метатеоретичні властивості

**Несуперечність.** У скінченній апроксимації (Частини I–III) усі аксіоми виконуються в скінченній моделі — несуперечність тривіальна. Для повного S_∞ несуперечність спадкує від коректності коіндуктивної конструкції (Aczel, 1988) за умови, що ℛ — множина справді обчислюваних (well-defined) функцій; для довільної, необмеженої ℛ це не гарантовано автоматично.

**Неповнота (лише за аналогією, не теорема).** Якщо ℛ достатньо багата (містить правила самоопису), то за аналогією з теоремами Гьоделя можна очікувати існування тверджень внутрішньої мови, які істинні (F(P)=P), але не доводяться в системі. *(Це залишається евристичною аналогією; строге кодування арифметики й діагональної леми в SUBIT-∞ вихідні тексти не надають, тому кваліфікується як гіпотеза, а не доведений результат — на відміну від того, як це подавалося раніше.)*

**Ієрархія виразності (підсумок):**

```
SUBIT-64  ⊂  SUBIT⁺  ⊂  SUBIT-TOPOS  ⊂  SUBIT_∞
```

| Рівень | Додає | Не має / обмеження |
|---|---|---|
| SUBIT-64 | статичний алфавіт 64 станів | жодної динаміки |
| SUBIT⁺ | правило ρ як частина стану; оператор F, g | тільки одноточкові траєкторії; CHAOTIC математично недосяжний (II.5) |
| SUBIT-TOPOS | класифікатор множин Ω; категорія; типи; модальна логіка | простір станів усе ще скінченний (S₀); CCC — умовний |
| SUBIT_∞ | нескінченний рекурсивний S_∞; генуїнна CHAOTIC-категорія; ультраметрика d_Ω | CCC і топосний статус лишаються відкритими (IV.6–IV.7) |

**Відношення до відомих систем:**

| Система | Відношення до SUBIT_∞ |
|---|---|
| Скінченні автомати (DFA/NFA) | Вкладаються через принцип симуляції (III.7) |
| Класична логіка | Спеціальний випадок при Ω={⊤,⊥} (Частина I) |
| Лінійна (Ґеделева) логіка / інтуїціоністська логіка | Ω-алгебра Гейтінга (III.2, виправлена) |
| Лямбда-числення | U — λ-інтерпретатор (III.7, IV.6), F↔β-редукція |
| Класичні топоси (Гротендік) | Узагальнення: SUBIT — proto-topos з умовним T2 (III.4, IV.7) |
| Білаттис Белнапа (FOUR) | Логічна реалізація алфавіту 𝔸 (I.1) |
| p-адичні метрики / простори послідовностей | Структурна модель для виправленої d_Ω (IV.5) |
| Коіндукція / non-well-founded set theory | Конструкція S_∞ (IV.1, за Aczel 1988) |

## IV.9 Відкриті питання

- Чи існує коректна, доведена (а не лише ескізна) конструкція експоненціала для об'єктів із необоротним F_X — і якщо ні, чи є SUBIT CCC лише на підкатегорії оборотних систем?
- Чи є Ω_SUBIT дійсно внутрішнім субоб'єктним класифікатором у строгому категоріальному сенсі (IV.7)?
- Чи можна строго закодувати арифметику в SUBIT_∞, щоб неповнота (IV.8) стала теоремою, а не аналогією?
- Гіпотеза фрактальної межі: чи множина ρ, для яких траєкторія фіксованого s₀ є CHAOTIC (тепер математично змістовна категорія завдяки Частині IV), утворює множину дробової Хаусдорфової розмірності відносно природної топології на ℛ? *(Відкрито.)*
- Чи існує нерухома точка інтерпретації s*: F(s*,ρ*)=(s*,ρ*) для довільної досить багатої ℛ ("абсолютна інтерпретація")? Слідує з теорем про нерухому точку за умов компактності й неперервності F, які тут не встановлені в загальному вигляді.

# ЧАСТИНА V. Епістемологічний статус і протокол застосування

*Ця частина — нормативна для будь-якого застосування SUBIT-∞ поза межами самої нотації.*

## V.1 Що доведено, а що — ні

**Доведено (як властивості нотації, після виправлень вище):**
- Несуперечність скінченної апроксимації (Частини I–III).
- Ω з операціями ∧,∨,¬ утворює алгебру Гейтінга на лінійному ланцюгу (III.2, виправлено).
- Виправлена d_Ω — (псевдо)ультраметрика на S_∞×ℛ (IV.5, виправлено).
- Принцип вкладення скінченних автоматів у SUBIT⁺ (III.7).

**Не доведено / відкрито:**
- CCC-статус категорії SUBIT для об'єктів із необоротним F (III.3, IV.6).
- Строгий топосний статус Ω_SUBIT (IV.7).
- Строга (не лише аналогова) неповнота (IV.8).
- Існування U як універсального інтерпретатора для *довільного* X (конструкція лише ескізна).

**Принципово недоведенне засобами самої нотації:**
- Що будь-яка конкретна емпірична система (історична, соціальна, біологічна), до якої застосовують SUBIT-∞, справді еволюціонує за правилом ρ, обраним дослідником.
- Що присвоєння Ω-класу конкретній емпіричній множині станів є істинним у сенсі відповідності реальності — це завжди інтерпретаційне судження дослідника, а не обчислена величина.

## V.2 Мінімальний протокол застосування

1. Визначити емпіричну систему й дослідницьке питання.
2. Сформулювати конкуруючі гіпотези як явні правила ρ₁, ρ₂, … — кожне з конкретним механізмом.
3. Вивести для кожного ρᵢ відмінне емпіричне передбачення (розрізняльний тест).
4. Зібрати реальні дані (першоджерела), що підтверджують чи спростовують кожне передбачення.
5. Лише після цього — присвоїти Ω-клас переходу як компактний підсумковий ярлик уже здобутого емпіричного висновку, а не замінник кроку 4.
6. Явно розрізняти в тексті: що доведено формально (як у Частинах I–IV), що підтверджено джерелом, а що є інтерпретаційною пропозицією дослідника.

Цей протокол застосовано й перевірено на практиці в супровідному дослідженні формування й занепаду цивілізації Караль-Супе.

## Додаток A. Гексаграмна реалізація SUBIT-64

Кожному з 64 станів s=(b₁b₂b₃)(b₄b₅b₆) відповідає унікальна гексаграма І-Цзін — від ䷀ (111111) до ䷿ (010101), успадкована з вихідної специфікації SUBIT-TOPOS v1.0 без змін і використовувана виключно як комбінаторна нотація.

## Підсумкова формула

```
SUBIT-∞ = ( S_∞, ℛ, F, g, Ω, d_Ω, U, ℒ )
```

**Центральна теза:** правило належить стану; істина визначається стабільністю (F(P)=P); відстань вимірює горизонт розбіжності траєкторій (перша розбіжність, не сума); існує (правдоподібний, не повністю доведений) універсальний інтерпретатор; категорія прагне бути декартово замкненою, за умови оборотності.

**Центральне методологічне застереження:** ніщо з вищенаведеного не є твердженням про те, що будь-яка конкретна річ у світі справді "stable" чи "chaotic" — це завжди інтерпретаційний крок дослідника, який мусить бути підкріплений незалежними емпіричними даними, а не самою нотацією.

# SUBIT-∞

## Формальна специфікація ієрархії SUBIT-64 ⊂ SUBIT⁺ ⊂ SUBIT-TOPOS ⊂ SUBIT_∞

**Версія 5.0**

---

## Анотація

SUBIT-∞ — формальна нотаційна система для опису самореферентних динамічних систем: систем, у яких правило еволюції є частиною самого стану, а не зовнішнім параметром. Специфікація побудована як строга кумулятивна ієрархія з чотирьох рівнів, кожен з яких є самодостатньою, завершеною системою і додає до попереднього рівно один новий шар структури:

```
SUBIT-64  ⊂  SUBIT⁺  ⊂  SUBIT-TOPOS  ⊂  SUBIT_∞
```

**SUBIT-64** фіксує статичний алфавіт із 64 архетипних станів. **SUBIT⁺** додає внутрішнє правило еволюції та оператор, що змінює і стан, і правило. **SUBIT-TOPOS** підносить це до категорії з класифікатором стабільності, типовою системою та модальною логікою. **SUBIT_∞** знімає обмеження скінченності, розширюючи простір станів до рекурсивної коіндуктивної структури, у якій категорія "хаотичної" динаміки вперше стає математично змістовною.

Специфікація завершується нормативним розділом про епістемологічний статус системи: SUBIT-∞ є інструментом формулювання й структурування гіпотез, а не емпіричною теорією; жодна з його формальних властивостей (несуперечність, алгебраїчна структура, метричні властивості) не переноситься автоматично на істинність тверджень про будь-яку конкретну емпіричну систему, до якої його застосовують.

# ЧАСТИНА I. SUBIT-64 — алфавіт станів

## 1. Алфавіт примітивів

В основі системи лежить скінченна множина примітивних маркерів потужності 4. Специфікація параметризована вибором конкретної реалізації цієї множини; визначено дві стандартні, взаємно ізоморфні реалізації.

**Семантична реалізація** — для прикладного моделювання конкретних емпіричних систем:

```
A_WHO   = { ME, WE, YOU, THEY }
A_WHERE = { EAST, SOUTH, WEST, NORTH }
A_WHEN  = { SPRING, SUMMER, AUTUMN, WINTER }
```

**Логічна реалізація** — білаттис Белнапа, для формально-логічного трактування:

```
𝔸 = { T, F, B, N }
```

де T = True (Yang), F = False (Yin), B = Both (діалетеїчне значення — і істинне, і хибне), N = Neither (паракомплетне значення — ні істинне, ні хибне). Множина 𝔸 несе структуру білаттиса з двома незалежними частковими порядками:

```
порядок істинності:  F <ₜ N <ₜ T,   F <ₜ B <ₜ T
порядок інформації:   N <ᵢ F <ᵢ B,   N <ᵢ T <ᵢ B
```

Кожне значення обох реалізацій кодується двома бітами (bigram = b₁b₂):

| Bigram | Семантична реалізація | Логічна реалізація |
|---|---|---|
| 10 | ME / EAST / SPRING | T |
| 11 | WE / SOUTH / SUMMER | B |
| 01 | YOU / WEST / AUTUMN | F |
| 00 | THEY / NORTH / WINTER | N |

Відповідність між реалізаціями є ізоморфізмом множин потужності 4: він дозволяє переносити алгебраїчні результати (зокрема, структуру класифікатора Ω у Частині III) між реалізаціями, не встановлюючи жодного змістовного ототожнення на кшталт "ME означає True" — це технічна, а не інтерпретаційна еквівалентність.

## 2. Простір станів S₀

**Означення 2.1.** Простір станів SUBIT-64 визначається як

```
S₀ = A_WHO × A_WHERE × A_WHEN  (або 𝔸³ у логічній реалізації)
|S₀| = 4³ = 64
```

Кожен стан — трійка s = (α, β, γ), де α ∈ A_WHO, β ∈ A_WHERE, γ ∈ A_WHEN. Стан кодується 6-бітним словом b₁b₂b₃b₄b₅b₆, де b₁b₂ кодує WHO, b₃b₄ — WHERE, b₅b₆ — WHEN.

**Гексаграмна нотація.** Розбивши код на дві тригами — Lower Trigram (b₁b₂b₃) і Upper Trigram (b₄b₅b₆) — кожному стану можна зіставити унікальну гексаграму І-Цзін (повна таблиця відповідності 64 гексаграм наведена в Додатку A). Ця нотація використовується виключно як компактний, однозначний комбінаторний запис 6-бітного слова; жодне додаткове тлумачення традиційної символіки триграм (стихії, сторони світу, кольори) не є частиною формальної специфікації.

**Властивості рівня.** S₀ є статичним простором: відсутній оператор переходу, відсутня внутрішня динаміка, класифікатор істини тривіальний (двозначний: стан або належить розглянутій підмножині, або ні). SUBIT-64 — необхідний алфавіт архетипів, але сам по собі не описує зміну, причинність чи перехід між станами.

# ЧАСТИНА II. SUBIT⁺ — скінченна самореферентна динаміка

## 3. Простір правил і розширений стан

**Означення 3.1.** Простір правил еволюції на цьому рівні — скінченна множина

```
ℛ = { ρ₁, ρ₂, …, ρₙ },   ρᵢ : S₀ → S₀
```

**Означення 3.2.** Розширеним станом називається пара

```
ŝ = (s, ρ) ∈ S₀ × ℛ
```

де ρ — активне правило еволюції, що належить самому стану. Це — принципова відмінність SUBIT⁺ від класичного скінченного автомата: у автоматі функція переходу δ зовнішня щодо стану q і фіксується раз і назавжди; у SUBIT⁺ правило ρ є компонентою стану ŝ і само підлягає зміні.

## 4. Оператор еволюції та ієрархія рівнів самореференції

**Означення 4.1.** Оператор еволюції

```
F : S₀ × ℛ → S₀ × ℛ
F(s, ρ) = ( f_ρ(s), g(ρ, s) )
```

де f_ρ : S₀ → S₀ — застосування поточного правила до стану; g : ℛ × S₀ → ℛ — функція метаеволюції, що визначає, як саме правило змінюється залежно від поточного правила й стану.

**Аксіома 4.1 (детермінованість).** F — тотальна функція, визначена для всіх пар (s, ρ) ∈ S₀ × ℛ.

Ця конструкція виявляє чотири рівні самореференції, недоступні класичному автомату:

```
Рівень 0:   s = (α, β, γ)      базовий стан (без правила)
Рівень 1:   ŝ = (s, ρ)         стан із внутрішнім правилом
Рівень 2:   F(ŝ) = (s′, ρ′)    еволюція стану і правила за один крок
Рівень 3:   g(ρ, s) → ρ′       метаеволюція: зміна способу зміни
```

Класичний автомат має лише Рівень 0 і фіксований (незмінний) Рівень 2; SUBIT⁺ додає Рівні 1 і 3, стираючи межу між даними, програмою й метапрограмою.

## 5. Траєкторії у скінченному просторі

**Означення 5.1.** Траєкторією розширеного стану ŝ₀ називається послідовність

```
τ(ŝ₀) = (ŝ₀, ŝ₁, ŝ₂, …),   ŝₙ₊₁ = F(ŝₙ)
```

**Твердження 5.1 (скінченна періодичність).** Оскільки S₀ × ℛ — скінченна множина, а F — детермінована функція цієї множини в саму себе, для будь-якого ŝ₀ існують m ≥ 0 і k ≥ 1 такі, що ŝ_{m+k} = ŝ_m. Іншими словами, кожна траєкторія в SUBIT⁺ рано чи пізно входить у цикл, можливо, після скінченного передперіодичного "хвоста" (принцип Діріхле, застосований до відображення скінченної множини в себе).

Це дає повний перелік типів одноточкових траєкторій, реалізованих на цьому рівні:

| Тип | Умова |
|---|---|
| Атрактор (нерухома точка) | F(ŝ) = ŝ ⟺ f_ρ(s) = s і g(ρ, s) = ρ |
| Орбіта (цикл довжини k > 1) | Fᵏ(ŝ) = ŝ і ∀i < k: Fⁱ(ŝ) ≠ ŝ |
| Передперіодична траєкторія | ∃m > 0, k ≥ 1: ŝ_{m+k} = ŝ_m, а ŝ₀, …, ŝ_{m−1} — без повторів |

Жодна одноточкова траєкторія на цьому рівні не може бути неперіодичною в строгому сенсі — генуїнно неперіодична динаміка вимагає нескінченного простору станів чи правил (Частина IV).

**Алгоритм 5.1 (класифікація за скінченним наближенням).**

```
Вхід: ŝ₀ = (s₀, ρ₀), горизонт пошуку N_max
visited ← ∅
для n = 0, 1, …, N_max:
    якщо ŝₙ ∈ visited:
        L ← n − позначку входження ŝₙ до visited
        якщо L = 1: повернути "атрактор"
        інакше:      повернути "цикл довжини L"
    додати ŝₙ до visited
    ŝₙ₊₁ ← F(ŝₙ)
якщо N_max вичерпано без повтору:
    повернути "цикл довший за N_max" (горизонт пошуку недостатній)
```

# ЧАСТИНА III. SUBIT-TOPOS — категорія, класифікатор, типи

## 6. Класифікатор стабільності Ω

Означення й результати цієї Частини формулюються для довільної множини P ⊆ S₀ × ℛ (а не лише для одноточкової траєкторії, як у Частині II), і залишаються дослівно чинними при заміні S₀ на S_∞ у Частині IV.

**Означення 6.1.** Клас стабільності множини P визначається послідовною перевіркою:

```
STABLE       ⟺  F(P) = P
METASTABLE   ⟺  F(P) ⊊ P
CYCLIC       ⟺  існує мінімальне k > 1 таке, що Fᵏ(P) = P, і F(P) ≠ P
CHAOTIC      ⟺  жодна з умов вище не виконується за жодного розглянутого k
```

Умови взаємовиключні за побудовою: STABLE фіксує точну (двобічну) інваріантність; METASTABLE — строго одностороннє стягування; CYCLIC — періодичне повернення без фіксованої точки; CHAOTIC — відсутність будь-якої зі знайдених регулярностей.

**Означення 6.2 (семантична істина).** Множина станів P вважається істинною тоді й лише тоді, коли вона стабільна: P істинне ⟺ F(P) = P. Це — внутрішній критерій: він не апелює до жодного зовнішнього спостерігача, а випливає безпосередньо з динаміки F. Істина трактується як динамічний інваріант, а не як статична відповідність.

**Зауваження (математична межа скінченного рівня).** Оскільки на рівні SUBIT-64/SUBIT⁺ простір S₀ × ℛ скінченний, а кожна одноточкова траєкторія обов'язково зрештою періодична (Твердження 5.1), клас CHAOTIC для одноточкових траєкторій на цьому рівні не реалізується: будь-яка достатньо тривала одноточкова траєкторія в скінченному просторі класифікується як STABLE або CYCLIC. Категорія CHAOTIC стає математично змістовною лише для множин P у нескінченному просторі S_∞ (Частина IV) — це і є структурна причина, чому ієрархія потребує виходу за межі скінченного рівня.

## 7. Алгебра Ω

На множині Ω = {STABLE, METASTABLE, CYCLIC, CHAOTIC} визначено лінійний порядок:

```
CHAOTIC < CYCLIC < METASTABLE < STABLE
```

Для будь-якого лінійно впорядкованого скінченного ланцюга операції ∧ = min і ∨ = max автоматично утворюють дистрибутивну ґратку. Разом із релятивним псевдодоповненням, визначеним стандартною формулою для ланцюгів (a → b := найбільший елемент ⊤, якщо a ≤ b; інакше b), ця структура утворює **алгебру Гейтінга** (відому в літературі як алгебра Ґеделя — лінійна модель інтуїціоністської логіки).

**Кон'юнкція (∧ = min):**

| ∧ | STABLE | METASTABLE | CYCLIC | CHAOTIC |
|---|---|---|---|---|
| **STABLE** | STABLE | METASTABLE | CYCLIC | CHAOTIC |
| **METASTABLE** | METASTABLE | METASTABLE | CYCLIC | CHAOTIC |
| **CYCLIC** | CYCLIC | CYCLIC | CYCLIC | CHAOTIC |
| **CHAOTIC** | CHAOTIC | CHAOTIC | CHAOTIC | CHAOTIC |

**Диз'юнкція (∨ = max):**

| ∨ | STABLE | METASTABLE | CYCLIC | CHAOTIC |
|---|---|---|---|---|
| **STABLE** | STABLE | STABLE | STABLE | STABLE |
| **METASTABLE** | STABLE | METASTABLE | METASTABLE | METASTABLE |
| **CYCLIC** | STABLE | METASTABLE | CYCLIC | CYCLIC |
| **CHAOTIC** | STABLE | METASTABLE | CYCLIC | CHAOTIC |

**Заперечення.** Визначаючи ¬a := a → CHAOTIC (тобто a → ⊥, де ⊥ = CHAOTIC — найменший елемент ланцюга) і застосовуючи формулу релятивного псевдодоповнення: якщо a = CHAOTIC, то a ≤ ⊥, звідки ¬CHAOTIC = ⊤ = STABLE. Для будь-якого іншого a (METASTABLE, CYCLIC чи STABLE) маємо a > ⊥, тож за тією самою формулою ¬a = ⊥ = CHAOTIC. Отже:

| a | ¬a |
|---|---|
| STABLE | CHAOTIC |
| METASTABLE | CHAOTIC |
| CYCLIC | CHAOTIC |
| CHAOTIC | STABLE |

Тобто заперечення будь-якого елемента, відмінного від найнижчого, дорівнює найнижчому елементу ланцюга — типова властивість лінійних алгебр Гейтінга.

**Твердження 7.1 (недосяжність класичного виключеного третього).**

```
METASTABLE ∨ ¬METASTABLE = METASTABLE ∨ CHAOTIC = METASTABLE ≠ STABLE
```

Закон виключеного третього не виконується для METASTABLE (і аналогічно для CYCLIC) — Ω_SUBIT є моделлю інтуїціоністської, а не класичної (булевої) логіки.

## 8. Категорія SUBIT

**Означення 8.1 (об'єкти).** Об'єктом категорії SUBIT є система X = (S_X, ℛ_X, F_X, g_X), де S_X ⊆ S₀ (у цій Частині; S_X ⊆ S_∞ у Частині IV), ℛ_X ⊆ ℛ, з аксіомою замкненості F_X(S_X × ℛ_X) ⊆ S_X × ℛ_X.

**Означення 8.2 (морфізми).** Морфізм φ: X → Y — пара відображень φ = (φ_S, φ_ℛ), φ_S: S_X → S_Y, φ_ℛ: ℛ_X → ℛ_Y, що задовольняє умову динамічної сумісності:

```
φ_S( π_S( F_X(ŝ) ) ) = π_S( F_Y( φ_S(π_S(ŝ)), φ_ℛ(π_ℛ(ŝ)) ) )
```

тобто застосування еволюції з наступним відображенням дає той самий результат, що й відображення з наступною еволюцією. Композиція та тотожні морфізми визначаються покомпонентно; асоціативність композиції та нейтральність тотожного морфізма спадкуються безпосередньо від відповідних властивостей композиції функцій. Отже, SUBIT є категорією.

**Спеціальні об'єкти й конструкції:**

- *Термінальний об'єкт* **1**: S₁ = {∗}, ℛ₁ = {id}. Для будь-якого X існує рівно один морфізм X → 1.
- *Добуток* X × Y: S_{X×Y} = S_X × S_Y, ℛ_{X×Y} = ℛ_X × ℛ_Y, F_{X×Y}((s₁,s₂),(ρ₁,ρ₂)) = (F_X(s₁,ρ₁), F_Y(s₂,ρ₂)), із проекційними морфізмами π₁, π₂.
- *Експоненціал* Yˣ: S_{Yˣ} визначається як множина динамічно сумісних відображень S_X → S_Y, з оператором евалюації F_{Yˣ}(φ)(s) = F_Y(φ(F_X⁻¹(s))).

**Зауваження про застосовність експоненціала.** Наведена конструкція експоненціала спирається на існування оберненого відображення F_X⁻¹, тобто застосовна лише до об'єктів X, чия динаміка F_X оборотна. Для об'єктів із необоротною динамікою (типовий випадок для дисипативних систем, де траєкторії стягуються) ця конкретна конструкція не визначена, і статус декартової замкненості категорії SUBIT у повному обсязі є відкритим питанням (розділ 17); вона встановлена лише для повної підкатегорії об'єктів з оборотним F.

## 9. SUBIT як proto-topos

Категорія є топосом, якщо вона має (T1) скінченні ліміти, (T2) експоненціали й (T3) субоб'єктний класифікатор. SUBIT задовольняє (T1) безумовно й (T2) на підкатегорії оборотних об'єктів (розділ 8). Умова (T3) виконується в динамічній, а не класичній формі: замість двозначного Ω = {⊤, ⊥} — Ω_SUBIT = {STABLE, METASTABLE, CYCLIC, CHAOTIC}, що за розділом 7 утворює алгебру Гейтінга, а не булеву алгебру. У цьому сенсі SUBIT є **proto-topos**: категорія, що прагне задовольнити умови топосу з двома застереженнями — умовним T2 і нестандартним, некласичним Ω замість строгого T3. Чи є SUBIT топосом у повністю формальному категоріальному сенсі (тобто чи існує природний ізоморфізм Hom(–, Ω) ≅ Sub(–)), залишається відкритим питанням (розділ 17).

## 10. Динамічна теорія типів

**Судження.** Γ ⊢ t : A @ τ означає: у контексті Γ стан t має тип A на фазі еволюції τ. Тип A трактується не як статична класифікація, а як клас траєкторій зі спільним режимом стабільності: A = {ŝ | stability_class(ŝ) = mode_A}.

**Правила виведення:**

```
Рефлексивність:    ───────────────────
                   Γ, x:A@τ ⊢ x : A@τ

Еволюція типу:     Γ ⊢ t:A@τ     F(A) ⊆ B
                   ──────────────────────────
                   Γ ⊢ F(t) : B @ (τ+1)

Стабільний тип:    Γ ⊢ t:A@τ     F(A) = A
                   ──────────────────────────
                   Γ ⊢ t : □A @ τ

Потенційний тип:   Γ ⊢ t:A@τ     ∃k: Fᵏ(A) ⊆ B
                   ─────────────────────────────
                   Γ ⊢ t : ◇B @ τ

Циклічний тип:     Γ ⊢ t:A@τ     ∃k: Fᵏ(A) = A
                   ─────────────────────────────
                   Γ ⊢ t : ◯A @ τ
```

**Атракторна рівність.** Замість класичної ідентичності вводиться відношення s ~_F t ⟺ ∃k: Fᵏ(s) = Fᵏ(t): два стани еквівалентні, якщо їхні траєкторії зрештою збігаються.

## 11. Модальна логіка

| Модальність | Визначення | Змістовний сенс |
|---|---|---|
| □A | F(A) = A | стабільна (необхідна) істина: A — точний F-інваріант |
| ◇A | ∃k ≥ 0: Fᵏ(s) ∈ A | потенційна стабілізація: існує момент входження в A |
| ◯A | ∃k > 0: Fᵏ(s) ∈ A і Fᵏ(A) = A | циклічне повернення |

**Аксіоми:**

```
(M1)  □A → A
(M2)  □A → □□A
(M3)  □(A → B) → (□A → □B)
(M4)  ◇A ↔ ¬□¬A
(M5)  ◯A → ◇A
(M6)  □A → ◯A
(M7)  ◯◯A ↔ ◯A
(M8)  □A ∧ □B → □(A ∧ B)
```

Не виконуються ◇A ∨ ◇¬A (не кожна траєкторія стабілізується) і □A ∨ □¬A (класичний виключений третій не діє). Відповідність класифікатору Ω: stable ↔ □A; metastable ↔ A ∧ ¬□A; cyclic ↔ ◯A ∧ ¬□A; chaotic ↔ ¬◇A.

## 12. Внутрішня мова, універсальний об'єкт, принцип симуляції

**Внутрішня мова.** Примітивні терми: s, t, u — терми типу State; ρ, σ — терми типу Rule; p, q — терми типу Prop. Конструктори: who(s), where(s), when(s) — проекції на координати стану; rule(ŝ) — витягування правила зі стану; evolve(ŝ) = F(ŝ). Пропозиційні конструктори: stable(p), reaches(s, A), cycle(A), morphism(φ, X, Y), iso(φ).

**Універсальний об'єкт.** U = (S₀ × ℛ*, F*, g*), де ℛ* — коди всіх допустимих локальних правил, F* — інтерпретатор, що приймає код (s, ρ) системи X і обчислює f_ρ(s), g* — оператор переписування правил. Для будь-якого X ∈ SUBIT постулюється існування морфізму φ_X: U → X, що робить U внутрішнім універсальним інтерпретатором категорії — структурний аналог λ-числення (стан ↔ λ-терм, правило ↔ λ-функція, F ↔ β-редукція) та універсальної машини Тюрінга. Конструкція кодування encode_X, encode_R для довільного X подається на рівні принципу; повне доведення динамічної сумісності кодування для кожного конкретного X виходить за межі цієї специфікації.

**Принцип симуляції.** Будь-який скінченний автомат (Q, δ) вкладається в SUBIT⁺: обираємо ін'єкцію ι: Q → S₀; для кожного символу a ∈ Σ будуємо правило ρ_a ∈ ℛ таке, що f_{ρ_a}(ι(q)) = ι(δ(q, a)); визначаємо метаеволюцію g: ρ_a ↦ ρ_{наступний символ}. Це вкладення зберігає стани, переходи й прийняття (q ∈ F_accept ↦ ι(q) ∈ Fix(F)). Наслідок: SUBIT⁺ є умовно універсальною симуляційною системою, де універсальність досягається не через нескінченність множини станів, а через внутрішню самореференцію — здатність системи переписувати власні правила.

# ЧАСТИНА IV. SUBIT_∞ — рекурсивний нескінченний простір

## 13. Простір станів S_∞

**Означення 13.1.** Рекурсивний простір станів визначається як найбільша коалгебраїчна нерухома точка функтора X ↦ X × X × X:

```
S_∞ = νX. (X × X × X)
```

де ν — коіндуктивний фікс-пойнт-оператор. Явна конструкція: S_∞ — множина всіх скінченних та нескінченних дерев глибини не більше ω, у яких кожен внутрішній вузол має рівно трьох нащадків, а листя належать алфавіту A; ототожнення за бісимуляцією (у сенсі антифундаційної аксіоми, Aczel, 1988) допускає циклічні, самореферентні структури. Елемент s ∈ S_∞ записується як трійка s = (w, x, y), де w, x, y ∈ S_∞.

**Вкладення S₀ ⊂ S_∞.** Кожен атом a ∈ A ототожнюється з константним самореферентним станом (a, a, a) ∈ S_∞ — нерухомою точкою розгалуження, що є стандартним способом вкладення скінченного алфавіту в коіндуктивний універсум. Тоді

```
S₀ = { (w, x, y) | w, x, y — константні стани над A } ⊂ S_∞
```

є вкладенням SUBIT-64 як листків "глибини 1" над цими константними атомами: SUBIT-64 постає скінченною апроксимацією глибини 1 об'єкта S_∞. Це дає змогу представляти глибші структури — наприклад, якщо координата WHO ("спільнота") сама вимагає внутрішнього опису через власні WHO/WHERE/WHEN (підгрупи зі своїми координатами), це природно виражається станом глибини більшої за 1 в S_∞, чого SUBIT-64 принципово не підтримує.

**Простір правил.** У загальному випадку

```
ℛ = { f : S_∞ → S_∞ | f обчислювана в розширеному сенсі (задана скінченним описом) }
```

На відміну від Частини II, ℛ тут може бути нескінченною множиною. Саме це знімає обмеження Твердження 5.1: якщо S_∞ × ℛ нескінченна, принцип Діріхле більше не гарантує зрештової періодичності будь-якої траєкторії, і генуїнно неперіодична (chaotic у строгому сенсі) динаміка стає математично можливою.

## 14. Динаміка й категорія на рівні S_∞

Оператор еволюції

```
F : S_∞ × ℛ → S_∞ × ℛ
F(s, ρ) = ( f_ρ(s), g(ρ, s) )
```

формально ідентичний до Частини II, але тепер визначений на потенційно нескінченному S_∞. Усі означення розділів 6–11 (класифікатор Ω, алгебра, типи, модальна логіка) переносяться дослівно із заміною S₀ на S_∞: жодне з них по суті не спиралося на скінченність носія.

**Множина атракторів.** Fix(F) = {ŝ ∈ S_∞ × ℛ | F(ŝ) = ŝ} є найменшою STABLE-множиною відносно F.

**Категорія.** Означення 8.1–8.2 переносяться дослівно із заміною S_X ⊆ S₀ на S_X ⊆ S_∞. Застереження щодо оборотності F_X в конструкції експоненціала (розділ 8) не є артефактом скінченності й лишається чинним і на цьому рівні: статус повної декартової замкненості категорії SUBIT-∞ так само обмежений підкатегорією оборотних об'єктів.

**Універсальний об'єкт (повна версія).** U = (S_∞ × ℛ*, F*, g*); для будь-якого X ∈ SUBIT постулюється морфізм φ_X: U → X через кодування encode_X: S_X → S_∞, encode_R: ℛ_X → ℛ*, за тим самим застереженням щодо повноти доведення, що й у розділі 12.

## 15. Семантична ультраметрика d_Ω

**Означення 15.1 (перша розбіжність).** Для двох розширених станів ŝ, t̂ ∈ S_∞ × ℛ визначимо

```
n₀(ŝ, t̂) := min{ n ≥ 0 : Ω(Fⁿŝ) ≠ Ω(Fⁿt̂) },   якщо таке n існує
```

і покладемо

```
d_Ω(ŝ, t̂) := 2^(−n₀(ŝ,t̂)),  якщо n₀ визначено;   d_Ω(ŝ, t̂) := 0,  якщо Ω(Fⁿŝ) = Ω(Fⁿt̂) для всіх n ≥ 0
```

Тобто d_Ω вимірює **горизонт узгодженості** — перший крок еволюції, на якому дві траєкторії починають класифікуватися по-різному за Ω, а не суму розбіжностей на кожному окремому кроці.

**Теорема 15.1 (властивості ультраметрики).** Функція d_Ω задовольняє:

1. d_Ω(ŝ, t̂) = 0 тоді й лише тоді, коли Ω(Fⁿŝ) = Ω(Fⁿt̂) для всіх n ≥ 0 (Ω-траєкторії ŝ і t̂ збігаються назавжди);
2. d_Ω(ŝ, t̂) = d_Ω(t̂, ŝ) (симетричність — очевидна з симетричності означення δ);
3. сильна нерівність трикутника d_Ω(ŝ, û) ≤ max(d_Ω(ŝ, t̂), d_Ω(t̂, û)).

*Доведення (3).* Нехай n₁ = n₀(ŝ, t̂), n₂ = n₀(t̂, û). Тоді для всіх n < min(n₁, n₂) маємо Ω(Fⁿŝ) = Ω(Fⁿt̂) і Ω(Fⁿt̂) = Ω(Fⁿû), звідки за транзитивністю рівності Ω(Fⁿŝ) = Ω(Fⁿû) для всіх таких n. Отже, n₀(ŝ, û) ≥ min(n₁, n₂), звідки d_Ω(ŝ, û) ≤ 2^(−min(n₁,n₂)) = max(2^(−n₁), 2^(−n₂)) = max(d_Ω(ŝ, t̂), d_Ω(t̂, û)). ∎

Ця конструкція є прямим аналогом стандартної метрики на просторі нескінченних послідовностей (і, структурно, p-адичної метрики): відстань визначається першою точкою розбіжності, а не сумою розбіжностей за всіма кроками.

**Зауваження (пседометричність).** Властивість (1) показує, що d_Ω(ŝ, t̂) = 0 не тягне за собою ŝ = t̂ у буквальному сенсі: два різні розширені стани можуть мати тотожну, назавжди узгоджену Ω-траєкторію. Тому d_Ω, строго кажучи, є **псевдоультраметрикою** на S_∞ × ℛ; вона стає справжньою ультраметрикою на факторпросторі (S_∞ × ℛ)/~_Ω, де ~_Ω ототожнює точки з однаковою нескінченною Ω-послідовністю.

**Теорема 15.2 (нульвимірність).** Простір ((S_∞ × ℛ)/~_Ω, d_Ω) є тотально незв'язним: кожна відкрита куля одночасно є замкненою множиною (clopen), топологія — нульвимірна. *(Стандартний наслідок ультраметричності, побудованої за принципом першої розбіжності.)*

**Інтерпретаційне зауваження.** У прикладному застосуванні d_Ω дає кількісну міру того, наскільки швидко дві конкуруючі гіпотези (як дві траєкторії розширених станів) розходяться в передбаченнях: n₀ — це перший крок еволюції, на якому вони починають давати різні Ω-передбачення, а не просто бінарну ознаку "збігаються/не збігаються".

## 16. Метатеоретичні властивості

**Несуперечність.** У скінченній апроксимації (Частини I–III) усі аксіоми виконуються в скінченній моделі — несуперечність цього рівня тривіальна. Для повного S_∞ несуперечність спадкує від коректності коіндуктивної конструкції найбільшої нерухомої точки (Aczel, 1988), за умови, що ℛ складається зі справді коректно визначених (well-defined) обчислюваних функцій.

**Аналогія з неповнотою.** Якщо простір правил ℛ достатньо багатий, щоб містити правила самоопису системи, правдоподібно очікувати — за аналогією з теоремами Гьоделя про арифметику — існування тверджень внутрішньої мови, які є істинними (F(P) = P) у моделі, але не виводяться синтаксично засобами самої системи. Ця відповідність є евристичною аналогією, а не доведеною теоремою: строге кодування арифметики й побудова діагональної леми всередині SUBIT-∞ виходять за межі цієї специфікації.

**Ієрархія виразності:**

| Рівень | Додає | Головне обмеження |
|---|---|---|
| SUBIT-64 | статичний алфавіт 64 станів | відсутня динаміка |
| SUBIT⁺ | правило ρ як частина стану; F, g | лише одноточкові траєкторії; CHAOTIC недосяжний |
| SUBIT-TOPOS | класифікатор множин Ω; категорія; типи; модальна логіка | простір станів усе ще скінченний; CCC — умовний |
| SUBIT_∞ | нескінченний рекурсивний S_∞; змістовний клас CHAOTIC; ультраметрика d_Ω | CCC і строгий топосний статус лишаються відкритими |

**Відношення до відомих систем:**

| Система | Відношення до SUBIT_∞ |
|---|---|

| Лінійна (Ґеделева) інтуїціоністська логіка | Реалізується через Ω-алгебру Гейтінга (розділ 7) |

## 17. Відкриті питання

- Чи існує конструкція експоненціала, застосовна до об'єктів із необоротною динамікою F_X, і якщо так, чи робить вона категорію SUBIT-∞ декартово замкненою в повному обсязі, а не лише на підкатегорії оборотних об'єктів?
- Чи є Ω_SUBIT дійсно внутрішнім субоб'єктним класифікатором у строгому категоріальному сенсі — тобто чи існує природний ізоморфізм Hom(–, Ω_SUBIT) ≅ Sub(–) для категорії SUBIT?
- Чи можна строго закодувати арифметику всередині SUBIT_∞ так, щоб аналогія з неповнотою (розділ 16) перетворилася на доведену теорему?
- **Гіпотеза фрактальної межі.** Чи утворює множина правил ρ, для яких траєкторія фіксованого початкового стану s₀ є CHAOTIC, множину дробової Хаусдорфової розмірності відносно природної топології на ℛ?
- **Гіпотеза нерухомої точки інтерпретації.** Чи існує розширений стан ŝ* = (s*, ρ*) такий, що F(ŝ*) = ŝ* для довільної достатньо багатої ℛ — "абсолютна інтерпретація", яка більше не змінюється? Наявність такої точки випливала б із теорем про нерухому точку за умов компактності й неперервності F, які в загальному вигляді тут не встановлено.

# ЧАСТИНА V. Застосування

## 18. Епістемологічний статус і протокол застосування

### 18.1 Природа формальних результатів цієї специфікації

Усі теореми й твердження Частин I–IV (несуперечність скінченної апроксимації, алгебраїчна структура Ω як алгебри Гейтінга, ультраметричність d_Ω, вкладення скінченних автоматів, категоріальні конструкції) є твердженнями **про саму нотацію** — про те, як певні символи й функції співвідносяться одне з одним за визначенням. Це не емпіричні твердження, і жодне з них не встановлює й не може встановити, що:

- будь-яка конкретна емпірична система (історична, соціальна, біологічна, екологічна), до якої застосовують апарат SUBIT-∞, дійсно еволюціонує за правилом ρ, яке дослідник обирає для її опису;
- присвоєння конкретній емпіричній множині станів P певного Ω-класу (STABLE, METASTABLE, CYCLIC чи CHAOTIC) є істинним у сенсі відповідності реальності, а не інтерпретаційним судженням дослідника, підігнаним під уже наявні дані.

Формальна коректність нотації — необхідна, але аж ніяк не достатня умова для того, щоб висновок, сформульований мовою SUBIT-∞ про якусь конкретну систему, був емпірично обґрунтованим.

### 18.2 Функція апарату в дослідницькій роботі

SUBIT-∞ функціонує як інструмент структурування гіпотез, а не як їх джерело чи підтвердження. Його користь для дослідника — не в тому, щоб "довести" щось про світ через властивості формалізму, а в тому, щоб:

- змусити явно сформулювати конкретний причинний механізм (ρ) там, де наративний виклад залишає його імпліцитним;
- дати компактну мову для розрізнення типів переходу (наприклад, "chaotic-розпад" проти "metastable-переналаштування правила"), яка потім спрямовує пошук конкретної емпіричної ознаки, що відрізняє ці типи;
- дати кількісну (через d_Ω) або якісну (через Ω) мову для порівняння того, наскільки й де саме розходяться передбачення конкуруючих гіпотез.

### 18.3 Протокол застосування

1. Визначити емпіричну систему та дослідницьке питання.
2. Сформулювати конкуруючі гіпотези як явні, відмінні одне від одного правила ρ₁, ρ₂, …, кожне з конкретним причинним механізмом.
3. Для кожного ρᵢ вивести емпіричне передбачення, відмінне від передбачень інших гіпотез (розрізняльний тест).
4. Зібрати або розглянути наявні першоджерельні дані, що підтверджують чи спростовують кожне передбачення.
5. Лише після виконання кроку 4 — за потреби — присвоїти Ω-клас переходу як компактний підсумковий ярлик уже здобутого емпіричного висновку. Ω-клас ніколи не замінює крок 4.
6. У викладі результатів явно розрізняти три статуси тверджень: (а) формально доведене в самій нотації (Частини I–IV); (б) підтверджене конкретним емпіричним джерелом; (в) інтерпретаційна пропозиція дослідника, що потребує подальшої перевірки.

## Підсумкова формула

```
SUBIT-∞ = ( S_∞, ℛ, F, g, Ω, d_Ω, U, ℒ )
```

де S_∞ = νX.(X × X × X) — рекурсивний простір станів, що містить S₀ = A³ (|S₀| = 64) як вкладену скінченну апроксимацію глибини 1; ℛ — простір внутрішніх правил еволюції; F — оператор динаміки; g — оператор метадинаміки (еволюція правил); Ω — динамічний класифікатор стабільності, що утворює алгебру Гейтінга на чотирьох значеннях; d_Ω — семантична ультраметрика за принципом першої розбіжності; U — універсальний об'єкт-інтерпретатор; ℒ — внутрішня мова динамічної теорії типів і модальної логіки.

**Центральна теза.** Правило належить стану. Істина визначається стабільністю: F(P) = P. Відстань між траєкторіями вимірюється горизонтом їхньої першої розбіжності. Категорія прагне до декартової замкненості на підкатегорії оборотних об'єктів. Універсальний інтерпретатор існує в межах, окреслених принципом симуляції.

**Центральне методологічне положення.** Формальна коректність цієї нотації не переносить сама по собі жодного емпіричного змісту на будь-яку конкретну систему, описану її мовою: висновок про те, що щось у світі є "stable" чи "chaotic", завжди залишається інтерпретаційним кроком дослідника, який потребує незалежного емпіричного обґрунтування.

## ДОДАТОК C.  
## ФОРМАЛЬНИЙ КОД ПРАВИЛ ρ_narod ТА ρ_knyzhna У ПСЕВДОКОДІ SUBIT-∞

У цьому додатку подано формалізований запис двох мовленнєвих стратегій — народної (ρ_narod) та книжної (ρ_knyzhna) — у вигляді псевдокоду, узгодженого з нотацією SUBIT-∞. Наведений код не є виконуваною програмою; він становить точний, однозначний опис правил перетворення мовних одиниць, які використовувалися в розділах 7–8 для моделювання поведінки київських мовців. Відповідно до епістемологічного протоколу SUBIT-∞ (розділ 18 специфікації), цей код є інтерпретаційним інструментом, а не емпіричним доведенням.

---

### C.1. Типи даних і загальні означення

Нехай:

```
A = {T, F, B, N}
```

де  
- **T** — питома риса живої мови;  
- **F** — книжна церковнослов’янська риса;  
- **B** — варіативність, співіснування обох систем;  
- **N** — гіперкоректний, несистемний прояв.

Розширений стан:

```
ŝ = (s, ρ) ∈ S_∞ × ℛ,
```

де `s` — мовна одиниця (дерево з мітками), `ρ` — активне правило.

Правила:

```
ℛ = { ρ_narod, ρ_knyzhna }
```

Оператор еволюції:

```
F(s, ρ) = ( f_ρ(s), g(ρ, s) )
```

де  
`f_ρ` — застосування поточного правила до стану;  
`g` — метаеволюція, тобто зміна самого правила залежно від стану.

---

### C.2. Народна стратегія ρ_narod

Стратегія ρ_narod реалізує живу київську систему. Вона перетворює книжні елементи на народні й зберігає народні без змін.

```
ФУНКЦІЯ f_ρ_narod(s):
    ЯКЩО s є Листок(мітка):
        ПОВЕРНУТИ Листок(перетворити_мітку_народно(мітка))
    ЯКЩО s є Вузол(лівий, середній, правий):
        ПОВЕРНУТИ Вузол(
            f_ρ_narod(лівий),
            f_ρ_narod(середній),
            f_ρ_narod(правий)
        )

ФУНКЦІЯ перетворити_мітку_народно(a):
    # a ∈ A — мітка поточного компонента
    ВИБІР a:
        T: ПОВЕРНУТИ T   # народна риса зберігається
        B: ПОВЕРНУТИ T   # варіативність схиляється до народного боку
        F: ПОВЕРНУТИ T   # книжна риса замінюється народною
        N: ПОВЕРНУТИ B   # гіперкоректний прояв частково впорядковується
```

Коментар. Таке перетворення на рівні міток відповідає дії народної граматики: книжне *тобѣ* → *тобі*, *Лазарю* → *Лазореві*, *ходилъ* → *ходивъ*, *не хотя* → *не хотячи*, *врагъ* → *ворогъ*, *трясавица* → *трясця*. Стан B переходить у T, оскільки в неофіційному мовленні конкуренція розв’язується на користь живої форми; стан N перетворюється на B, адже гіперкоректна форма не стає нормою, але може зберігатися як варіант.

---

### C.3. Книжна стратегія ρ_knyzhna

Стратегія ρ_knyzhna відтворює церковнослов’янську норму. Вона намагається зберегти книжні елементи й повернути народні до книжних відповідників. Однак у реальному мовленні її застосування часто супроводжується збоями, що породжують маркер N.

```
ФУНКЦІЯ f_ρ_knyzhna(s):
    ЯКЩО s є Листок(мітка):
        ПОВЕРНУТИ Листок(перетворити_мітку_книжно(мітка))
    ЯКЩО s є Вузол(лівий, середній, правий):
        ПОВЕРНУТИ Вузол(
            f_ρ_knyzhna(лівий),
            f_ρ_knyzhna(середній),
            f_ρ_knyzhna(правий)
        )

ФУНКЦІЯ перетворити_мітку_книжно(a, контекст):
    # a ∈ A; контекст містить відомості про наявність у мовця книжної вимови
    ВИБІР a:
        T: ЯКЩО контекст.мовець_має_вибуховий_g = ТАК:
                ПОВЕРНУТИ F   # народна риса замінюється книжною
            ІНАКШЕ:
                ПОВЕРНУТИ N   # виникає гіперкоректний збій (напр., "хрішний")
        F: ПОВЕРНУТИ F        # книжна риса зберігається
        B: ЯКЩО контекст.мовець_має_вибуховий_g = ТАК:
                ПОВЕРНУТИ F   # варіативність згортається до книжної
            ІНАКШЕ:
                ПОВЕРНУТИ N   # змішана форма псується гіперкорекцією
        N: ПОВЕРНУТИ N        # помилка не виправляється, а закріплюється
```

Коментар. Параметр `контекст.мовець_має_вибуховий_g` моделює ключову відмінність між книжною та живою фонетикою. Оскільки в київській говірці вибуховий [g] був відсутній, спроба відтворити книжне *грѣшный* давала гіперкоректне *хрішний* (маркер N), а не канонічну форму. У тих позиціях, де книжна норма не вступала в конфлікт із живою фонетикою (наприклад, закінчення *-у* в давальному відмінку), перетворення могло відбуватися без збою: народне *Лазореві* → книжне *Лазарю* (якщо мовець свідомо утримував книжну стратегію).

### C.4. Метаеволюція g: перемикання правил

Оператор метаеволюції визначає, яке правило буде активним на наступному кроці, залежно від поточного правила та комунікативної ситуації.

```
ФУНКЦІЯ g(ρ, s):
    ВИБІР ρ:
        ρ_knyzhna:
            ЯКЩО s.жанр ∈ { "побутовий", "жартівливий" } АБО s.емоційність = ВИСОКА:
                ПОВЕРНУТИ ρ_narod
            ІНАКШЕ ЯКЩО s.жанр = "молитовний" І s.контроль = ВИСОКИЙ:
                ПОВЕРНУТИ ρ_knyzhna
            ІНАКШЕ:
                ПОВЕРНУТИ ρ_narod   # за замовчуванням книжна стратегія не утримується

        ρ_narod:
            ЯКЩО s.жанр = "молитовний" І s.контроль = ВИСОКИЙ:
                ПОВЕРНУТИ ρ_knyzhna  # свідома спроба писати по-книжному
            ІНАКШЕ:
                ПОВЕРНУТИ ρ_narod
```

Коментар. Цей псевдокод формалізує спостереження, зроблені в розділі 3: книжна стратегія активна переважно в стереотипних молитовних формулах, де автор свідомо відтворює завчений текст і контролює написання. Щойно з’являється побутовий контекст або емоційний вигук, метаеволюція перемикає правило на народне. Зворотний перехід від ρ_narod до ρ_knyzhna можливий лише за умови високого свідомого контролю й офіційного жанру.

### C.5. Приклад траєкторії

Розглянемо породження напису *«О горе тобі, Андрониче, ох тобі, небоже!»*.

```
Початковий стан:
    s₀ = Вузол(
            Вигук("О горе тобі"),
            Звертання("Андрониче"),
            Додаток("тобі", "небоже")
         )
    ρ₀ = ρ_knyzhna

Крок 1:
    g(ρ_knyzhna, s₀) = ρ_narod   # емоційний вигук, побутовий докір
    s₁ = f_ρ_narod(s₀)

    f_ρ_narod(Вигук) = Вигук із мітками T (вигук "о горе" — народний)
    f_ρ_narod(Звертання) = Звертання з кличним відмінком T ("Андрониче")
    f_ρ_narod(Додаток) = Додаток із формою "тобі" T, лексемою "небоже" T

Крок 2:
    g(ρ_narod, s₁) = ρ_narod   # система залишається в народному атракторі
    s₂ = f_ρ_narod(s₁) = s₁    # нерухома точка: F(s₁) = s₁

Результат:
    Ω(траєкторія) = STABLE
```

### C.6. Зауваження про інтерпретаційний статус коду

Наведений псевдокод є формалізацією гіпотези про мовленнєву поведінку киян, а не виконуваною моделлю реальної психолінгвістичної діяльності. Його коректність у межах SUBIT-∞ гарантує лише внутрішню несуперечливість опису; відповідність же цього опису історичній дійсності забезпечується виключно свідченнями софійських графіті. Будь-яка зміна емпіричних даних (наприклад, виявлення нових написів із послідовною книжною нормою в побутових жанрах) вимагатиме перегляду параметрів функцій, наведених у цьому додатку.

## Додаток C

## Формальний математичний апарат SUBIT

---

### C.1. Вступ до формального апарату

Цей додаток містить строге визначення математичних структур, що лежать в основі SUBIT. Виклад передбачає знайомство з базовою термінологією монографії (Частина IV), але є самодостатнім у тому сенсі, що всі необхідні означення подано безпосередньо. Формули записано у Unicode-нотації без використання LaTeX. Позначення узгоджено з основною специфікацією SUBIT-∞ (версія 5.2).

Ключові символи:

- A — базовий алфавіт, |A| = 4.
- S₀ — базовий простір станів, S₀ = A³, |S₀| = 64.
- S_∞ — рекурсивний нескінченний простір станів.
- ℛ — простір правил еволюції.
- ŝ = (s, ρ) — розширений стан.
- F — оператор еволюції.
- Ω — класифікатор стабільності.
- d_Ω — семантична ультраметрика.
- P(τ) — канонічна функція траєкторія → множина.

### C.2. Базовий алфавіт і простір станів

#### C.2.1. Алфавіт

**Означення C.1 (Алфавіт).** Базовий алфавіт A є множиною потужності 4. Стандартними реалізаціями є:

- Семантична реалізація: A_WHO = {ME, WE, YOU, THEY}, A_WHERE = {EAST, SOUTH, WEST, NORTH}, A_WHEN = {SPRING, SUMMER, AUTUMN, WINTER}.
- Логічна реалізація: 𝔸 = {T, F, B, N}.

Ці дві реалізації є ізоморфними як множини. Логічна реалізація 𝔸 несе структуру білаттиса Белнапа з двома частковими порядками:

- Порядок істинності: F < N < T, F < B < T.
- Порядок інформації: N < F < B, N < T < B.

Кодування значень двома бітами:

| Bigram | Семантична | Логічна |
|---|---|---|
| 10 | ME / EAST / SPRING | T |
| 11 | WE / SOUTH / SUMMER | B |
| 01 | YOU / WEST / AUTUMN | F |
| 00 | THEY / NORTH / WINTER | N |

#### C.2.2. Базовий простір станів

**Означення C.2 (S₀).** Базовий простір станів визначається як декартів добуток:

S₀ = A_WHO × A_WHERE × A_WHEN

або, у логічній реалізації, S₀ = 𝔸³.

Потужність: |S₀| = 4³ = 64.

Кожен стан s ∈ S₀ є трійкою s = (α, β, γ). Кодується 6-бітним словом b₁b₂b₃b₄b₅b₆, де b₁b₂ кодує WHO, b₃b₄ — WHERE, b₅b₆ — WHEN. Гексаграмна нотація (Додаток A) є компактним записом цього коду.

#### C.2.3. Розширений простір станів S_∞

**Означення C.3 (S_∞).** Рекурсивний простір станів визначається як найбільша коалгебраїчна нерухома точка (кінцева коалгебра) функтора Φ(X) = A ⊔ X × X × X на категорії множин:

S_∞ = νX. (A ⊔ X × X × X)

Це множина всіх дерев (скінченних і нескінченних, глибини не більше ω), у яких кожен вузол є або листом із міткою з A, або внутрішнім вузлом із рівно трьома піддеревами. Ототожнення за бісимуляцією (Анцель, 1988) допускає нескінченні та циклічні структури.

**Вкладення S₀ ⊂ S_∞.** S₀ ототожнюється з підмножиною S_∞, що складається з дерев глибини рівно 1:

S₀ = { (a, b, c) ∈ S_∞ | a, b, c ∈ A ⊂ S_∞ }.

**Лема C.1 (Невиродженість S_∞).** Якщо |A| > 1, то S_∞ не є одноелементною множиною.

*Доведення.* Див. Додаток B основної специфікації. Коротко: функтор без базового конструктора (Φ′(X) = X³) має кінцеву коалгебру, ізоморфну 1 (термінальна послідовність стабілізується на першому кроці). Додавання доданку A вносить розрізняльність на кожному рівні розгортання, що гарантує |S_∞| ≥ |A| > 1. ∎

### C.3. Розширений стан і оператор еволюції

#### C.3.1. Простір правил

**Означення C.4 (Правило еволюції).** Правилом еволюції називається функція ρ : S → S, де S = S₀ або S = S_∞ залежно від контексту. Простір правил позначається ℛ. На рівні SUBIT-64/SUBIT⁺ простір ℛ є скінченним; на рівні SUBIT_∞ він може бути нескінченним, але кожне правило задається скінченним описом (обчислюване правило).

#### C.3.2. Розширений стан

**Означення C.5 (Розширений стан).** Розширеним станом називається пара:

ŝ = (s, ρ) ∈ S × ℛ

де s — поточний стан, ρ — активне правило еволюції. Принципова відмінність від класичного автомата: правило є частиною стану, а не зовнішнім параметром.

#### C.3.3. Оператор еволюції

**Означення C.6 (Оператор F).** Оператор еволюції визначається як:

F : S × ℛ → S × ℛ

F(s, ρ) = ( f_ρ(s), g(ρ, s) )

де:

- f_ρ : S → S — застосування правила ρ до стану s (локальна еволюція);
- g : ℛ × S → ℛ — функція метаеволюції, що визначає, як правило змінюється залежно від поточного правила та стану.

**Аксіома C.1 (Детермінованість).** F є тотальною функцією, визначеною для всіх пар (s, ρ).

#### C.3.4. Ієрархія рівнів самореференції

- Рівень 0: s = (α, β, γ) — базовий стан.
- Рівень 1: ŝ = (s, ρ) — стан із правилом.
- Рівень 2: F(ŝ) = (s′, ρ′) — еволюція стану і правила.
- Рівень 3: g(ρ, s) → ρ′ — метаеволюція.

### C.4. Траєкторії та їх властивості

#### C.4.1. Траєкторія

**Означення C.7 (Траєкторія).** Траєкторією розширеного стану ŝ₀ називається послідовність:

τ(ŝ₀) = (ŝ₀, ŝ₁, ŝ₂, …),  ŝₙ₊₁ = F(ŝₙ) для n ≥ 0.

#### C.4.2. Періодичність у скінченному просторі

**Твердження C.1 (Скінченна періодичність).** Якщо S × ℛ скінченна, то для будь-якого ŝ₀ існують m ≥ 0 і k ≥ 1 такі, що ŝ_{m+k} = ŝ_m. Тобто кожна траєкторія входить у цикл після скінченного передперіодичного хвоста.

*Доведення.* Застосування принципу Діріхле до послідовності {ŝₙ} у скінченній множині S × ℛ. Існують i < j з ŝᵢ = ŝⱼ. Тоді k = j − i, m = i. ∎

**Типи траєкторій:**

- Атрактор (нерухома точка): F(ŝ) = ŝ, тобто f_ρ(s) = s і g(ρ, s) = ρ.
- Орбіта (цикл довжини k > 1): Fᵏ(ŝ) = ŝ і ∀i < k: Fⁱ(ŝ) ≠ ŝ.
- Передперіодична: ∃m > 0, k ≥ 1: ŝ_{m+k} = ŝ_m, а ŝ₀, …, ŝ_{m−1} — без повторів.

#### C.4.3. Множина атракторів

**Означення C.8 (Fix(F)).** Множина атракторів:

Fix(F) = { ŝ ∈ S × ℛ | F(ŝ) = ŝ }.

Fix(F) є найменшою STABLE-множиною відносно F.

### C.5. Класифікатор стабільності Ω

#### C.5.1. Класи стабільності

**Означення C.9 (Класи Ω).** Для довільної множини P ⊆ S × ℛ:

- STABLE ⟺ F(P) = P.
- METASTABLE ⟺ F(P) ⊊ P (строга власна підмножина).
- CYCLIC ⟺ ∃ k > 1: Fᵏ(P) = P і F(P) ≠ P.
- CHAOTIC ⟺ F(P) ⊄ P і ∀ k > 1: Fᵏ(P) ≠ P.

Ці умови взаємовиключні та вичерпні.

*Доведення вичерпності.* Якщо F(P) ⊆ P і F(P) ≠ P, то за індукцією Fᵏ(P) ⊆ F(P) ⊊ P для всіх k ≥ 1, отже Fᵏ(P) ≠ P за жодного k — умова CYCLIC не виконується. Якщо F(P) ≠ P і ∃k>1: Fᵏ(P)=P, то F(P) не може бути власною підмножиною P (інакше Fᵏ(P) ⊆ F(P) ⊊ P), отже F(P) ⊄ P. Таким чином, коли F(P) ≠ P, реалізується рівно одна з умов: METASTABLE (якщо F(P) ⊊ P), CYCLIC (якщо ∃k>1: Fᵏ(P)=P), або CHAOTIC (у решті випадків). ∎

#### C.5.2. Семантична істина

**Означення C.10 (Істина).** P істинне ⟺ F(P) = P (клас STABLE). Істина визначається стабільністю.

#### C.5.3. Алгебра Ω

На Ω = {STABLE, METASTABLE, CYCLIC, CHAOTIC} визначено лінійний порядок:

CHAOTIC < CYCLIC < METASTABLE < STABLE.

Операції ∧ = min, ∨ = max, та релятивне псевдодоповнення (a → b = ⊤, якщо a ≤ b; інакше b) утворюють **алгебру Гейтінга**.

Заперечення: ¬a := a → CHAOTIC.

| a | ¬a |
|---|---|
| STABLE | CHAOTIC |
| METASTABLE | CHAOTIC |
| CYCLIC | CHAOTIC |
| CHAOTIC | STABLE |

**Твердження C.2 (Невиконання виключеного третього).**

METASTABLE ∨ ¬METASTABLE = METASTABLE ∨ CHAOTIC = METASTABLE ≠ STABLE.

Отже, Ω_SUBIT є моделлю інтуїціоністської логіки.

### C.6. Семантична ультраметрика d_Ω

#### C.6.1. Побудова метрики

Для двох розширених станів ŝ, t̂ ∈ S_∞ × ℛ визначимо:

n₀(ŝ, t̂) := min{ n ≥ 0 : Ω(Fⁿŝ) ≠ Ω(Fⁿt̂) }, якщо таке n існує.

Тут Ω(Fⁿŝ) позначає Ω-клас канонічної множини P(τ_{Fⁿŝ}), побудованої за C.8. Якщо n₀ не існує, покладемо d_Ω(ŝ, t̂) := 0. Інакше:

d_Ω(ŝ, t̂) := 2^(−n₀(ŝ, t̂)).

#### C.6.2. Властивості

**Теорема C.1 (Ультраметричність).** d_Ω задовольняє:

1. d_Ω(ŝ, t̂) = 0 ⟺ Ω(Fⁿŝ) = Ω(Fⁿt̂) для всіх n ≥ 0.
2. Симетричність: d_Ω(ŝ, t̂) = d_Ω(t̂, ŝ).
3. Сильна нерівність трикутника: d_Ω(ŝ, û) ≤ max(d_Ω(ŝ, t̂), d_Ω(t̂, û)).

*Доведення (3).* Нехай n₁ = n₀(ŝ, t̂), n₂ = n₀(t̂, û). Для всіх n < min(n₁, n₂) маємо Ω(Fⁿŝ) = Ω(Fⁿt̂) і Ω(Fⁿt̂) = Ω(Fⁿû), звідки Ω(Fⁿŝ) = Ω(Fⁿû). Отже n₀(ŝ, û) ≥ min(n₁, n₂), звідки d_Ω(ŝ, û) ≤ max(d_Ω(ŝ, t̂), d_Ω(t̂, û)). ∎

**Зауваження.** d_Ω є псевдоультраметрикою; вона стає ультраметрикою на факторпросторі (S_∞ × ℛ)/~_Ω, де ~_Ω — відношення еквівалентності, що ототожнює стани з однаковою Ω-послідовністю.

**Теорема C.2 (Нульвимірність).** Факторпростір із d_Ω є тотально незв'язним; його топологія нульвимірна.

### C.7. Рекурсивний простір S_∞: додаткові властивості

#### C.7.1. Структурна метрика d_S

**Означення C.11 (d_S).** Для s, t ∈ S_∞ визначимо δ(s, t) — найменшу глибину розходження піддерев у out(s), out(t). Якщо s, t — листки з різними мітками, δ = 0. Для вузлів (w, x, y) і (w′, x′, y′): δ = 1 + min(δ(w,w′), δ(x,x′), δ(y,y′)). Тоді:

d_S(s, t) := 2^(−δ(s, t)).

**Твердження C.3 (Компактність).** (S_∞, d_S) є компактним простором.

*Доведення (ескіз).* S_∞ гомеоморфний добутковому простору скінченного розгалуження над скінченним алфавітом. Компактність випливає з леми Кеніґа та теореми Тихонова. ∎

#### C.7.2. Неперервність F

**Припущення C.1.** Для кожного ρ, заданого скінченним описом, функція f_ρ є неперервною відносно d_S.

За цього припущення оператор F є неперервним на S_∞ × ℛ із добутковою топологією.

### C.8. Канонічна побудова P(τ)

#### C.8.1. Проблема

Означення Ω застосовується до множин P. Для застосування до траєкторії τ потрібна функція P : Траєкторії → 𝒫(S_∞ × ℛ), яка задовольняє:

- У1 (узгодженість): на скінченному рівні відтворює типологію Твердження C.1.
- У2 (інваріантність): не залежить від довільних параметрів.
- У3 (явність відмови): випадок нелокалізованої поведінки позначається як ⊥.
- У0 (нетривіальність): P(τ) не повинна апріорно визначати відповідь Ω(P(τ)).

#### C.8.2. ω-границя

**Означення C.12 (ω-границя).** ω(ŝ₀) := { ŝ ∈ S_∞ × ℛ | ∃ підпослідовність (nₖ): ŝ_{nₖ} → ŝ у метриці d_S × d_S }.

**Твердження C.4 (Непорожність).** За компактності (C.7.1) і неперервності F (C.7.2), ω(ŝ₀) непорожня для будь-якого ŝ₀.

**Твердження C.5 (Інваріантність ω-границі).** F(ω(ŝ₀)) = ω(ŝ₀).

*Доведення.* Стандартний результат топологічної динаміки. (⊇) Нехай y ∈ ω, тоді ŝ_{nₖ} → y. За компактністю (ŝ_{nₖ−1}) має збіжну підпослідовність до z ∈ ω. З неперервності F: F(z) = lim F(ŝ_{nₖ−1}) = lim ŝ_{nₖ} = y. (⊆) Якщо y ∈ ω, ŝ_{nₖ} → y, то F(ŝ_{nₖ}) = ŝ_{nₖ+1} → F(y), отже F(y) ∈ ω. ∎

**Наслідок C.1 (Колапс).** Якщо P(τ) := ω(ŝ₀), то Ω(P(τ)) = STABLE для будь-якої τ. Це порушує У0, тому потрібна інша побудова.

#### C.8.3. Точка входження та окіл

**Означення C.13.** m(ŝ₀) := min{ n ≥ 0 : ŝₙ ∈ ω(ŝ₀) }.

**Означення C.14.** P_pt(τ) := { ŝ_{m(ŝ₀)} }. Для ε > 0: P_nbhd(τ, ε) := B_ε(ŝ_{m(ŝ₀)}) — куля радіуса ε у d_S.

**Твердження C.6 (Узгодженість).** Якщо S скінченний, P_pt(τ) і Ω-тест дають ту саму відповідь, що Твердження C.1: F(ŝ_m) = ŝ_m ⟺ STABLE; ∃k>1: Fᵏ(ŝ_m) = ŝ_m ⟺ CYCLIC.

**Твердження C.7 (Метастабільність для околу).** Для синґлтона P_pt метастабільність неможлива (образ синґлтона — синґлтон). Тому METASTABLE перевіряється на P_nbhd(τ, ε): STABLE ⟺ F(B_ε) = B_ε; METASTABLE ⟺ F(B_ε) ⊊ B_ε для деякого ε.

#### C.8.4. Підсумкова функція P(τ)

**Означення C.15.** P(τ) :=

- якщо m(ŝ₀) обчислюване за скінченну кількість кроків: повернути пару (P_pt(τ), P_nbhd(τ, ε)) для класифікації;
- інакше: повернути ⊥ («асимптотичний режим не локалізовано»).

⊥ виникає з обчислювальної недосяжності m(ŝ₀), а не з математичної порожності ω (яка завжди непорожня).

#### C.8.5. Крок 0 протоколу

Побудова P(τ) передбачає, що емпіричні дані вже подані як траєкторія в S_∞ × ℛ. Тому протокол застосування включає Крок 0: обґрунтування породжувального розбиття неперервного простору вимірів на скінченний алфавіт A. Це аналог породжувального розбиття в символічній динаміці (Колмогоров, Сінай).

### C.9. Модальна логіка SUBIT

#### C.9.1. Оператори

| Оператор | Визначення | Сенс |
|---|---|---|
| □A | F(A) = A | стабільна істина |
| ◇A | ∃k ≥ 0: Fᵏ(s) ∈ A | потенційна стабілізація |
| ◯A | ∃k > 1: Fᵏ(s) ∈ A і Fᵏ(A) = A | циклічне повернення (k>1) |

#### C.9.2. Аксіоми

1. □A → A
2. □A → □□A
3. □(A → B) → (□A → □B)
4. ◇A ↔ ¬□¬A
5. ◯A → ◇A
6. □A → ◯A
7. ◯◯A ↔ ◯A
8. □A ∧ □B → □(A ∧ B)

Не виконуються: ◇A ∨ ◇¬A, □A ∨ □¬A.

Відповідність Ω: STABLE ↔ □A; METASTABLE ↔ A ∧ ¬□A; CYCLIC ↔ ◯A ∧ ¬□A; CHAOTIC ↔ ¬◇A.

### C.10. Метатеоретичні властивості

#### C.10.1. Несуперечність

У скінченній апроксимації (S₀, ℛ скінченні) усі аксіоми виконуються в скінченній моделі. Для S_∞ несуперечність спадкує від коректності побудови кінцевої коалгебри (Лема C.1).

#### C.10.2. Аналогія з неповнотою

Якщо ℛ достатньо багата, щоб містити правила самоопису, правдоподібно очікувати (за аналогією з теоремами Гьоделя) існування тверджень, істинних (F(P)=P), але не виведених синтаксично. Це евристична аналогія, а не доведена теорема.

#### C.10.3. Ієрархія виразності

| Рівень | Додає | Обмеження |
|---|---|---|
| SUBIT-64 | статичний алфавіт 64 станів | відсутня динаміка |
| SUBIT⁺ | правило ρ у стані; F, g | CHAOTIC недосяжний для одноточкових траєкторій |
| SUBIT-TOPOS | класифікатор Ω; категорія; типи; модальність | простір станів скінченний; експоненціал умовний |
| SUBIT_∞ | нескінченний S_∞; змістовний CHAOTIC; d_Ω | зв'язок Ω із траєкторією вимагає P(τ) |

#### C.10.4. Відкриті питання

- Чи існує експоненціал для необоротних об'єктів, що робить SUBIT декартово замкненою?
- Чи є Ω_SUBIT внутрішнім субоб'єктним класифікатором?
- Чи можна закодувати арифметику так, щоб аналогія з неповнотою стала теоремою?
- Гіпотеза фрактальної межі: множина правил, що ведуть до CHAOTIC, має дробову розмірність?
- Гіпотеза нерухомої точки інтерпретації: чи існує ŝ* з F(ŝ*) = ŝ* для довільної багатої ℛ?

### C.12. Підсумкова формула

SUBIT-∞ = ( S_∞, ℛ, F, g, Ω, d_Ω, U, ℒ, P )

S_∞ = νX.(A ⊔ X × X × X)

S₀ = A³, |S₀| = 64

Ω = {STABLE, METASTABLE, CYCLIC, CHAOTIC}

F(s, ρ) = ( f_ρ(s), g(ρ, s) )

d_Ω(s, t) = 2^(−n₀(s, t))

P(τ) = (P_pt(τ), P_nbhd(τ, ε)) або ⊥

Центральна теза: **Правило належить стану. Істина визначається стабільністю. Відстань — горизонтом першої розбіжності. Простір станів — дерево з мітками. Класифікатор застосовується до канонічно побудованої множини.**

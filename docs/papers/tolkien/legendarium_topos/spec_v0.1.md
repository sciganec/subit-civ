# Специфікація TOPOS-LEGENDARIUM  
## Формальна основа для побудови топосу леґендаріуму Дж. Р. Р. Толкіна  
### Версія 0.1 — робочий проєкт

***

## Анотація

TOPOS-LEGENDARIUM є формальною специфікацією для філологічно обережного моделювання леґендаріуму Дж. Р. Р. Толкіна засобами SUBIT-∞ v5.2. Її мета — не побудувати остаточний «канон» Арди й не перетворити художній корпус на буквально математичний об’єкт. Натомість специфікація визначає спільну мову для опису трьох взаємопов’язаних рівнів: світу Арди, текстів, що його представляють, та редакційної історії цих текстів.

Центральним об’єктом моделі є стратифікований топос:

𝕋_Leg = (𝒲, 𝒯, ℛ, Π, Γ, Κ, Ω_L, 𝒬)

де 𝒲 є шаром світу, 𝒯 — шаром текстового передання, ℛ — шаром редакційних версій, Π — відображенням текстової репрезентації світу, Γ — відображенням редакційної реалізації тексту, Κ — процедурою кодування матеріалу в стани SUBIT, Ω_L — класифікатором стабільності для реконструйованих траєкторій, а 𝒬 — протоколом джерельного статусу тверджень.

Специфікація призначена для подальшої розбудови бази об’єктів, морфізмів, текстових свідчень, редакційних залежностей і тематичних моделей — зокрема моделі зла, уМареності Арди, походження орків, природи смертності, Перснів Влади, падіння Нуменору та есхатології.

# Частина I. Методологічні засади

## 1. Призначення системи

TOPOS-LEGENDARIUM описує не «справжню Арду», а структуру інтерпретаційної роботи з корпусом текстів Толкіна.

Система має чотири функції:

1. Відокремлювати події внутрішнього світу від способів їх текстового передання.
2. Відокремлювати текст від конкретної редакції, рукопису або публікації.
3. Фіксувати джерельний статус тверджень без примусового зведення варіантів до єдиної версії.
4. Давати мінімальну формальну мову для порівняння космологічних, історичних, наративних і редакційних структур.

TOPOS-LEGENDARIUM не є:

- базою «єдино правильного канону»;
- автоматичною машиною інтерпретації;
- заміною текстології;
- доказом того, що Толкін свідомо мислив категоріями SUBIT;
- системою, яка усуває суперечності в рукописному корпусі.

## 2. Епістемологічний принцип

Кожне твердження у системі належить до одного з чотирьох рівнів:

- **Формальне:** випливає з означень TOPOS-LEGENDARIUM або SUBIT.
- **Текстове:** безпосередньо засвідчене визначеним текстом чи фрагментом.
- **Редакційне:** залежить від конкретної версії, рукопису, реконструкції або редакторського рішення.
- **Інтерпретаційне:** пропонує пояснювальний зв’язок між текстовими та формальними даними.

Жодне інтерпретаційне твердження не повинно бути подане як прямий текстовий факт.

## 3. Одиниця аналізу

Базовою одиницею TOPOS-LEGENDARIUM є не «персонаж» і не «книга» самі по собі, а **засвідчена наративна одиниця**:

ν = (e, t, r, c)

де:

- e — реконструйована світова сутність, подія, властивість або відношення;
- t — текстовий носій;
- r — редакційна версія;
- c — контекст: жанровий, наративний, часовий і джерельний.

Наприклад, твердження про ельфійське походження орків не зберігається як абстрактна теза «орки = ельфи», а як набір окремих наративних одиниць, пов’язаних із конкретними текстами та редакціями.

# Частина II. Стратифікована структура

## 4. Центральна конструкція

Топос леґендаріуму визначається як структура:

𝕋_Leg = (𝒲, 𝒯, ℛ, Π, Γ, Κ, Ω_L, 𝒬)

де:

- 𝒲 — категорія світових об’єктів Арди;
- 𝒯 — категорія текстів і форм внутрішнього передання;
- ℛ — категорія редакційних станів;
- Π: 𝒯 → 𝒲 — відображення репрезентації;
- Γ: ℛ → 𝒯 — відображення редакційної реалізації;
- Κ — функція кодування одиниць аналізу у простір SUBIT;
- Ω_L — класифікатор стабільності для реконструйованих траєкторій;
- 𝒬 — система джерельного статусу й рівнів упевненості.

Загальна послідовність доступу до світового твердження:

r → Γ(r) → t → Π(t) → w.

Її слід читати так: редакційна версія r реалізує певний текст t, а текст t репрезентує певний світовий об’єкт, подію або відношення w.

## 5. Аксіома нерівності шарів

Шари 𝒲, 𝒯 та ℛ не ототожнюються:

𝒲 ≠ 𝒯 ≠ ℛ.

Зокрема:

- світова подія ≠ її текстовий опис;
- текстовий опис ≠ рукописна чи друкована редакція;
- редакційна публікація ≠ остаточна авторська доктрина.

Ця аксіома є фундаментальною для будь-якої роботи з пізніми, незавершеними або суперечливими матеріалами.

# Частина III. Шар світу Арди

## 6. Категорія світу 𝒲

Категорія 𝒲 має вигляд:

𝒲 = (Ob_𝒲, Mor_𝒲).

Об’єкти Ob_𝒲 — це світові сутності, події, колективи, простори, часи, артефакти й стани.

Морфізми Mor_𝒲 — це відношення та переходи між ними.

Усі об’єкти 𝒲 мають базову типізацію:

type_W: Ob_𝒲 → Θ_W.

Множина типів Θ_W містить щонайменше:

Θ_W = {
SOURCE,
AINUR,
INCARNATE,
PEOPLE,
KIN,
PLACE,
REALM,
OBJECT,
ARTIFACT,
LANGUAGE,
NAME,
EVENT,
ERA,
LAW,
STATE,
RELATION
}.

## 7. Онтологічні рівні

Для кожного об’єкта w ∈ Ob_𝒲 визначається функція онтологічного рівня:

level(w) ∈ Λ.

Множина Λ має базову ієрархію:

Λ = {
L₀: SOURCE,
L₁: SPIRITUAL_CREATED,
L₂: COSMIC_CREATED,
L₃: ARDA_MATERIAL,
L₄: INCARNATE_HISTORICAL,
L₅: TEXT_INTERNAL
}.

Типова послідовність залежності:

Eru → Ainur → Eä → Arda → Incarnates → Histories.

Це не хронологічна шкала. Вона виражає асиметрію онтологічної залежності.

## 8. Основні класи світових об’єктів

### 8.1. Джерело

Об’єкт типу SOURCE має особливий статус. Він не моделюється як звичайний симетричний агент серед інших об’єктів.

Для Eru:

type_W(Eru) = SOURCE.

Еру є граничною умовою можливості створеного світу, а не просто елементом множини персонажів.

### 8.2. Створені духовні агенти

Для кожного a ∈ Ainur:

type_W(a) = AINUR.

Айнур можуть бути пов’язані з Еа та Ардою через морфізми участі, опіки, оформлення, навчання, влади, служіння або деформації.

### 8.3. Простори

Простір p має тип:

type_W(p) ∈ {PLACE, REALM}.

Приклади класів простору:

- Eä;
- Arda;
- Aman;
- Beleriand;
- Númenor;
- Middle-earth;
- Mordor;
- Valinor;
- Halls_of_Mandos.

### 8.4. Народи та роди

Колективна сутність n має тип:

type_W(n) ∈ {PEOPLE, KIN}.

Приклади:

- Eldar;
- Edain;
- Dwarves;
- Ents;
- Orcs;
- Númenóreans;
- Hobbits.

### 8.5. Події

Подія e має тип:

type_W(e) = EVENT.

Подія повинна мати щонайменше:

event(e) = (agents(e), place(e), time(e), effects(e)).

де:

- agents(e) — множина залучених агентів;
- place(e) — просторова локалізація;
- time(e) — епоха або інший часовий інтервал;
- effects(e) — множина наслідків.

### 8.6. Епохи

Епоха η має тип:

type_W(η) = ERA.

Базова впорядкованість:

Before_Eä < First_Age < Second_Age < Third_Age < Fourth_Age < Eschatological_Horizon.

Нерівність тут означає наративно-історичне передування, а не метафізичну цінність.

# Частина IV. Морфізми світу

## 9. Словник базових морфізмів

Кожний світовий морфізм має форму:

μ: x → y.

Його тип визначається функцією:

type_M: Mor_𝒲 → Θ_M.

Мінімальна множина типів морфізмів:

Θ_M = {
CREATE,
MAKE,
ENTER,
AWAKEN,
BEGET,
NAME,
TEACH,
GIVE,
KEEP,
RULE,
SERVE,
ALLY,
EXILE,
OATH,
TAKE,
STEAL,
CORRUPT,
DEFORM,
ENSNARE,
DOMINATE,
KILL,
DESTROY,
FALL,
REMEMBER,
TELL,
TRANSLATE,
HEAL,
RENEW,
DEPART
}.

## 10. Творення і похідне творення

Морфізм CREATE має обмежену доменну умову:

CREATE: Eru → x.

Для жодного створеного агента a ≠ Eru не допускається морфізм:

CREATE: a → x.

Створені агенти можуть здійснювати похідні дії:

MAKE(a, x);

SHAPE(a, x);

TEACH(a, y);

GUARD(a, z);

CULTIVATE(a, p).

Це розрізнення не є богословським доказом; воно є робочою моделлю асиметрії, яку тексти приписують Еру та створеним істотам.

## 11. Деформаційні морфізми

Морфізм деформації має форму:

DEFORM_μ: x → x′.

Його мінімальна семантична умова:

potential(x′) ⊊ potential(x).

Тут potential(x) означає реконструйовану множину можливостей або властивостей, доступних об’єктові x в обраному текстовому й інтерпретаційному контексті.

DEFORM не означає автоматично моральну провину кожного об’єкта x′. Він позначає структуру зміни, у якій похідний стан має звужені або пошкоджені можливості щодо вихідного стану.

Типові підкласи:

- CORRUPT: моральне або волеве спотворення;
- ENSNARE: обмеження свободи через владу, страх, залежність або примус;
- DOMINATE: підпорядкування іншого агента;
- DESPOIL: пошкодження землі, тіла або створеної форми;
- COUNTERFEIT: імітація чи підміна блага без його повноти.

## 12. Зло як клас морфізмів

Для тематичного модуля зла визначається предикат:

evil(μ) ∈ {T, F, B, N}.

де:

- T — морфізм текстово й інтерпретаційно класифікований як зло;
- F — морфізм не має статусу зла в даному корпусі;
- B — існують підстави і для, і проти такої класифікації;
- N — наявних даних недостатньо.

Первинна робоча гіпотеза:

evil(μ) = T ⇒ type_M(μ) ∈ {
CORRUPT,
DEFORM,
ENSNARE,
DOMINATE,
DESPOIL,
DESTROY
}.

Обернена імплікація не є автоматичною. Наприклад, смерть, руйнування чи відхід можуть бути трагічними, але не в кожному разі становлять зло в метафізичному чи моральному сенсі.

# Частина V. Час, простір і наратив

## 13. Часова структура

Для кожного світового об’єкта або морфізму визначаються часові межі:

begin(x) ∈ Time ∪ {⊥};

end(x) ∈ Time ∪ {⊥}.

Для події:

time(e) = [t₁, t₂].

Якщо точна локалізація неможлива:

time(e) = ⊥.

Позначення ⊥ не означає відсутність події. Воно означає, що її час не локалізовано в межах доступного корпусу.

## 14. Просторова структура

Для об’єкта x може бути визначена функція:

loc(x) ⊆ Place.

Якщо об’єкт має кілька локалізацій, усі вони зберігаються з окремим часовим і джерельним контекстом.

Не допускається автоматичне ототожнення місця з моральним статусом. Наприклад:

loc(Melkor, Utumno) ≠ evil(Utumno).

Моральна або метафізична класифікація місця потребує окремого набору свідчень.

## 15. Наративна перспектива

Для кожної засвідченої одиниці ν визначається перспектива:

perspective(ν) ∈ {
ME,
WE,
YOU,
THEY,
UNSPECIFIED
}.

Ця координата відповідає осі WHO в SUBIT.

Орієнтовне значення:

- ME — індивідуально-фокалізована перспектива;
- WE — колективна або спільнотна перспектива;
- YOU — адресована, діалогічна або нормативна перспектива;
- THEY — зовнішня, дистанційована або хронікальна перспектива;
- UNSPECIFIED — перспектива не встановлена.

Наративна перспектива належить шарові 𝒯, а не безпосередньо світові 𝒲.

# Частина VI. Шар текстів

## 16. Категорія текстів 𝒯

Категорія текстів має вигляд:

𝒯 = (Ob_𝒯, Mor_𝒯).

Об’єкти Ob_𝒯 — це тексти, частини текстів, наративні комплекси, внутрішньосвітові джерела, коментарі й лінгвістичні матеріали.

Кожний текст t має опис:

text(t) = (
title(t),
genre(t),
language(t),
narrative_level(t),
internal_attribution(t),
external_status(t)
).

## 17. Базові типи текстів

Функція типізації:

type_T: Ob_𝒯 → Θ_T.

Мінімальна множина Θ_T:

Θ_T = {
MYTH,
COSMOGONY,
ANNAL,
CHRONICLE,
TALE,
LAY,
POEM,
GENEALOGY,
ESSAY,
LETTER,
DRAFT,
OUTLINE,
COMMENTARY,
EDITORIAL_NOTE,
LINGUISTIC_NOTE,
PUBLISHED_WORK
}.

Один текст може мати кілька типів:

type_T(t) ⊆ Θ_T.

## 18. Внутрішній і зовнішній статус

Кожний текстовий об’єкт має два різні атрибути.

Внутрішній статус:

internal_attribution(t) ∈ {
ELVISH,
NUMENOREAN,
GONDORIAN,
HOBBITISH,
MANNISH,
UNKNOWN,
NONE
}.

Зовнішній статус:

external_status(t) ∈ {
AUTHOR_PUBLISHED,
POSTHUMOUS_EDITED,
MANUSCRIPT,
DRAFT,
LATE_NOTE,
LETTER,
EDITORIAL_RECONSTRUCTION,
COMMENTARY
}.

Приклад принципу:

internal_attribution(t) ≠ external_status(t).

Текст може бути внутрішньосвітово поданий як ельфійська традиція, але зовнішньо бути посмертною редакторською конструкцією.

## 19. Морфізми текстового передання

Множина Mor_𝒯 містить щонайменше:

TRANSMIT;

COMPOSE;

TELL;

RECORD;

COPY;

TRANSLATE;

ABRIDGE;

EXPAND;

COMMENT;

CITE;

FRAME;

ATTRIBUTE.

Текстовий морфізм має форму:

τ: t₁ → t₂.

Приклади:

TRANSLATE: t_ельфійський → t_вестронський;

ABRIDGE: t_повний → t_скорочений;

COMMENT: t_основний → t_коментар;

FRAME: t_внутрішнє_джерело → t_оповідь.

# Частина VII. Шар редакцій

## 20. Категорія редакцій ℛ

Категорія редакцій задається як:

ℛ = (Ob_ℛ, Mor_ℛ).

Об’єкти Ob_ℛ — конкретні редакційні стани: чорновики, рукописи, машинописи, авторські перегляди, опубліковані видання, посмертні компіляції, коментовані публікації.

Кожна редакція r має структуру:

edition(r) = (
work(r),
date(r),
authorial_stage(r),
editorial_stage(r),
completeness(r),
provenance(r)
).

## 21. Типи редакційного статусу

Функція:

status_R: Ob_ℛ → Σ_R.

де:

Σ_R = {
EARLY_DRAFT,
REVISED_DRAFT,
LATE_DRAFT,
MANUSCRIPT,
TYPESCRIPT,
AUTHOR_PUBLISHED,
POSTHUMOUS_EDITED,
EDITORIAL_COMPOSITE,
COMMENTED_PUBLICATION,
UNCERTAIN
}.

Цей статус не є шкалою абсолютної істинності. Він лише визначає спосіб, яким матеріал увійшов до корпусу.

## 22. Редакційні морфізми

Множина Mor_ℛ містить:

REVISE;

REWRITE;

REPLACE;

ABANDON;

MERGE;

SPLIT;

OMIT;

RESTORE;

COMPILE;

EDIT;

PUBLISH;

ANNOTATE.

Редакційний морфізм має форму:

γ: r₁ → r₂.

Він означає конкретний перехід між редакційними станами, а не внутрішньосвітову подію.

## 23. Конфлікт версій

Для двох редакційних тверджень q₁ і q₂ задається відношення:

conflict(q₁, q₂) ∈ {
NONE,
COMPATIBLE_VARIANT,
TENSION,
CONTRADICTION,
UNRESOLVED
}.

Приклад:

conflict(
Origin_Orcs = Elves,
Origin_Orcs = Men
) = CONTRADICTION.

Але ця суперечність належить передусім редакційному шарові. Вона не повинна механічно трактуватися як логічна суперечність у межах одного синхронно заданого світу.

***

# Частина VIII. Відображення між шарами

## 24. Відображення репрезентації Π

Відображення:

Π: 𝒯 → 𝒲

зіставляє текстовому об’єкту або текстовій одиниці реконструйований світовий референт.

Для окремої одиниці:

Π(ν) = e.

Відображення Π не є ін’єктивним:

Π(t₁) = Π(t₂)

можливо, якщо кілька текстів репрезентують один об’єкт або подію.

Відображення Π не є обов’язково функціонально однозначним на рівні інтерпретації:

Π(t) = {w₁, w₂, …, wₙ}

можливо, якщо текст допускає кілька референтних реконструкцій.

## 25. Відображення редакційної реалізації Γ

Відображення:

Γ: ℛ → 𝒯

зіставляє конкретній редакції текстовий об’єкт або текстову форму.

Для одного тексту t можливі кілька редакцій:

Γ(r₁) = Γ(r₂) = t,

r₁ ≠ r₂.

Для одного редакційного комплексу можливі також кілька текстових компонентів:

Γ(r) = {t₁, t₂, …, tₙ}.

Це особливо важливо для посмертних компіляцій.

## 26. Ланцюг джерельної залежності

Кожне світове твердження повинно зберігати шлях походження:

r ⟶ Γ(r) ⟶ t ⟶ Π(t) ⟶ w.

Для твердження q визначається функція джерельного сліду:

trace(q) = (r, t, w, c).

Твердження без trace(q) не може отримати статус текстово підтвердженого.

***

# Частина IX. Джерельний статус і багатозначна логіка

## 27. Логічні значення

Для кожного твердження q у визначеному корпусі C задається значення:

val_C(q) ∈ 𝔹₄.

де:

𝔹₄ = {T, F, B, N}.

Значення мають такий зміст:

- T — підтверджено: є достатня текстова підстава для q, і немає релевантного контртвердження в межах C;
- F — відкинуто: є достатня текстова підстава для ¬q, і немає релевантного підтвердження q у межах C;
- B — обидва: у межах C є підстави і для q, і для ¬q;
- N — жодне: у межах C немає достатньої підстави ні для q, ні для ¬q.

## 28. Залежність від корпусу

Значення твердження залежить від визначення корпусу:

val_C₁(q) ≠ val_C₂(q)

є допустимим.

Наприклад:

val_Published_Silmarillion(Origin_Orcs = Elves) = T;

val_Extended_Legendarium(Origin_Orcs = Elves) = B.

Ця формула є шаблоном застосування, а не готовим остаточним результатом. Її можна використовувати лише після наповнення системи конкретними текстовими свідченнями.

## 29. Рівень джерельної сили

Окремо від логічного значення вводиться рівень джерельної сили:

strength(q) ∈ {
PRIMARY,
PUBLISHED_AUTHORIAL,
LATE_AUTHORIAL,
POSTHUMOUS_EDITORIAL,
DRAFT,
LETTER,
COMMENTARY,
INFERRED
}.

Логічна істинність і сила джерела не тотожні:

val_C(q) = T

не означає автоматично:

strength(q) = PRIMARY.

***

# Частина X. Кодування SUBIT

## 30. Функція кодування Κ

Для застосування інструментів SUBIT вводиться функція:

Κ: ν → ŝ.

де:

ŝ = (s, ρ)

є розширеним станом SUBIT.

Базовий стан:

s = (WHO, WHERE, WHEN).

Для TOPOS-LEGENDARIUM:

WHO ∈ {
ME,
WE,
YOU,
THEY
};

WHERE ∈ {
EAST,
SOUTH,
WEST,
NORTH
};

WHEN ∈ {
SPRING,
SUMMER,
AUTUMN,
WINTER
}.

Семантичне значення цих координат не встановлюється наперед. Для кожного тематичного модуля воно повинно бути явно визначене.

## 31. Принцип локального кодування

Кожне застосування Κ повинно містити окрему декларацію:

coding_context = (
corpus,
unit_of_analysis,
WHO_mapping,
WHERE_mapping,
WHEN_mapping,
rule_of_transition
).

Без coding_context класифікація стану не є валідною для даного дослідження.

## 32. Заборона універсального прочитання

Не допускається твердження:

Κ(ν) = s ⇒ s є «сутністю» ν.

Правильне твердження:

Κ(ν) = s

означає лише, що одиниця ν закодована як s у межах визначеного контексту кодування.

# Частина XI. Динаміка й класифікація

## 33. Траєкторія

Для послідовності пов’язаних наративних одиниць визначається траєкторія:

τ(ŝ₀) = (ŝ₀, ŝ₁, ŝ₂, …).

де:

ŝₙ₊₁ = F(ŝₙ).

Оператор F не є властивістю Толкінового тексту як такого. Він є явним дослідницьким правилом переходу, яке має бути описане в coding_context.

## 34. Функція P(τ)

Для коректної Ω-класифікації траєкторія повинна бути перетворена на класифіковану множину:

P(τ) ∈ 𝒫(S_∞ × ℛ_SUBIT) ∪ {⊥}.

Позначення ⊥ означає:

«асимптотичний режим не локалізовано в межах доступних даних, визначеного корпусу або ресурсів аналізу».

⊥ не означає, що текст не має структури. Воно означає, що модель не має підстав коректно її класифікувати.

## 35. Класифікатор Ω_L

Класифікатор:

Ω_L(P) ∈ {
STABLE,
METASTABLE,
CYCLIC,
CHAOTIC,
UNLOCALIZED
}.

де:

STABLE ⇔ F(P) = P;

METASTABLE ⇔ F(P) ⊊ P;

CYCLIC ⇔ існує мінімальне k > 1 таке, що Fᵏ(P) = P і F(P) ≠ P;

CHAOTIC ⇔ F(P) ⊄ P і для всіх k > 1 виконується Fᵏ(P) ≠ P;

UNLOCALIZED ⇔ P(τ) = ⊥.

Для філологічного застосування Ω_L має статус описового інструмента, а не емпіричного вироку щодо «справжньої природи» тексту.

## 36. Порівняння траєкторій

Для двох траєкторій τ₁ і τ₂ вводиться відстань:

d_Ω(τ₁, τ₂) = 0,

якщо вони не демонструють першої розбіжності у послідовності своїх Ω-класів у межах обраної моделі.

Твердження:

d_Ω(τ₁, τ₂) = 0

не означає:

τ₁ = τ₂.

Воно означає лише Ω-еквівалентність у межах заданого кодування, корпусу та правила переходу.

# Частина XII. Тематичні модулі

## 37. Принцип модульності

TOPOS-LEGENDARIUM не розгортається як одна монолітна інтерпретація. Він складається з тематичних модулів:

𝕄 = {
𝕄_Cosmogony,
𝕄_Evil,
𝕄_Orcs,
𝕄_Elves,
𝕄_Men,
𝕄_Death,
𝕄_Númenor,
𝕄_Rings,
𝕄_Language,
𝕄_Genealogy,
𝕄_Eschatology,
…
}.

Кожен модуль успадковує спільну структуру 𝕋_Leg, але має власні:

- корпус;
- словник об’єктів;
- словник морфізмів;
- процедуру кодування;
- набір джерельних питань;
- критерії достатності свідчень.

## 38. Модуль зла

Робоче позначення:

𝕄_Evil ⊆ 𝕋_Leg.

Його центральне питання:

Як у леґендаріумі зло може бути онтологічно несамостійним, але історично та причинно реальним?

Основні класи для цього модуля:

- CREATE;
- MAKE;
- PRESERVE;
- TAKE;
- CORRUPT;
- DEFORM;
- DOMINATE;
- ENSNARE;
- DESTROY;
- HEAL;
- RENEW.

Робоча інтерпретаційна гіпотеза:

evil(μ) = T ⇒ potential(codomain(μ)) ⊊ potential(domain(μ)).

Ця гіпотеза не є автоматичним правилом. Вона має перевірятися на кожному текстовому випадку.

## 39. Модуль Arda Marred

Робоче позначення:

𝕄_ArdaMarred ⊆ 𝕄_Evil.

Центральна гіпотеза:

Arda_Marred = структурна умова, за якої деформаційні морфізми стають історично доступними для об’єктів Арди.

Важливе застереження:

Arda_Marred ≠ total_evil(Arda).

УМареність не означає тотальної зіпсутості всіх істот або всіх місць. Вона означає вразливість історичного світу до втрати, корупції, насильства, смертності й необоротного занепаду.

## 40. Модуль орків

Робоче позначення:

𝕄_Orcs ⊆ 𝕄_Evil.

Для кожної конкуруючої гіпотези має бути окремий об’єкт:

H_Elvish;

H_Mannish;

H_Bestial;

H_Mixed;

H_Unknown.

Кожна гіпотеза має власний морфізм походження:

φ_Elvish: X_Elf → X_Orc;

φ_Mannish: X_Man → X_Orc;

φ_Bestial: X_Animal → X_Orc.

Жодну з них не можна автоматично призначити остаточною без визначення корпусу C і джерельного сліду trace(q).

# Частина XIV. Інваріанти й заборони

## 48. Інваріант джерельної простежуваності

Кожне текстове або редакційне твердження q повинно мати:

trace(q) ≠ ∅.

Якщо:

trace(q) = ∅,

то:

strength(q) = INFERRED.

## 49. Інваріант контекстності

Для кожного твердження q:

val_C(q)

визначене лише відносно явно заданого корпусу C.

Не допускається:

val(q)

без вказання C, якщо твердження залежить від редакційної варіативності.

## 50. Інваріант нерівності рівнів

Не допускається підміна:

world_event(e) = textual_claim(t).

Правильна форма:

Π(t) ⊢ e,

тобто текст t репрезентує або підтримує реконструкцію e.

## 51. Інваріант інтерпретаційної скромності

Не допускається висновок:

формальна_класифікація(q) ⇒ текстова_істина(q).

Коректна форма:

формальна_класифікація(q) + текстові_свідчення(q) ⇒ інтерпретаційна_гіпотеза(q).

## 52. Інваріант суперечності

Якщо:

val_C(q) = B,

то не допускається автоматичний перехід до:

val_C(q) = T

або

val_C(q) = F

без обмеження чи зміни корпусу C.

# Частина XV. Відкриті питання

## 53. Питання повноти

Чи може бути створений достатньо повний реєстр усіх текстів, редакцій і внутрішньосвітових відношень без перетворення топосу на некерований архів?

## 54. Питання гранулярності

Яким має бути оптимальний масштаб одиниці ν:

- речення;
- абзац;
- сцена;
- розділ;
- мотив;
- редакційний блок;
- цілий текст?

Відповідь може бути різною для різних модулів.

## 55. Питання множинних світів

Чи слід ранні версії леґендаріуму моделювати як суперечливі твердження в одному 𝒲, чи як окремі історично пов’язані світи:

𝒲₁, 𝒲₂, …, 𝒲ₙ?

Робоча відповідь версії 0.1: починати з одного 𝒲 і явного шару ℛ; переходити до множинних 𝒲ᵢ лише там, де варіанти не можуть бути продуктивно зіставлені в одному інтерпретаційному просторі.

## 56. Питання наративного голосу

Як формально відрізняти:

- твердження оповідача;
- ельфійську традицію;
- людську легенду;
- поетичну гіперболу;
- текст у межах внутрішнього світу;
- авторський коментар у листі;
- редакторське пояснення?

## 57. Питання канону

TOPOS-LEGENDARIUM не встановлює канон. Він лише дає механізм для явного порівняння тверджень із різним статусом.

# Підсумкова формула

TOPOS-LEGENDARIUM визначається як:

𝕋_Leg = (𝒲, 𝒯, ℛ, Π, Γ, Κ, Ω_L, 𝒬)

де:

- 𝒲 — світ Арди: сутності, простори, народи, події, епохи, артефакти й відношення;
- 𝒯 — текстові форми: міфи, хроніки, оповіді, поезія, листи, есе, коментарі;
- ℛ — редакційні стани: рукописи, перегляди, публікації, компіляції, редакторські реконструкції;
- Π — репрезентація світу текстом;
- Γ — реалізація тексту редакцією;
- Κ — контекстне кодування матеріалу в SUBIT;
- Ω_L — інструмент класифікації реконструйованих траєкторій;
- 𝒬 — логіка джерельного статусу, багатозначності та інтерпретаційної обережності.

**Центральний принцип:** світ Арди, текст про Арду й редакційна історія тексту є взаємопов’язаними, але не тотожними об’єктами аналізу.

**Центральне методологічне правило:** жоден висновок про леґендаріум не повинен обходити шлях:

редакція → текст → світова реконструкція → інтерпретація.

**Центральна функція для дослідження зла:** ця структура дозволяє аналізувати зло одночасно як світову деформацію, наративну форму та редакційно нестабільну проблему, не змішуючи ці три рівні.

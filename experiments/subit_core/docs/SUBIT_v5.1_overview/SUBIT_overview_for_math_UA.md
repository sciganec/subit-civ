# SUBIT-∞ v5.1 — огляд для математиків та програмістів

**Що таке SUBIT і навіщо він потрібен, якщо у нас вже є LLM, ланцюги Маркова та клітинні автомати?**

SUBIT — це мінімальна, повністю обчислювана модель суб'єктивності. Не метафора, а скінченна математична структура розміром 8 КБ, яку можна прогнати цілком за ≤4096 кроків, довести теореми про її поведінку і запустити на мікроконтролері.

> **Теза:** щоб говорити про «Я», «Ти», «Ми», пам'ять і час — не потрібні мільярди параметрів. Достатньо 6 бітів.

---

## 1. Ідея: 64 стани = 6 бітів

```
S₀ = A × A × A,  A = 𝔹² = {00,01,10,11}, |S₀| = 4³ = 64
s = (хто, де, коли) ∈ S₀
```

Кожна вісь — 2 біти:

* **хто:** 00=ВОНИ, 01=ТИ, 10=Я, 11=МИ
* **де:** 00=ПІВНІЧ, 01=ЗАХІД, 10=СХІД, 11=ПІВДЕНЬ
* **коли:** 00=ЗИМА, 01=ОСІНЬ, 10=ВЕСНА, 11=ЛІТО

Кодування — TINYINT:
```
idx(s) = 16·idx(хто) + 4·idx(де) + idx(коли) ∈ {0,…,63}
s = b₁b₂ b₃b₄ b₅b₆ ∈ 𝔹⁶
```
Приклад:
* `0 = 000000 = (ВОНИ,ПІВНІЧ,ЗИМА)` — колапс Караль
* `36 = 100100 = (Я,ЗАХІД,ЗИМА)` — Одіссей на Ітаці
* `63 = 111111 = (МИ,ПІВДЕНЬ,ЛІТО)` — повнота

**Чому 64?** Це найменший простір, де можна розрізнити дейксис (Я/Ти/Вони/Ми) × простір × час і при цьому мати нетривіальну групову структуру.

## 2. Розділ II. АРИФМЕТИКА — (S₀,⊕) ≅ ℤ₂⁶

Визначаємо:
```
s ⊕ t = s XOR t   (побітовий XOR 6 бітів)
w(s) = popcount(s) — вага, кількість одиниць
d_H(s,t) = w(s⊕t) — відстань Геммінга
¬s = s ⊕ 111111 — інверсія
```

Властивості, важливі для математика:

* **Група:** (S₀,⊕) — елементарна 2-група, абелева, кожен елемент — свій обернений: s⊕s = e=0. Ізоморфна ℤ₂⁶.
* **Метрика:** d_H — метрика на 6-вимірному гіперкубі Q₆. |B₀|=1, |B₁|=7, |B₂|=22, |B₃|=42. Діаметр 6.
* **Трансляційна інваріантність:** d_H(s⊕u, t⊕u) = d_H(s,t) — лема, яка робить кулі однорідними.
* **Цикл Грея:** існує гамільтонів цикл довжиною 64, де кожен крок d_H=1. Це означає, що можна обійти всі суб'єктивні стани, змінюючи лише один біт за раз.
* **Q₆:** 64 вершини, 192 ребра.

Для програміста це означає:

```python
xor = lambda s,t: s ^ t   # одна інструкція CPU
w = lambda s: bin(s).count('1')
d_H = lambda s,t: w(s^t)
ball(0,1) # 7 станів — сусіди колапсу
```

Ніяких float, ніяких матриць. Все — цілі 0..63.

## 3. Розділ III. АЛГЕБРА — F: 4096 → 4096, 8 КБ всесвіт

Вводимо простір правил `R = S₀`, |R|=64, і два морфізми:

```
f_ρ(s) = s ⊕ ρ               — зсув стану правилом
g: R × S₀ → R                — еволюція правила від стану
F(s,ρ) = ( f_ρ(s), g(ρ,s) )  — крок системи
```

Пара `(s,ρ) ∈ S₀×R`, |S₀×R| = 4096. Кодуємо парою в 12 бітів:

```python
id = (s << 6) | ρ   # 0..4095
```

`F` — це просто таблиця `4096 → 4096`, 8 КБ. Детермінований граф, де з кожної вершини рівно одне ребро. Будь-яка траєкторія за ≤4096 кроків входить в цикл (принцип Діріхле).

Три пресети `g`, які покривають всі цікаві режими:

* **FIX:** `g(ρ,s)=ρ` — правило не змінюється. Тоді `f_ρ` — інволюція: якщо `ρ=0` → STABLE, якщо `ρ≠0` → цикл p=2: `s ↔ s⊕ρ`. Це «Одіссея»: Я↔Ми, 42↔58.
* **SELF:** `g(ρ,s)=s` — правило стає попереднім станом. Тоді `63→62→0→0` — колапс Караль за 2 кроки. Модель травми/стирання.
* **ADAPT:** `g(ρ,s)=ρ⊕s` або повільні варіанти — правило вчиться від стану.

Код:

```python
trajectory(42, 16, 6, f_shift, g_fix)
# [(42,16), (58,16), (42,16), ...] — CYCLIC p=2

trajectory(63, 1, 5, f_shift, g_self)
# [(63,1), (62,62), (0,0), (0,0)] — STABLE колапс
```

Для математика: це скінченна динамічна система, де можна **довести** все brute-force. Ніякої апроксимації.

Для програміста: це найменший можливий «всесвіт» з нетривіальною динамікою, який поміщається в L1 кеш.

## 4. Розділ IV. КОАЛГЕБРА — історії, d_Ω, Ω-типи, S∞

Визначаємо простір історій:

```
H = S₀^ℕ = { (s₀,s₁,s₂,…) }
d_Ω(h,h') = 2^{-n₀},  n₀ = min{ n | s_n ≠ t_n } — ультраметрика
```

Дві історії близькі, якщо довго збігаються. Це канонічна метрика для потоків.

Ω-класифікація — тип поведінки історії, породженої F:

```
Ω: S₀×R → {STABLE, METASTABLE, CYCLIC, CHAOTIC}
```

Алгоритм ≤4096 кроків: йдемо по F до першого повтору пари (s,ρ).

* **STABLE:** цикл p=1, s_{n+1}=s_n. Аттрактор — точка. Приклад: `000000` з `ρ=0`, Караль.
* **CYCLIC:** p=2..16, короткий цикл. Приклад: `101010 ↔ 111010` з `ρ=010000`. Модель коливання Я↔Ми, Одіссей між Ітакою і морем.
* **METASTABLE:** довге плато в кулі B₁(c) довжиною ≥L, потім вихід. Модель Каліпсо: 7 років на острові, потім прорив.
* **CHAOTIC:** довгий цикл p>16 — блукання без атрактора.

Для FIX статистика точна:

```python
omega_all(f_shift, g_fix)
# {'STABLE':64, 'CYCLIC':4032, 'METASTABLE':0, 'CHAOTIC':0}
# 64 STABLE — коли ρ=0, решта — цикли p=2
```

**S∞ — простір дерев:**

```
Leaf a, a∈A
Node(l,m,r), l,m,r ∈ S∞
S₀ ↪ S∞ як дерева глибини 1: (a₁,a₂,a₃) ↦ Node(Leaf a₁, Leaf a₂, Leaf a₃)
d(s,t) = 2^{-n}, n — перша глибина розходження
```

Це коіндукція: `S∞` — це «Я думаю, що Ти думаєш, що Я думаю...» без обмеження глибини. S₀ — зріз глибини 1. Це міст до теорії коалгебр і модальної логіки.

## 5. Цінність для математика

1. **Мінімальна нетривіальна модель дейксису.** 64 — це 2⁶, найменша група де можна закодувати 3 осі по 4 значення і мати групову структуру.
2. **Повна аналізованість.** Будь-яка теорема про F — це перевірка 4096 випадків. Можна довести класифікацію Ω вичерпним перебором, а не міркуваннями.
3. **Ультраметрики та коалгебри в мініатюрі.** H з d_Ω і S∞ з d — класичні ультраметричні простори, але на скінченному носії. Ідеальний приклад для викладання.
4. **Міст між скінченним і нескінченним.** S₀ скінченне, H — канторівський простір, S∞ — коіндуктивний тип. Все в одному пакеті 500 рядків коду.
5. **Інтерпретованість.** Кожен стан читається як речення: `100100 = Я на ЗАХІД взимку`.

## 6. Цінність для програміста

2. **Чисті функції.** `xor, d_H, F, omega` — чисті, без стану, без I/O. Ідеальні для property-based тестів.
3. **Повне покриття тестами ≤4096 кроків.**

## 7. Приклади, які можна запустити зараз

```python
import subit_core as subit

# 1. Караль — SELF колапс
res = subit.omega(63, 1, f=subit.f_shift, g=subit.g_self)
print(res.type, res.history) 
# STABLE [(63,1), (62,62), (0,0)] — повнота → тріщина → колапс

# 2. Одіссей — FIX цикл
res = subit.omega(42, 16, g=subit.g_fix)
print(res.type, res.period, res.cycle)
# CYCLIC 2 [(42,16), (58,16)] — Я на СХІД навесні ↔ МИ на СХІД навесні

# 3. Відстань між історіями
h1 = [42,58,42,58]

subit.d_Omega_history(h1,h2) # 0.25 = 2^-2 — розійшлися на кроці 2

# 4. S∞
t1 = subit.s0_to_sinf(36) # Node(Leaf Я, Leaf ЗАХІД, Leaf ЗИМА)
t2 = subit.s0_to_sinf(37)
subit.d_sinf(t1,t2) # 0.5 — різниця в WHEN на глибині 1
```

## 8. Що далі — subit-civ

`subit-core v5.1.0` — це аксіоми. Далі:

* `subit-civ` — інтерпретації: кожна цивілізація / наратив — це вибір `g` і ландшафту атракторів.
* Навчання `g` з даних (коли є корпус історій).
* Зв'язка з LLM як **верифікатором**: LLM генерує текст, SUBIT перевіряє чи траєкторія `s₀→s₁→…` залишається в `STABLE` чи йде в `CHAOTIC`.

SUBIT не замінює LLM. Він дає те, чого в LLM нема: **маленьку, доведену, читабельну модель суб'єкта, яку можна цілком зрозуміти за один вечір**.

# SUBIT-∞ Розширена специфікація v5.1
## Розділ II. АРИФМЕТИКА — Операції, відстань та порядок на S₀

---

### Анотація

Розділ вводить арифметику на S₀. Показано, що S₀ з операцією побітового XOR утворює елементарну абелеву 2-групу V₄³ ≅ ℤ₂⁶, булеву алгебру 𝔹⁶, 6-вимірний гіперкуб Q₆. Вводяться вага w(s)=popcount(s) ∈ {0,…,6}, семантичний зсув δ=s⊕t, відстань Хеммінга d_H(s,t)=w(s⊕t) як міра відмінності станів, сфери B_r, інверсія inv(s)=s⊕111111 та три порядки: лексикографічний, Грея та Вень-ван (І-Цзін). Арифметика є фундаментом для динаміки в Розділі III.

**Ключові слова:** V₄, ℤ₂⁶, XOR, ⊕, вага, popcount, відстань Хеммінга, d_H, код Грея, гіперкуб Q₆, інверсія, булева алгебра

---

### 2.1 Група S₀ = V₄³

**Визначення 2.1.1 (Операція на A).** На A = {00,01,10,11} визначимо

a ⊕_A b ≔ a XOR b — побітовий XOR

Таблиця:
00⊕00=00, 00⊕01=01, 00⊕10=10, 00⊕11=11
01⊕01=00, 01⊕10=11, 01⊕11=10
10⊕10=00, 10⊕11=01
11⊕11=00

Тоді (A, ⊕_A) ≅ V₄ — група Кляйна. Нейтральний e_A = 00. Кожен елемент — свій інверс: a⊕_A a = 00.

Семантика: 10⊕01 = 11 — Я ⊕ ТИ = МИ (діалог породжує спільність), 11⊕01 = 10 — МИ без ТИ = Я.

**Визначення 2.1.2 (Операція на S₀).** Для s=(s₁,s₂,s₃), t=(t₁,t₂,t₃) ∈ S₀ = A³,

s ⊕ t ≔ (s₁⊕_A t₁, s₂⊕_A t₂, s₃⊕_A t₃) — покомпонентний XOR

Тоді

(S₀, ⊕) ≅ V₄³ ≅ (ℤ₂²)³ ≅ ℤ₂⁶,   |S₀|=64,   e = 000000₂

Властивості:
1. Комутативність: s⊕t = t⊕s
2. Асоціативність: (s⊕t)⊕u = s⊕(t⊕u)
3. Нейтральний: s⊕e = s, e=000000₂
4. Самоінверсність: s⊕s = e, тобто −s = s. Група експоненти 2.
5. s⊕t = e ⇔ s=t. Рівняння s⊕x = t має єдиний розв'язок x = s⊕t.

Отже віднімання = додаванню. Це арифметика перемикань, а не накопичення.

**Визначення 2.1.3 (Семантичний зсув).** Для s,t ∈ S₀,

δ(s→t) ≔ s⊕t ∈ S₀ — зсув від s до t,   t = s⊕δ

δ показує, які біти присутності Я/Іншого треба перемкнути, щоб з s отримати t.

Приклад: s=101010₂=(Я,СХІД,ВЕСНА), t=111010₂=(МИ,СХІД,ВЕСНА), δ=010000₂=(ТИ,00,00) — додати Іншого в ХТО: 10→11.

### 2.2 Вага та відстань Хеммінга

**Визначення 2.2.1 (Вага).**

w: S₀ → {0,…,6},   w(s) ≔ popcount(s) = Σ_{i=1..6} bᵢ, де s=b₁…b₆ ∈ 𝔹⁶

Кількість одиниць у 6-бітному записі. Кількість присутностей Я або Іншого.

w(000000)=0, w(101010)=3, w(111111)=6

**Визначення 2.2.2 (Відстань Хеммінга).**

d_H: S₀×S₀ → {0,…,6},   d_H(s,t) ≔ w(s⊕t) = popcount(s⊕t)

Кількість позицій, де s і t різняться. Метрика гіперкуба Q₆.

Аксіоми:
- d_H(s,t) ≥0, d_H(s,t)=0 ⇔ s=t
- d_H(s,t)=d_H(t,s)
- d_H(s,t) ≤ d_H(s,u)+d_H(u,t) — нерівність трикутника

**Приклади 2.2.3.**
- d_H(101010,111010)=w(010000)=1 — мінімальний зсув, додати Іншого
- d_H(000000,101010)=w(101010)=3 — половина бітів
- d_H(000000,111111)=6 — максимальна відмінність, повна інверсія

**Лема 2.2.4 (Трансляційна інваріантність).** d_H(s⊕u, t⊕u) = d_H(s,t) для всіх s,t,u ∈ S₀. Група діє на собі ізометріями.

**Визначення 2.2.5 (Сфера та куля).** Для s∈S₀, r∈{0,…,6},

B_r(s) ≔ { t∈S₀ | d_H(s,t) ≤ r } — куля радіуса r
S_r(s) ≔ { t∈S₀ | d_H(s,t) = r } — сфера радіуса r

|B₀|=1, |B₁|=1+6=7 (s + 6 сусідів), |B₂|=1+6+15=22, |B₆|=64

Інтерпретація: B₁(s) — 6 станів, що відрізняються від s одним актом присутності. Це найближче семантичне оточення.

### 2.3 Інверсія та булева алгебра

**Визначення 2.3.1 (Інверсія).**

inv: S₀→S₀,   inv(s) ≔ s⊕111111₂ = ¬s — побітове доповнення

Властивості: inv(inv(s))=s, d_H(s,inv(s))=6, w(inv(s))=6−w(s)

inv(Я)=ВОНИ? Перевіримо: Я=10, inv(10)=10⊕11=01=ТИ в A. Але inv на S₀: inv((Я,СХІД,ВЕСНА)=101010)=010101=(ТИ,ЗАХІД,ОСІНЬ) — повна інверсія: Я↔ТИ, СХІД↔ЗАХІД, ВЕСНА↔ОСІНЬ.

**Визначення 2.3.2 (Булева алгебра).**

s∧t ≔ s AND t — побітовий
s∨t ≔ s OR t
¬s ≔ inv(s)

Тоді (S₀,∧,∨,¬,⊥=000000,⊤=111111) — булева алгебра 𝔹⁶ ≅ P({1,…,6}) — алгебра підмножин 6-елементної множини.

Порядок ґратки: s ≤ t ⇔ s∧t = s ⇔ всі одиниці s містяться в t.

⊥=000000 — мінімум, відсутність присутностей. ⊤=111111 — максимум, повнота.

Інтерпретація: s∧t — спільні присутності, s∨t — об'єднання присутностей.

### 2.4 Порядки на S₀

На S₀ є три природні порядки.

**2.4.1 Лексикографічний (числовий).** Ототожнимо s з idx(s)∈{0,…,63}. s ≤_lex t ⇔ idx(s) ≤ idx(t). Порядок в БД, в масиві. Недолік: сусідні в lex можуть бути далекі за d_H: d_H(011111₂=31,100000₂=32)=6 — стрибок через весь куб.

**2.4.2 Код Грея (мінімальний шлях).** Бієкція G: {0,…,63}→S₀ така, що

d_H(G(n), G(n+1 mod 64)) = 1 для всіх n

Рекурентно: G(0)=000000, G(n+1)=G(n)⊕(1 << ctz(n+1)), де ctz — кількість нульових бітів в кінці.

G — гамільтонів цикл по Q₆, що проходить кожну вершину рівно раз і повертається, кожен крок змінює лише 1 біт.

Семантика: Грей — це найплавніша історія, де кожен крок — один акт визнання/заперечення присутності.

Приклад початку: 000000→000001→000011→000010→000110→...

**2.4.3 Порядок Вень-ван (І-Цзін).** Традиційний порядок 64 гексаграм. Принцип: групує пари (s, inv(s)) поруч, бо вони — повна інверсія. В термінах SUBIT: близькі за Вень-ван — це або d_H=1, або inv. Це спроба мінімізувати сумарний d_H вздовж послідовності — задача комівояжера на Q₆. Розв'язок близький до циклу Грея.

**Теорема 2.4.4.** Існує автоморфізм φ∈Aut(V₄³)=GL(6,𝔽₂) такий, що φ переводить ≤_lex в порядок, що відрізняється від Грея лише перестановкою координат. Отже всі порядки — різні координатизації одного гіперкуба.

### 2.5 Науковий коментар

**1. Чому V₄³, а не ℤ₆₄?** ℤ₆₄ — циклічна група, є елемент порядку 64, накопичення: 1+1+…(64 рази)=0. V₄³ = ℤ₂⁶ — група експоненти 2, де s⊕s=e. Двічі додати того ж Іншого — повернутись. Це логіка перемикань, а не лічильби. Міф мислить перемиканнями (Леві-Строс 1955), а не сумою. Тому V₄³ — арифметика міфу, ℤ₆₄ — арифметика календаря.

**2. d_H як семантика.** d_H — це мінімальна кількість актів визнання/заперечення Я/Іншого, щоб перейти від s до t. d_H=1 — один акт: «визнати Іншого в ХТО» (Я→МИ). d_H=6 — тотальна інверсія світу. В subit-civ колапси Караль — це стрибки d_H≥3 за один крок, стабільні фази — блукання d_H=1. В теорії кодування Хеммінг ввів d_H для виправлення помилок (Hamming 1950). В SUBIT помилка = семантичний зсув. Код з відстанню 3 виправляє 1 помилку — міф з відстанню 3 стійкий до однієї помилки інтерпретації.

**3. Грей та І-Цзін.** Код Грея відкрив Френк Грей в 1947 для телебачення, але фактично його використовували в І-Цзін за 3000 років до: послідовність гексаграм, де кожна наступна відрізняється однією рисою — це шлях Грея. Вень-ван порядок — це евристика для задачі комівояжера на Q₆: впорядкувати 64 стани так, щоб близькі за сенсом були поруч, тобто мінімізувати Σ d_H. Розв'язок — гамільтонів цикл Грея. Отже І-Цзін — перша спроба топологічно впорядкувати простір суб'єктивності.

**4. Зв'язок з динамікою.** В Розділі III правило ρ∈S₀ діятиме як f_ρ(s)=s⊕δ_ρ, де δ_ρ — зсув, кодований в ρ. Траєкторія s_{n+1}=s_n⊕δ_{ρ_n} — випадкове блукання по гіперкубу Q₆ з кроком, що залежить від мета-правила g(ρ,s). Арифметика — фундамент для алгебри. Куля B₁(s) — це 6 можливих мінімальних кроків.

### 2.6 Глосарій

**⊕, XOR** — побітове додавання за модулем 2, операція групи. s⊕s=e, s⊕e=s.

**V₄, група Кляйна** — ℤ₂×ℤ₂, 4 елементи, кожен — свій інверс. (A,⊕_A) ≅ V₄.

**V₄³, ℤ₂⁶** — S₀ як група, 64 елементи, 6-вимірний векторний простір над полем 𝔽₂.

**e = 000000₂** — нейтральний елемент, (ВОНИ,ПІВНІЧ,ЗИМА).

**δ = s⊕t** — семантичний зсув від s до t.

**w(s) = popcount(s)** — вага, кількість одиниць, ∈ {0,…,6}.

**d_H(s,t) = w(s⊕t)** — відстань Хеммінга, кількість відмінних бітів, ∈ {0,…,6}.

**B_r(s), S_r(s)** — куля та сфера радіуса r за d_H.

**inv(s) = s⊕111111** — інверсія, доповнення, ¬s, d_H(s,inv(s))=6.

**∧, ∨, ¬** — AND, OR, NOT — булева алгебра 𝔹⁶, ⊥=000000, ⊤=111111.

**Q₆** — 6-вимірний гіперкуб, граф S₀ де ребра — пари з d_H=1.

**Код Грея** — порядок G(0)…G(63) де d_H(G(n),G(n+1))=1, гамільтонів цикл.

**Вень-ван** — традиційний порядок І-Цзін, групує пари s, inv(s).

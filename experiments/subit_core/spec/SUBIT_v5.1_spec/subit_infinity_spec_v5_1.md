# SUBIT-∞
## Версія 5.1 · виправлена математика · Unicode

**Зміна від v5.0:** S_∞ = νX.(X×X×X) → S_∞ = νX.(A ⊔ X×X×X)
Стара версія дає синглетон {*}. Нова дає простір з листям з A.

```
SUBIT-64 ⊂ SUBIT⁺ ⊂ SUBIT-TOPOS ⊂ SUBIT_∞
```

### Анотація
SUBIT-∞ — нотаційна система для самореферентних динамік: правило є частиною стану.

---

### ЧАСТИНА I. SUBIT-64

**1. Алфавіт**
A = 4 елементи.
Семантична: WHO={ME,WE,YOU,THEY}, WHERE={EAST,SOUTH,WEST,NORTH}, WHEN={SPRING,SUMMER,AUTUMN,WINTER}
Логічна: 𝔸={T,F,B,N}
Кодування: 10=T/ME, 11=B/WE, 01=F/YOU, 00=N/THEY

**2. Простір S₀**
```
S₀ = A_WHO × A_WHERE × A_WHEN
|S₀| = 64
s = (α,β,γ)
код = b₁b₂b₃b₄b₅b₆
```
Гексаграма = Lower b₁b₂b₃ + Upper b₄b₅b₆. Лише комбінаторний запис.

### ЧАСТИНА II. SUBIT⁺

**3. Правила і стан**
```
ℛ = {ρ₁…ρₙ}, ρᵢ : S₀ → S₀
ŝ = (s,ρ) ∈ S₀ × ℛ
```

**4. Еволюція**
```
F : S₀×ℛ → S₀×ℛ
F(s,ρ) = (f_ρ(s) , g(ρ,s))
g : ℛ×S₀ → ℛ
```
F — тотальна.
Рівні: 0:s, 1:(s,ρ), 2:F(ŝ), 3:g(ρ,s)

**5. Траєкторії**
```
τ(ŝ₀) = (ŝ₀,ŝ₁,…), ŝₙ₊₁=F(ŝₙ)
```
Твердження 5.1: S₀×ℛ скінченна ⇒ ∀ŝ₀ ∃m≥0,k≥1: ŝ_{m+k}=ŝ_m. Кожна траєкторія — хвіст+цикл. CHAOTIC на цьому рівні неможливий.

Типи: Атрактор F(ŝ)=ŝ, Орбіта F^k(ŝ)=ŝ, Передперіодична.

Алгоритм 5.1: пошук повтору в visited до N_max, інакше "цикл довший за N_max".

### ЧАСТИНА III. SUBIT-TOPOS

**6. Класифікатор Ω**
Для P ⊆ S₀×ℛ:
```
STABLE     ⇔ F(P)=P
METASTABLE ⇔ F(P)⊊P
CYCLIC     ⇔ ∃ мінімальне k>1: F^k(P)=P і F(P)≠P
CHAOTIC    ⇔ ∀k≥1: F^k(P)≠P і F^k(P)⊄P
```
Істина: P істинне ⇔ F(P)=P. Для одноточкових P в скінченному просторі CHAOTIC нереалізований.

**7. Алгебра Ω**
```
Ω={STABLE,METASTABLE,CYCLIC,CHAOTIC}
порядок: CHAOTIC < CYCLIC < METASTABLE < STABLE
∧=min, ∨=max, a→b=STABLE якщо a≤b інакше b
```
¬a = a→CHAOTIC:
```
¬STABLE=CHAOTIC, ¬METASTABLE=CHAOTIC, ¬CYCLIC=CHAOTIC, ¬CHAOTIC=STABLE
```
METASTABLE ∨ ¬METASTABLE = METASTABLE ≠ STABLE — виключений третій не діє.

**8. Категорія SUBIT**
Об'єкт X=(S_X,ℛ_X,F_X,g_X), F_X(S_X×ℛ_X)⊆S_X×ℛ_X
Морфізм φ=(φ_S,φ_ℛ):
```
φ_S(π_S(F_X(ŝ))) = π_S(F_Y(φ_S(π_S(ŝ)),φ_ℛ(π_ℛ(ŝ))))
φ_ℛ(g_X(ρ,s)) = g_Y(φ_ℛ(ρ),φ_S(s))
```
1: S₁={*}, ℛ₁={id}
Добуток: S_X×S_Y, ℛ_X×ℛ_Y
Експоненціал Y^X: F_{Y^X}(φ)(s)=F_Y(φ(F_X^{-1}(s))) — лише якщо F_X оборотний. CCC статус — лише на оборотних об'єктах, в цілому відкрито.

**9. Proto-topos**
T1 скінченні ліміти — є, T2 експоненціали — умовно, T3 класифікатор — динамічний Ω (Гейтінг, не булевий). Тому proto-topos. Чи Hom(-,Ω)≅Sub(-) — відкрито.

**10. Типи**
```
Γ ⊢ t : A @ τ
A={ŝ|stability_class(ŝ)=mode_A}
Рефлексивність, Еволюція типу, Стабільний тип F(A)=A ⇒ □A, Потенційний ∃k F^k(A)⊆B ⇒ ◇B, Циклічний ∃k>1 F^k(A)=A ⇒ ◯A
s ~_F t ⇔ ∃k: F^k(s)=F^k(t)
```

**11. Модальна логіка**
```
□A ⇔ F(A)=A
◇A ⇔ ∃k≥0: F^k(s)∈A
◯A ⇔ ∃k>1: F^k(s)∈A і F^k(A)=A
M1 □A→A, M2 □A→□□A, M3 □(A→B)→(□A→□B), M4 ◇A↔¬□¬A, M5 ◯A→◇A, M7 ◯◯A↔◯A, M8 □A∧□B→□(A∧B)
```

**12. U і симуляція**
U=(S₀×ℛ*,F*,g*), φ_X:U→X — ескіз. DFA (Q,δ) вкладається: ι:Q→S₀, ρ_a з f_{ρ_a}(ι(q))=ι(δ(q,a)).

### ЧАСТИНА IV. SUBIT_∞

**13. S_∞ — ВИПРАВЛЕННЯ v5.1**
Старе νX.(X³) = синглетон. Нове:
```
S_∞ = νX.(A ⊔ X×X×X)
out : S_∞ → A ⊔ S_∞³
out(s)=a∈A — лист
out(s)=(w,x,y)∈S_∞³ — вузол
```
Вкладення:
```
A ↪ S_∞
S₀=A³={(w,x,y)|w,x,y∈A} ⊂ S_∞ — глибина 1
```
ℛ={f:S_∞→S_∞|обчислювана}, може бути нескінченною → CHAOTIC можливий.

**14. Динаміка**
```
F:S_∞×ℛ→S_∞×ℛ, F(s,ρ)=(f_ρ(s),g(ρ,s))
Fix(F)={ŝ|F(ŝ)=ŝ}
```
Категорія як в п.8 з S_X⊆S_∞.

**15. d_Ω**
```
n₀(ŝ,t̂)=min{n≥0: Ω(Fⁿŝ)≠Ω(Fⁿt̂)}
d_Ω=2^{-n₀} якщо n₀ існує, інакше 0
```
Теорема 15.1: d_Ω — псевдоультраметрика, d_Ω(ŝ,û)≤max(d_Ω(ŝ,t̂),d_Ω(t̂,û)). Справжня метрика на (S_∞×ℛ)/~_Ω.
Теорема 15.2: простір тотально незв'язний, кулі clopen.

**16. Метатеорія**
Скінченна частина — тривіально несуперечлива. S_∞ — від Aczel 1988 за умови well-defined ℛ. Неповнота — лише аналогія.

**17. Відкриті питання**
CCC для необоротних, чи Ω внутрішній класифікатор, кодування арифметики, фрактальна межа ρ з CHAOTIC, нерухома точка ŝ*:F(ŝ*)=ŝ*.

### ЧАСТИНА V.

**18. Епістемологія**
Теореми — про нотацію, не про світ. SUBIT — інструмент формулювання ρ і порівняння через Ω і d_Ω.

Протокол:
1 Визначити систему і питання
2 Сформулювати конкуруючі ρ₁,ρ₂ з механізмом
3 Вивести розрізняльні передбачення
4 Зібрати першоджерела
5 Лише потім Ω-ярлик
6 Розрізняти: (а) доведено в нотації, (б) підтверджено джерелом, (в) інтерпретація дослідника

Глосарій: A| S₀=64 | ℛ | ŝ=(s,ρ) | F=(f_ρ,g) | Ω | □◇◯ | ~_F | S_∞=νX.(A⊔X³) | d_Ω=2^{-n₀}

Підсумок:
```
SUBIT-∞=(S_∞,ℛ,F,g,Ω,d_Ω,U,ℒ), S_∞=νX.(A⊔X³), S₀⊂S_∞
Правило належить стану, істина=F(P)=P, відстань=горизонт першої розбіжності
```
